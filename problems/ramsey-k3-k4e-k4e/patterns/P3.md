# P3 Extensions of other 20-point colourings

Valid 20-point colourings other than O1 (F1: O1 has no extension), found
by local search, each tried with `extensions` for a 21st point. Every answer
restricts to a valid 20-point colouring 21 times over, so the answers are
exactly the extensions of some of them.

**Kill test.** 1,000 distinct valid 20-point colourings from local search,
each run through `extensions`; how many extend, and how close the rest come.
**Status.** new.
