# I25 Tie-rule sandwich

Make the rule "an exact catch-up ends the turn" a choice of one player, the controller: the real game lies between the two controller games (C111), so C1 follows if neither controller can win on I_N (C112). In the controller games odd and even totals behave alike (the controller wins odd totals by exactly 1, draws even ones, N ≤ 22), so inductions through odd N that break on the real game's irregular signs (C100's add-top step: "odd tops have no bridge") may close there. Diagnostic for every route: a draw that needs the real tie rule (tie-fragile) can only be proved by an argument that uses it; C86's band is 22 % fragile, C1's roots and C92 from N = 16 are robust (N ≤ 20). Source: ideator, 2026-11-05 (`scratch/ideator/fresh05/`, B).

**Kill test.** (1) The controller games at N = 23 (queued Q2, about 0.8 GB, a minute): a non-zero value at an even total refutes C112 (not C1) and kills the idea. (2) The add-top step in G_A, N ≤ 18 (Q3, seconds): if "the row of I_N in G_A is the parity bit for d ≤ N − 1" survives adding the top through odd N where the real game's does not, G_A is the better induction target.
