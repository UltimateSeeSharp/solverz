# I30 Automatic rows

If the rows m({1..N}, d), d fixed, are automatic sequences in N, Walnut could prove properties of them for all N. Technique `T21` Walnut. Source: user's toolbox sweep, 2026-11-05.

**Kill test.** Rows for every N ≤ 22, d ≤ 8 (scratch `uni/rows.rs`, one `Margin` table over {1..22}; `scratch/a19/rows22-kept.txt`), and whether a small automaton reproduces them. Done: they are trivially automatic: every row with d ≥ 2 is periodic with period 4 from small N (|m| = the parity bit, sign + at odd parity: d = 3: 0 0 1 1 …), and d = 0, 1 have |m| ≤ 1 throughout with irregular signs at odd parity up to N = 18 (d = 0: −1 at N = 9, 10, 14, 18), +1 from N = 21.
**Status.** dead as a proof route: an automaton that reproduces the rows is easy (period 4), but Walnut proves statements about the automaton, not that the game's values follow it; that link is |m({1..N}, 0)| ≤ 1 for every N, which is C1 itself (C37 (3), `conjecture_of_margin_le_one`). No install needed or requested.
