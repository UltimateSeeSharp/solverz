# I13 Smallest-first to mid height

The defender D takes the smallest number left (whole turns, until it catches up; at a tie the smallest) while the set is low, min R < c·span (span = max R − min R), then plays optimally. C1(N) ⇐ C61 (EX(c, N)): at every exit, the first position with min R ≥ c·span, D's value is ≥ 0, in both roles, and no game ends inside the class; parity (C33) then gives the draw. The low phase becomes a fixed rule; what remains is a statement about exits, near-blocks with few holes at relative height ≥ c, i.e. I7's descent (C32) down to height c with holes. Unlike I8 there is no hand-over to Hyb2 and no low-phase class; unlike E9 the switch is below 1/2 (there k = 1 fails from N = 8). Root claim: C61.

**Kill test.** (a) Exact values at every exit for N = 35, 36 (universe about {8..36}; needs an engine over a restricted universe with deficits): a losing exit kills c = 0.3, then c = 0.2, 0.25 are retried; every c failing by N ≈ 40 kills I13. (b) Cheaper: whether the exits have a short description on which a universal companion holds (near-blocks with ≤ h holes at relative height ≥ c are non-losing at the exits' deficits); the ideator's MHL (≤ 2 holes, height 0.2–0.45) fails with 3 clustered holes, while exits carry about N/12 holes (5 at N = 64, a structure walk without values). No such description → I13 says something only about reachable positions and folds into I8.
**Kill test (b) so far** (2026-10-30, `scratch/a13/classk2.rs`, `sep1.rs`): exits for N ≤ 28 are near-blocks with ≤ 2 holes (largest internal gap 3), relative height 0.30–0.83 from N = 23, deficit below min R, mostly E to move, both count parities. Over all of {1..24} the class "near-block, relative height 0.30–0.85, |R| ≥ 6, e < min R, sum + e even" is safe only without holes: the mover wins at 26 of 2,095 one-hole positions, 206 of 11,332 with two holes, 1,400 of 39,786 with three. Reachable one-hole exits avoid those: the failures have the hole just above min R and a small deficit (hole − min R + e small), so a class must tie each hole to the deficit. By conservation an exit with E to move is fixed by its split of {1..N}: D holds [1, lo) ∖ B, E holds B ∪ H ∪ (hi, N], e = T(lo − 1) + T(hi) − T(N) − 2·sum(B) − sum(H). Splits with E to move, relative height 0.30–0.85, 0 ≤ e < lo still fail (`splitclass.rs`, N ≤ 22): with B = ∅ and ≤ 1 hole none fails, but most exits have B ≠ ∅ (236 of 253 one-hole exits at N = 28, `exitsb.rs`); requiring min R + 1 ∈ R leaves failures and excludes 17% of the exits (`exitlo1.rs`).
