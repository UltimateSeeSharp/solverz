# I13 Smallest-first to mid height

The defender D takes the smallest number left (whole turns, until it catches up; at a tie the smallest) while the set is low, min R < c·span (span = max R − min R), then plays optimally. C1(N) ⇐ C61 (EX(c, N)): at every exit, the first position with min R ≥ c·span, D's value is ≥ 0, in both roles, and no game ends inside the class; parity (C33) then gives the draw. The low phase becomes a fixed rule; what remains is a statement about exits, near-blocks with few holes at relative height ≥ c, i.e. I7's descent (C32) down to height c with holes. Unlike I8 there is no hand-over to Hyb2 and no low-phase class; unlike E9 the switch is below 1/2 (there k = 1 fails from N = 8). Root claim: C61.
