# I2 An invariant region of positions

- **Reduction.** For each player P a class C_P of positions (numbers left, gap, P to move) such that: P's first turn start is in C_P (for player 2, after every opening); from each C_P position P has a turn after which every opponent turn returns P to C_P or ends the game without P losing. Then P never loses; with both players, the game is a draw. Blueprint root: C1.
- **Metric.** Violations of that closure for the best candidate class, as the earliest point (numbers left) where the opponent can force P out of it. Now: no fixed-h hole class closes (C43); adjacent pairs with ≤ 2 broken hold until 0–11 numbers are left for N ≤ 24, ≤ 4 broken hold the whole game for N ≤ 24 (2026-10-22).
- **Evidence.** The parity law (C3). Interval rows follow the parity rule exactly in a middle band of gaps; draw-parity gaps are never losses there (log 2026-10-22: interval rows). Near-intervals with few holes keep this (C4, C5); complete sets don't. Drawing play looks like adjacent pairing with defects that grow like N/6 (log 2026-10-22: holes grow under drawing play).
- **Kill criteria.** Every simple candidate C has closure violations growing with N.
