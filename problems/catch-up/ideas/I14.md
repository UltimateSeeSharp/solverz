# I14 Exact-change certificates

L: level sets R (mover at a tie) with two distinct openings t ≠ t' such that after each, every payment of the opponent (overshoot e) is answered by an exact payment of e into a set of L (or e = 0 and the rest is in L, or the opener takes everything and ends ≥ 0, or the opponent cannot pay). By C30's corollary every R in L is a draw (induction on |R|), so C1 ⇐ {1..N} ∈ L.

**Kill test.** {1..N} ∉ L for some even-total N.
**Evidence.** Ideator (2026-10-30, `scratch/ideator/fresh30/ec2.rs`, every S ⊆ {1..14}): sound (every member of L is a draw), but L is only ∅ and 42 three-element sets; no drawn 4-element set and no {1..N}, N ≥ 4. No two distinct numbers form a level draw, so exact payments leaving 1 or 2 numbers never land in L; certifying overshoots needs a class "opponent owes f", which is I2.
**Status.** dead (2026-10-30): kill test met at N = 4.
