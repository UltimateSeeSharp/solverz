# I24 Tied one-hole blocks

A tied family with no height threshold: C105 (odd blocks minus one number of the parity draw at a tie, every height) and C106 (blocks minus one number never lose at a tie; at a = 1 they draw). C1 is the a = 1, h = top instances ({1..N} = {1..N+1} ∖ {N+1}). Every proved block result (C23, C24, C20) is height-free only above about 2p − 1, and every open one (C86 below 2p − 1, C85, C84) is tested height by height; C105 holds at every height tried, low and high, so it is a candidate for one uniform argument; its rounds half is a finite game per k. Uses toward the rest: C106 gives C104's no-loss half at a = 1 by exact change, and C105 gives it on odd blocks at a ≤ d ≤ max. Source: ideator, 2026-11-04 (`scratch/ideator/fresh04c/`, B).

**Kill test.** E34 (C105: k ≤ 9, every a ≤ 2(2k + 1) and a = (2k + 1)², margins) and E35 (C106: n ≤ 19, same heights). A non-draw (C105) or a loss (C106) kills that claim; one at a = 1 would refute C1's generalization there, not C1.
