# Obstructions

Counterexamples to generalizations and the approaches they rule out. Check here before trying an idea.

- **Induction by four on drawn sets** (log 2026-10-22): {2,7,9,14} is a draw, {2,7,9,14} ∪ {15,16,17,18} a player-1 win. Rules out: proving {1..N} → {1..N+4} from "S is an even-sum draw" alone.
- **… restricted to complete sets** (same entry): {1,2,4,8,15,17,18,20,25} ∪ {26,27,28,29} is a player-1 win though the smaller set draws. Rules out: completeness as the induction invariant.
- **Complete even-sum sets are draws** (same entry): first exception {1,2,3,7,9,11,14,15,22} (player 1 wins by opening 2); none with max ≤ 21. Rules out: completeness alone as the characterization of draws.
