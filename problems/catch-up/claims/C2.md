# C2 Every opening draws

For even-total N ≥ 12, every opening move of player 1 still leads to a draw; implies C1 for those N

**Proof.** Open.
**Evidence.** Every opening draws for each even-total N with 12 ≤ N ≤ 35 ([experiments](../experiments/_experiments.md)); fails at N = 3, 4, 7, 11. A middle band of gaps around every opening gap draws too (log 2026-10-22: interval rows).
