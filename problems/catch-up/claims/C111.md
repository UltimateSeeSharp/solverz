# C111 Tie-rule sandwich

For a player X let G_X(S) be Catch-Up's margin game on S in which X decides, at every exact catch-up (a pick that brings the picker exactly level), whether the turn ends (the real rule) or the picker must take one more number. Then for every S, from player A's side, value(G_B) ≤ value(real) ≤ value(G_A); hence C1(N) follows from C112 at N.

**Use.** I25's reduction. It makes "an exact catch-up ends the turn" a parameter: an argument that never uses that rule proves C112 as well.
**Proof.** Paper (ideator, unchecked): the controller may always choose "end", so it can replay any real-game strategy; value_A(G_A) ≥ value_A(real) and value_B(G_B) ≥ value_B(real). If neither controller wins on I_N, 0 ≤ value_A(G_B) ≤ value_A(real) ≤ value_A(G_A) ≤ 0. Verified (2026-11-05; `lake build --wfail`, standard axioms; `CatchUp/Controller.lean`): `ctlMargin R a b c` is the controller game's margin (c: the mover controls; an exact catch-up is a mover strictly behind whose pick brings it level), `CatchUp.ctlMargin_sandwich`: ctlMargin R a b false ≤ margin R a b ≤ ctlMargin R a b true for every R, a, b; `CatchUp.conjecture_of_controller_games`: C112 in the form ctlMargin (Icc 1 N) 0 0 true ≤ 0 ∧ 0 ≤ ctlMargin (Icc 1 N) 0 0 false for every even-total N gives C1 (through C37 (3), `conjecture_of_margin_le_one`). Deviation: stated in margins rather than values; `ctlMargin` and the Rust `Controller` of E39 are the same recursion (exact catch-up: a < b and a + x = b; one more number y then the opponent trails by y; nothing left: 0).
