# C112 The controller cannot win

For every N with N(N + 1)/2 even and X ∈ {player 1, player 2}: on I_N the controller X of G_X (C111) cannot win, i.e. value(G_X(I_N)) = 0 (a draw).

**Use.** I25's root claim; with C111 it gives C1 (Lean: the hypothesis of `conjecture_of_controller_games`, ctlMargin (Icc 1 N) 0 0 true ≤ 0 ∧ 0 ≤ ctlMargin (Icc 1 N) 0 0 false).
**Evidence.** [E39](../experiments/E39.md) (committed `Controller` engine): N ≤ 24, both controller games 0 at every even total, the controller +1 at every odd total. Ideator fresh05 (`scratch/ideator/fresh05/tiectl.rs`, own margin engine, self-checked against A278587's signs to N = 20 and C47): both controller games are 0 at every even-total N ≤ 22; at odd totals the controller wins by exactly 1 for every N ≤ 22 (the real game's irregular signs at N = 9, 10, 14, 18 disappear); all four fixed tie rules give 0 at even totals, N ≤ 18. In G_A the interval row is the parity bit for the controller at every d ≤ N − 1 from N = 16 (to N = 20). Which draws are tie-robust (both controller games 0), N ≤ 20: C1's roots 10 of 10; C92's families 79 of 87 (the 8 fragile at N = 11, 12, 15 only); C81 at j = 2, 749 of 782; C104, 362 of 406 (fragile mostly n ≤ 9); C86's band 189 of 243 (22 % fragile). So the band route (and C110, which contains it) needs the real tie rule; C1 and C92 from N = 16 do not, in the range tested.
Every opening (scratch `ctl.rs open`, N ≤ 20): from N = 17 every opening of {1..N} gives the controller exactly the parity bit, whoever controls (+1 at odd totals, 0 at even; at N = 19, 20 also every opening when the opponent controls), while the real game's openings at odd totals are irregular (N = 13, 17: one opening wins). Off the root it is not exact: on {1..N} minus ≤ 3 holes the controller beats the parity bit already at small d (N = 22: holes {8, 9, 10} at d = 10, N = 21: {7, 8, 9} at d = 5), while the real game is parity-trivial there at every d ≤ N from N = 21 (to N = 22, both parities: |m| equals the parity bit).
**Tried.** G_A is harsher off the root: the gap bound fails in G_A, its parity-regular region on blocks is smaller than the real game's draw region (n = 10, a = 5: off at d = 5, 6, 9), and the level law fails for the controller at a tie (713 of 16,383 sets within {1..14}) while it holds for the non-controller.
