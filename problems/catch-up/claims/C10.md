# C10 Reductions within C8

**Statement.** (a) For T = {1,2,3} ∪ E', E' a pair set above 3 with p pairs: V(T, p mod 2) ≥ neg V({2,3} ∪ E', (p + 1) mod 2). {2,3} ∪ E' is a pair set with p + 1 pairs at its g0, so C8 (E) for it gives V(T, g0) ≥ draw. (b) For a pair set E with p pairs, p even: if V(E ∖ P, 1) = draw for every pair P = {a, a+1} of E, then V(E, 0) ≤ draw.
**Proof.** `valueAux`'s early loss (the mover cannot catch up with everything left) never fires at the nodes used: each player concerned has enough left (in (b), E ∖ P ≠ ∅ as p ≥ 2). V depends only on the deficit, not on the base scores (a helper fact for Lean, also used by C9). (a) Pick 1. If p is even the gap is 0 and the turn ends with the mover ahead by 1: the opponent trails by 1 with {2,3} ∪ E'. If p is odd the gap is 1 and 1 catches up exactly: the opponent moves at gap 0 with {2,3} ∪ E'. By C6 the value is at least this pick's value. (b) By C6 it suffices that every pick has value ≤ draw. A pick at gap 0 ends the turn. If the mover takes a + 1, the opponent, behind by a + 1, takes a and is still behind by 1 with E ∖ P: that continuation is worth V(E ∖ P, 1) = draw to the opponent, so the opponent's value is ≥ draw and the pick's ≤ draw. If the mover takes a, the opponent takes a + 1 and leads by 1: the mover faces V(E ∖ P, 1) = draw, so the opponent's value is ≥ draw again.
**Evidence.** `pair_moves 28` (journal 2026-10-22: pair sets, first picks): in all 121,393 T sets ⊆ {1..28} pick 1 and pick 3 draw. Refuter (proof mode, 2026-10-22): SURVIVES; own DP and a literal port (agreeing with OEIS A278587): (a) on all T ⊆ {1..26} with equality for pick 1; (b) on all even-p E ⊆ {1..26}, and both partner inequalities on every R ⊆ {1..26} (419M checks). The analogue of (b) for p odd fails: after a bottom pick and the partner reply the mover trails by 2 with an even number of pairs, a mover win in 446 E sets ⊆ {1..28} (smallest {2,3,4,5} at gap 2: pick 4 wins), so the defender must sometimes refuse the partner (C44).
**Lean** (2026-11-04, verified: `lake build --wfail`, axioms propext, Classical.choice, Quot.sound): (b) in margin form, for any set, as `CatchUp.margin_tie_le_zero_of_partner` (`CatchUp/GameMargin.lean`).
