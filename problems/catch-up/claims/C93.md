# C93 Four consecutive numbers

**Statement.** For a ≥ 5 and d ≤ a + 3: V({a, a+1, a+2, a+3}, d) = draw for d ∈ {0, 2}, loss for d = 1 and 3 ≤ d ≤ a, win for a < d ≤ a + 3. In particular ({a..a+3}, 4) is a loss.
**Use.** The whole row of a 4-block (p = 2) up to deficit a + 3 at every height a ≥ 5. Settles I6's backlog item B18 (Lemma B's payoff: draw at debts 0 and 2, loss elsewhere below a). With C13 (V({a..a+3}, d) = R({0..3}, d) for a > d + 6) it gives C17 for p = 2, including the parity-forced loss at d = 1 that C17 leaves open; its d = 0, 2 entries are C11 and C86 (p = 2) at a ≥ 5. a ≥ 5 is sharp for d = 4: ({4..7}, 4) draws. The 3-subsets of {a..a+3} are C95 (d).
