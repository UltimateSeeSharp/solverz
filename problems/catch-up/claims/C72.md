# C72 Balancing in one turn

**Statement.** For some N ≥ 7 and some opening x of I_N, player 2 has a legal first turn taking a set A with 2·sum(A) = N(N+1)/2, its whole draw quota.
**Evidence.** Refuted. catch-up-research@b0853b4, `CatchUp/WholeTurn.lean`, `interval_no_one_turn_balance`: for every N ≥ 7 and every x ∈ I_N, no turn set A from (I_N ∖ {x}, x) has 2·sum(A) = sum(I_N ∖ {x}) + x; it follows from `no_balance_after_opening` (no balanced first turn once 4·max ≤ total) and 4N ≤ N(N+1)/2. An arithmetic statement for all N, so nothing to recheck with `position_value`.
Rules out: drawing defenses that settle the score in player 2's first turn; the quota must be carried across turns.
