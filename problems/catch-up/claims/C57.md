# C57 Sliding a quadruple above any drawn base

**Evidence.** (journal 2026-10-28: Const survives the refuter, exact to N = 20): B ∪ ({m+1..m+4} + c), m = max B, changes value with c for 9 of 255 bases B ⊆ {1..8} and 58 of 1,023 within {1..10}; B = {5,6,7} draws at c = 0, 1 and is a player-1 win from c = 2 ({5,6,7,10,11,12,13}, refuter, two engines). Rules out: a proof of C35 that does not use that the base is an interval {1..N−4}.
