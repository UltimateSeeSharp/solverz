# C28 Level law

**Statement.** R finite, t ∈ R (any rank), s any score. If `valueAux (R.erase t) s (s + t) false = .draw`, then `valueAux R s s b = .draw` for either opening flag b. Equivalently: at a level position, if some pick draws then no pick wins.
**Proof.** As in C26, the level mover's options are neg(A_y) with A_y = `valueAux (R.erase y) s (s + y) false`; y = t gives a draw. Let y ≠ t; the opponent answers t.
- y > t: the opponent stays strictly behind (s + t < s + y): its option is Q_y = `valueAux ((R − y) − t) (s + t) (s + y) false`, which is neg of the hypothesis game's option "pick y" (that pick ends its mover's turn, s + y ≥ s + t). As in C26, Q_y ≠ loss, A_y is not an early loss, so A_y ≠ loss.
- y < t: the opponent catches up (s + t ≥ s + y), so its option is neg(P_y) with P_y = `valueAux ((R − y) − t) (s + y) (s + t) false`, the level mover now trailing by t − y. In the hypothesis game the mover's pick y leaves it strictly behind (s + y < s + t), so that option is P_y itself, on the same set ((R − t) − y = (R − y) − t) with the same scores. The hypothesis node is not empty (it holds y) and not an early loss (that would be a loss), so it is the best of its options; it is a draw, so P_y ≠ win (C6), so the opponent's option neg(P_y) ≠ loss. A_y is not empty (it holds t) and not an early loss (its numbers sum to at least t > y). So A_y ≠ loss.
- In both cases neg(A_y) ≠ win; with the draw at y = t the value is a draw (C6). Minimality of t is never used; C26 is the special case.
**Consequence.** value({1..N}) = draw iff some opening t of {1..N} leaves player 2 drawing at deficit t: one good opening suffices, at any rank. The refuter's observation on C26 (all R ⊆ {0..15}: whenever a level option draws, none wins) is the s = 0 case of the "Equivalently" form.
**Stronger form (same argument, not used).** For y ≠ t the opponent after y does at least as well as the negation of the hypothesis node after t; so at a level position at most one pick wins, and if one does, every other pick loses (refuter: 0 violations over all R ⊆ {0..17}; it fails at trailing nodes, e.g. R = {1, 3} behind by 2).
