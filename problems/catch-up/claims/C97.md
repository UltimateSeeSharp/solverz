# C97 Crossing deficits

**Statement.** Turns as in C96. (a) Let b ∉ C and V(C, b + c) = loss. At (C ∪ {b}, c), after any turn Y of the mover with b ∉ Y, the opponent's pick b loses if sum(Y) = b + c and wins otherwise; so for sum(Y) ≠ b + c the opponent wins at (C ∖ Y ∪ {b}, sum(Y) − c). Also: a loss at (C, w) stays a loss at (C ∖ Y, w − sum(Y)) for every Y ⊆ C with sum(Y) < w; from a loss every turn leaves the opponent a win. (b) If V(S, d) = loss and some turn Y at (S, e) has sum(Y) < d and d + e = 2·sum(Y), then V(S, e) ≠ loss; e.g. if 2, 3 ∈ S, V(S, 7) and V(S, 3) are not both losses (Y = {2, 3}). (c) If a ∈ S, every number of S is ≥ l and V(S, l + 2a) = loss: at (S, l) every pick x ∉ {a, l + a} loses; if moreover l + a ∉ S, V(S, l) ≠ loss iff V(S ∖ {a}, a − l) ≠ win. Instance l = 2, a = 3, 5 ∉ S, from V(S, 8) = loss.
**Use.** Tools relating values of one set at two deficits, beside C77's exact sums. (a): with a losing shadow (C, b + c), the mover at (C ∪ {b}, c) can be safe only with a turn that takes b or sums to b + c. (b): rows V(S, ·) are not monotone (C51), but two losses d > e cannot be bridged by a turn at e summing to their midpoint (the same Y keeps the turn at d and ends it at e, reaching one position as both a loss and a win). (c): a loss 2a above l fixes the safe entries at l. catch-up-research uses them in their exact-sum defenses (AlternativeSumDefense, NearMaximumDefense, ComplementaryPairDefense) and the Q_N(6) analysis (ConsecutiveGuard*, RootUpper*), none in our claims yet.
