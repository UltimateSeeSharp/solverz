# C63 Peel below height 1

**Statement.** Let 0 < c < 1 and k ≥ 2, the lex game of C62. (a) k even: if C62 holds at (k − 1, c + 1), it holds at (k, c). (b) k odd: if C62 holds at (k − 1, c + 1), the mover at (k, c) does not lose. Corollary: C36's fam a for p even (c = 1/2) follows from C62 at (p − 1, 3/2), the odd bases from 3 with the mover trailing by ε.
**Proof.** Write the numbers as c + i (+ ε for the upper element), i < k; let P1 be the mover.
- *Mirror after a stray answer.* Suppose P1 has opened one bottom element (c or c + ε) and P2, trailing by about c, answers with an element of offset j ≥ 1 (one pick ends its turn, since c + j > c). P1 now trails by j + uε, u ∈ {0, 1}. It takes the other bottom element (still behind: j − c > 0 as c < 1) and then the twin of P2's pick, which leaves P1 ahead by 2c + τε (τ an integer), with only intact pairs of offset ≥ 1 left. From there P1 answers every pick y of P2 with y's twin: y = c + j' > 2c + τε (c < 1) ends P2's turn ahead by j' − c + O(ε), and the twin puts P1 ahead by 2c + τ'ε again. When the numbers run out P1 is ahead by 2c + O(ε) > 0: P2 loses.
- *(a)* The canonical position is level (deficit 0). P1 opens t = c. P2 trails by c, so each of its options is one pick: the twin c + ε leaves P1 to move trailing by ε on the pairs at c + 1, …, c + k − 1, which is C62 at (k − 1, c + 1) with k − 1 odd, a draw; every other pick loses (mirror). So after t the opponent's node is a draw, and C28 (level law, verified) gives the draw at (k, c); C28 is about `valueAux` on integers, and for rational c = a/g the lex game equals `valueAux` on {K(a + gi), K(a + gi) + 1} once K ≥ k + 2: every comparison in play is between two sums of numbers, whose integer parts differ by a multiple of K and whose ε-counts (at most k upper elements and the starting ε) by at most k + 1 < K, so it agrees with the lex comparison; irrational c is a rational of the same cell (C62's Use).
- *(b)* P1 trails by ε and opens c + ε, leading by c. P2's twin c ties exactly, the turn passes, and P1 moves at deficit 0 on C62's (k − 1, c + 1) with k − 1 even, a draw; every other pick loses (mirror). So P1 does not lose.
- *Corollary.* Halving, fam a with base {1, 3, …, 2p − 1} is (p, 1/2); p even is case (a), and (p − 1, 3/2) is the base {3, 5, …, 2p − 1}.
