# C107 Neighbour bound (NB)

For the mover trailing by d ≥ 1 at (S, d) and x ∈ S with x ≥ d, let opt(x) = −m(S ∖ {x}, x − d), the margin of the single pick x (C33's margin game). (i) If x + 1 ∈ S: opt(x) ≤ m(S ∖ {x, x+1}, d + 1). (ii) If x − 1 ∈ S: opt(x) ≤ m(S ∖ {x−1, x}, d − 1).

**Use.** One step of a no-win argument at a trailing position (I23, I24); the general-deficit form of C74's neighbour jump and of catch-up-research's lower-ray interior reduction; C28 is its d = 0 limit.
**Evidence.** Ideator fresh04c run 7: every S ⊆ {1..11}, d ≤ 12, 61,440 cases, no violation.
**Tried.** As a chain (blocks minus j adjacent pairs at deficit d₀ + j never a mover win) it fails at j = 2 (ideator run 9: N = 12, ({1, 6..12}, 2) is a mover win).
**Proof.** After x the opponent trails by x − d and answers the neighbour, which catches up (x + 1 ≥ x − d; x − 1 ≥ x − d as d ≥ 1) and leads by d + 1, resp. d − 1, on S ∖ {x, x±1}; so m(S ∖ {x}, x − d) ≥ −m(S ∖ {x, x±1}, d ± 1). Verified (2026-11-05; `lake build --wfail`, standard axioms): `CatchUp.neg_margin_erase_le_of_succ` (i) and `CatchUp.neg_margin_erase_le_of_pred` (ii) (`CatchUp/Neighbour.lean`), in scores: the mover has a, the opponent b = a + d. Deviation: the inequality holds for every x (the left side is the option of x only when x ≥ d), and (i) needs only a ≤ b.
