**Statement.** For N ≥ 7 and every first-pair pick a ∈ [3, N] from ({3..N}, 1), the position (S, L) = ([3, N] ∖ {a}, a − 1), the protected player leading by L, meets the budget envelope: some B ⊆ S and D ≥ 0 with |S ∖ B| ≤ 2D, D + sum(B) ≤ L and L + D + sum(B) ≤ x for every x ∈ S ∖ B.
**Evidence.** Refuted. catch-up-research@b0853b4, `CatchUp/TurnReserveInitialization.lean` (CU-L031), `budget_envelope_initialization_iff`: for N ≥ 7, a ∈ [3, N], the envelope holds iff N = 7 and a = 3. Their certified finding about all N, with no single game position, so nothing to recheck with `position_value`. The envelope is necessary for their mate-reply reserve invariant (fixed unequal pairs with gap sum D, a pool B), whose preservation is argued on paper only.
