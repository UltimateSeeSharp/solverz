# C92 The lower ray, canonical exact-deficit form

**Statement.** For N ≥ 4: if ({3..N}, 1) draws, ({5..N}, 4) draws and ({3..N} ∖ {b − 1, b}, 2) draws for every 4 ≤ b ≤ N, then V(I_N) = draw.
**Use.** For 3 ≤ b ≤ N the exact pick b − 1 takes Q_N(b) = (I_N ∖ {1, b}, b − 1) to the tied R_b = {2..N} ∖ {b − 1, b} (C74), so Q_N(b) ≠ loss once R_b is no mover win, and by C28 one drawn opening makes R_b a draw. The canonical openings: 4 for R_3 = {4..N}, leaving ({5..N}, 4); 2 for R_b, b ≥ 4, leaving ({3..N} ∖ {b − 1, b}, 2). With C82 this replaces C74's interior and boundary hypotheses (C81 at j = 2, C83) by one family, {1..N} minus {1, 2} and one more adjacent pair: C81's base {1..N}, j = 2, at d = 2 (and d = 4 for the pair {3, 4}). Per N only (C91 is the successor-pick analogue).
