# C108 Tied one-hole blocks in the rounds regime, upper holes

For k ≥ 2 and o with k − 1 ≤ o ≤ 2k, o ≡ k (mod 2), O = {0..2k} ∖ {o}: the rounds game R(O, 0) is a draw for either first mover; hence V({a + x : x ∈ O}, 0) = draw for every a > sum(O) = k(2k + 1) − o (C13), i.e. C105 at those heights for the hole h = a + o.

**Use.** C105's rounds half for the holes in the upper half; the first height-free-type statement with a hole proved below no threshold in p other than C13's.
**Proof.** Rounds game as in C13/C23 (Z's lead s, q = |T|/2). By C23 (Lean `depth_class_roundsMargin`), from a K-state Z playing AM+T ends with margin ≥ −1; the total sum(O) is even (o ≡ k), so every final margin is even (C13's parity, `even_roundsMargin_add`) and ≥ −1 means ≥ 0. Apply it with Z = the first mover and with Z = the other player: both get ≥ 0, so R(O, 0) = draw.
- *Z moves first* (s = 0, q = k). If o ≤ 2k − 2, t1 = 2k, t2 = 2k − 1 and the only hole is o (o = 0 is no hole), D_Z(O) = 2k − 1 − o ≤ k = s + q iff o ≥ k − 1. If o ≥ 2k − 1, no hole lies below t2, D_Z = 0. So the start is in KZ.
- *Y moves first* (s = 0). Y picks i; AM+T answers the largest number left, as no exact tie is possible (it would need i = the largest left after i, but i is not left).
  - i is not the maximum M of O: Z takes M, s′ = M − i ≥ 1, Y moves, T′ = O ∖ {i, M}, q′ = k − 1. For o ≤ 2k − 2 (M = 2k) the holes of T′ are at most o and i, each below t1′ ≤ 2k − 1, so D_Y(T′) ≤ (2k − 1 − o) + (2k − 1 − i), and s′ + q′ = 2k − i + k − 1 ≥ D_Y(T′) iff o ≥ k − 1; for o = 2k − 1 (t1′ ≤ 2k − 2, o not a hole) and o = 2k (M = 2k − 1) only i can be a hole, D_Y(T′) ≤ 2k − 2 − i < s′ + q′. s′ ≥ 1 holds. So (T′, s′) ∈ KY when q′ ≥ 2.
  - i = M: Z takes the next largest M′, s′ = M′ − M < 0, Z moves. o ≤ 2k − 2: s′ = −1, T′ = {0..2k − 2} ∖ {o}, t2′ = 2k − 3, D_Z(T′) = 2k − 3 − o if 0 < o < 2k − 3, else 0; −1 + (k − 1) ≥ 2k − 3 − o iff o ≥ k − 1. o = 2k − 1 (then k odd, k ≥ 3): s′ = −2, T′ = {0..2k − 3}, D_Z = 0 ≤ k − 3. o = 2k: s′ = −1, T′ = {0..2k − 3}, D_Z = 0 ≤ k − 2. So (T′, s′) ∈ KZ when q′ ≥ 2.
  - k = 2 (q′ = 1, o ∈ {2, 4}): R(O, 0) = draw for both first movers by direct evaluation (`scratch/a19/rb1.rs`).
**Evidence.** `scratch/a19/rb1.rs`, `rb2.rs` (k ≤ 8): AM+T's guarantee is 0 in both roles at every o ≥ k − 1 of the parity, and its play enters K after 0 rounds (Z first) and 1 round (Y first) there, as the proof says. Below (o < k − 1) AM+T still draws except o = 1, k odd, Y first; with exact play once 4 numbers are left it draws every hole of the parity, k ≤ 7 (C105).
