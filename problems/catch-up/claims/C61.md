# C61 Exits of smallest-first play are non-losing (EX)

For c = 0.3 and every N ≥ 12 with 1 + … + N even: on {1..N}, in either role, let D take the smallest number left (whole turns, until it catches up; at a tie the smallest) while min R < c·span, E playing freely. At every exit, the first position with min R ≥ c·span, D's value is ≥ 0, and no game ends before an exit.

**Evidence.** Ideator (2026-10-30, `scratch/ideator/pair30/deepexit3.rs`, `deepexit4.rs`, one engine, exact values over the exits' universe): holds for every even-total N from 12 to 32 (up to 1,275 exits per N); fails at N = 7, 8, 11; c = 0.35 fails at N = 24, c = 0.4 at 19, 20, 24, c = 0.2 holds at 24. Mine (`scratch/a13/exits.rs`, own table, exits at turn starts): agrees for N ≤ 16 (c = 0.3 fails at 7, 8, 11; c = 0.35 also fails at 12, 16).
