# C105 Tied odd blocks minus one number draw (B1)

For every k ≥ 2, height a ≥ 1, B = {a..a+2k} and h ∈ B with h − a ≡ k (mod 2) (equivalently sum(B) − h even): V(B ∖ {h}, 0) = draw.

**Use.** Root claim of I24, with C106. At a = 1, h = 2k + 1 it is C1 for N = 2k ≡ 0 mod 4 ({1..N} = {1..N+1} ∖ {N+1}). Height-free: unlike C86 and C85, it holds in the rounds regime too, where it is a finite one-pick game per k (C13): the tied mover on {0..2k} ∖ {o}.
**Evidence.** Ideator fresh04c (own solver `margin.py`): every odd block of size ≥ 5 inside {1..15}, every hole of the parity; sizes 5, 7, 9 at every a ≤ 24; sizes 11, 13 at a ≤ 10; size 9 at a = 40, size 11 at a = 60 (rounds regime); no non-draw. Mine (`scratch/a19/mg.rs`, margins): k ≤ 8 at every a ≤ 40, every hole of either parity: |m| ≤ 1, so the off-parity holes are ±1.
**Tried.** No fixed answer rule (h − 1, h + 1, min, max, a + b − h) draws every case (ideator run 6); C23's depth class needs s ≥ 1 with a hole, so even the rounds half needs a new class. After the tied mover's pick x the position ({B ∖ {h, x}}, x) can be far from a draw (margins up to +7 for k ≤ 6, `mg.rs b2h`), so |m| ≤ 1 does not pass to the two-hole positions.
**Proof.** Open.
