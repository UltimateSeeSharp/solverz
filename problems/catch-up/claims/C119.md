# C119 The maximal opening is not a win for the answerer

For every N ≥ 13 with N(N + 1)/2 even: on {1..N−1}, the mover trailing by N cannot win (V({1..N−1}, N) ≠ win; with C77 (b″) it is a draw).

**Use.** I33. One one-sided statement from one start gives C1: the opening N draws (C77 (b″) for no loss, C119 for no win) and the level law (C28) makes the root a draw.
