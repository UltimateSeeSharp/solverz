# C31 One-sided roots

**Statement.** (a) If for every N ≥ 4 with 1 + … + N even, `valueAux ((Icc 1 N).erase 1) 0 1 false ≠ .win` and `valueAux ((Icc 1 N).erase 2) 0 2 false ≠ .win`, then C1. (b) If for every such N, `valueAux (Icc 2 N) 0 1 false ≠ .win` and `valueAux (Icc 3 N) 1 2 false ≠ .win`, then C1.
**Proof.** N ≤ 3: N = 0 is empty, N = 1, 2 have odd totals, N = 3 is C30 with the picks 1 and 3 ({2, 3} at deficit 1 and {1, 2} at deficit 3 are not mover wins, by direct evaluation). (a) For N ≥ 4: C30 with t = 1, t' = 2 at the opening (opening flag via `valueAux_true_eq_false`). (b) For N ≥ 4: by C29 it suffices that V({2..N}, 1) = draw. The first hypothesis gives ≠ win. For ≠ loss: the mover's pick 2 on {2..N} (trailing by 1) ends its turn ahead by 1, so that option is neg(`valueAux (Icc 3 N) 1 2 false`), which is ≠ loss by the second hypothesis. N = 3 for C29 directly ({2, 3} at deficit 1 is a draw).
**Meaning.** Both forms ask only "the player to move does not win" from two starts: a strategy proof needs one role, the leader's defense, not two. Data (ideator): (a) holds for every even-total N ≤ 35 (every opening draws for N ≥ 12; N = 4, 7, 8, 11 by table); (b) holds for N ≤ 24.
