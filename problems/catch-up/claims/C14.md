# C14 Greedy bound

T a set with |T| even, played out in |T|/2 rounds of one Z pick and one Y pick each, the order in each round and Y's picks chosen adaptively. If Z always takes the largest number left, Z's total − Y's total (picks from T only) is ≥ −c_td(T), c_td(T) = (t1 − t2) + (t3 − t4) + … for t1 > t2 > …

**Proof.** Induction on \|T\|; it suffices that each round satisfies (Z's pick − Y's pick) ≥ c_td(T') − c_td(T), T' = T minus the two picks. Sort t1 > t2 > …; c_td is the alternating sum t1 − t2 + t3 − …. If Y takes t1 (picking first), Z takes t2: both sides equal t2 − t1. Otherwise Z takes t1 and Y takes some t_j, j ≥ 2, in either order (this includes Y picking first a non-maximal number). Removing t1 and t_j flips the signs of t2..t_{j−1} and keeps those after t_j; with A = −t2 + t3 − … ± t_{j−1}: c_td(T) = t1 + A ± t_j + tail and c_td(T') = −A + tail. The required inequality t1 − t_j ≥ −2A − t1 ∓ t_j becomes 2[(t1 − t2) + (t3 − t4) + … + (t_{j−2} − t_{j−1})] ≥ 0 for j odd and 2[(t1 − t2) + (t3 − t4) + … + (t_{j−1} − t_j)] ≥ 0 for j even. Both hold.
**Lean (2026-10-26).** `altSum T` = max T − altSum (T minus its max), the alternating sum by recursion. `greedyWorst T`: the worst case over Y's picks and the order, each round either Z takes t1 and Y some j (either order; same totals) or Y takes t1 first and Z the next largest; odd T gets a convention (Z takes the last number), unused. `neg_altSum_le_greedyWorst`: −altSum T ≤ greedyWorst T for even T. Deviation: the per-round inequality is proved through one joint lemma, x ≤ altSum U + altSum (U − x) ≤ 2·max U − x for x ∈ U (induction removing the maximum), instead of the sign bookkeeping above; it gives both directions, \|c(T) − c(T')\| ≤ t1 − t_j (`altSum_round`), so C18's part (a) is formalized as well.
