# C110 The one-hole band

For every k ≥ 3, height a ≥ 1, h ∈ B = {a..a+2k} and 0 ≤ d ≤ k − 1 with d + sum(B) − h even: V(B ∖ {h}, d) = draw. (k = 2: only d = 0, which is C105.)

**Use.** I24. C105 is its entry d = 0. With the hole at an end (h = a or h = a + 2k) B ∖ {h} is a block of 2k numbers, so C110 contains C86's band without its diagonal d = p (where C86 has its exception and its flips, C47, C88). It contains both of C27's families: {1..N} = {1..N+1} ∖ {N+1} at d = 0 (N ≡ 0 mod 4, k = N/2) and ({2..N}, 1) = ({1..N} ∖ {1}, 1) (N ≡ 3 mod 4, k = (N − 1)/2 ≥ 3); so C110 ⇒ C1 (N ≤ 12 by `conjecture_le_twelve`). Unlike C105 it is not real-height invariant: its even-block entries flip between integer heights (C88).
**Evidence.** [E38](../experiments/E38.md) (committed, two engines): k = 3..9 at every a ≤ 2(2k + 1) and a = (2k + 1)², every hole, no non-draw at d ≤ k − 1 (9,473 entries), |m| ≤ 1 there; the band ends exactly at d = k. Scratch (`scratch/a19/mg.rs band1`, every hole, heights 1..40 and the rounds regime): parity-trivial (|m| ≤ 1) at every d ≤ k − 1 for k = 3..7, first failure at d = k (k = 3: a = 7, offset 2, m = −2; k = 5..7 likewise at offset 2 near a = n); k = 2 fails already at d = 1 (a = 2, offset 3, m = 2).
