# C49 C23's depth class on {1..N}

**Evidence.** (journal 2026-10-26: the depth class does not transplant to low sets): with q = half the numbers left, player 2's first turn start after any opening x ≥ 2 has deficit x > q − D_Z, for every even-total N ≤ 20 (q rounded either way). Rules out: K's inequality "deficit ≤ q − D_Z(numbers left)" as I2's class at height 1; the deficit is measured in numbers, not offsets, so a transplant needs a rescaled deficit.
