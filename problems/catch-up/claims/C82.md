# C82 Second start draws

For every N ≥ 4 with N(N + 1)/2 even: V({3..N}, 1) = draw (Q_N(2), the mover after opening 1 and the reply 2).

**Use.** C74's first hypothesis; its ≠ win half is C31 (b)'s second hypothesis. For N ≡ 0 mod 4 it is C12 at height 3 (p = (N − 2)/2 odd, deficit 1).
**Evidence.** [E15](../experiments/E15.md): a two-pick defender draws it in both roles for every even-total N from 4 to 28. C74's evidence (`scratch/a14/ray.rs`): a draw for every even-total N from 11 to 24. Inside the draw region of the pair-deleted family (C81's two-sided census: {1..N} minus the pair {1, 2}, j = 1, d = 1). Verified in our build (catch-up-research): ({3..7}, 1) and ({3..8}, 1) draw (`FirstPairDescent.base_seven`, `base_eight`, `CatchUp/FirstPairDescentObstruction.lean`); ({3..11}, 1) and ({3..15}, 1) are no loss (`DeficitTwo.interval_eleven_nonwin` with the reduction below; `FivePair.first_pair_fifteen_nonloss`).
**Tried.** catch-up-research's mate-reply program for V({4..N}, 2) ≠ win (DeficitTwo, FivePair, AnchorFive, SevenPairTest, FourOrphan, NearRepair, ReserveTriangle; in our build): answer each pick with its partner on the even-start pairs {4, 5}, {6, 7}, …. Pair sets at small deficits have sparse doubling exceptions (C94: (4, 7, 14) at d = 3, (6, 10, 20, 40) at d = 4), pair-count-uniform invariants fail (C98; C45), and the repairs hold only at reached nodes (C45). It closes N = 11 and 15 only (`DeficitTwo.interval_eleven_nonwin`, `FivePair.interval_fifteen_nonwin`).
**Proof.** Open. catch-up-research: `Increasing.first_pair_draw_iff` (C78) reduces it to two increasing-turn checks, per N. ≠ loss half ⇐ V({4..N}, 2) ≠ win, by the pick 3 (`DeficitTwo.first_pair_nonloss_of_interval_nonwin`, N ≥ 3, verified). ≠ win half (CU-L008, report only): every first pick x leaves ({3..N} ∖ {x}, x − 1), which is no loss if ({4..N}, 2) ≠ loss (x = 3) and the tied {3..N} ∖ {x − 1, x} ≠ win for 4 ≤ x ≤ N − 2 (exact pick x − 1); x = N is C77 (a); CU-L007 (report only) excludes x = N − 1. So C82 follows from ({4..N}, 2) = draw, that tied family and x = N − 1.
