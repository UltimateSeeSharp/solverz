# C89 Pair-deleted sets never lose below half their size (NLB*)

For k ≥ 1, R = {k..N} minus j disjoint adjacent pairs (any placement), |R| even, 4j ≤ |R|, and 0 ≤ d < min(k, |R|/2) with d + sum(R) even: V(R, d) ≠ loss.

**Use.** Root claim of I18; widens C81 (base 2, deficit 1) to every base and every deficit below |R|/2; the one-sided companion of C87. Reach on the route: C74's interior sets ({2..N} minus two adjacent pairs, d = 1) have N − 5 elements, so C89 covers them only for N ≡ 3 (mod 4); for N ≡ 0 (mod 4) they are odd-size, where C89 claims nothing (and odd sizes do lose at some d).
**Evidence.** Ideator (2026-11-04, `scratch/ideator/fresh04/nlb.rs`, run 2, unchecked): every N ≤ 18, every k, every placement of j ≤ 4 pairs: no mover loss. Sharp: losses sit exactly at d = |R|/2 (C20's boundary, e.g. ({6, 7, 10, 11}, 2)) or on odd |R| (({4, 5, 8, 9, 10}, 2)). Mover wins exist, each with a run of odd length (({3, 4, 5, 8, 9, 10}, 1)), so the two-sided form needs aligned deletions (C87).
