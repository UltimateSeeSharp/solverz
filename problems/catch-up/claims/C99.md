# C99 Dense intervals never lose (CU-L003)

**Statement.** For every N ≥ 9, H_N (their `DenseThreeHoleNonloss N`): every (S, d) with S ⊆ I_N, at most 3 holes (|I_N ∖ S| ≤ 3), 0 ≤ d ≤ N, d ≤ sum(S) and even effective total d + sum(S) (the draw parity, C3) has V(S, d) ≠ loss. (d ≤ sum(S) holds by itself from N = 6.) False at every N = 4..8 (1, 4, 5, 2, 1 losses, e.g. ({2,4,6}, 2) at N = 6); at N = 8 the only loss is ({1,5,6,7,8}, 5) (every pick L).

**Use.** Root of their August main route (catch-up-research, CU-L003; audit item X1): C100 gives C1 from it. It does not reach C74's interior sets, which have 5 holes in I_N (their caveat, `results/structural-descent.md`).
**Evidence.** [E21](../experiments/E21.md) (ours, one engine): no loss in 189,922 positions, N = 9..25; all draws from N = 21. Theirs, historical, not replayed: native Lean certificates for N = 9..25 (`ofReduceBool`, outside our Trust rule); a C++ audit N = 9..21 (624,308 roots) and N = 22 (20,636); ≤ 2 holes holds from N = 6 to 21; ≤ k holes holds at N ≥ 3k for (N, k) = (9,3), (12,4), (15,5), (16,5), (18,6), (21,7); the smallest number is always a non-losing pick for N = 12..22 (3 exceptions at N = 11, e.g. the tied set with holes {1, 6, 9}; 28 at N = 9).
Partial Lean, verified in our build (ported 2026-11-04, standard axioms). Each starts from a hypothetical loss; none proves H_N at any N:
- `CatchUp.DenseLossFrontier.loss_frontier` (any h = |I_N ∖ S|, 2h + 1 ≤ d ≤ N, even effective total; for h ≤ 3 only d ≥ 7): a loss gives an upper descent (B ⊆ S, |B| ≤ h + 1, sum(B) = d, an opening w > d of the tied S ∖ B that wins) or a lower obstruction (B the maximal exact block, max B < w < d, d − w < h, no subset of S sums to d − w, opening w of S ∖ B wins, (S ∖ {w}, d − w) = L, value(S ∖ B) = W, ≥ 4 numbers left in (S ∖ B) ∖ {w}).
- `CatchUp.DenseLossGeneral`: `loss_dichotomy` (same range): an upper descent with |B| ≤ 2, or some t < h, t ∉ S, d − t ∈ S with (S ∖ {d − t}, t) = L; `exact_deficit_nonloss`: S ⊆ I_d, ≤ h holes, 2h + 1 ≤ d, {1..h−1} ⊆ S ⇒ (S, d) ≠ loss (the stratum d = N); `after_max_opening_nonloss`: opening N of I_N never wins (N ≥ 3; C77 (b″)).
- `CatchUp.dense_three_hole_exact_complement_priority`, `CatchUp.dense_loss_forces_upper_residual_or_small_prefix_blocked_loss` (`DenseLossInjection.lean`; ≤ 3 holes, 7 ≤ d ≤ N): d ∈ S or one of {1, d−1}, {2, d−2}, {3, d−3} ⊆ S; a loss gives an upper witness (|B| ≤ 2, winning opening w with max B < w, d < w ≤ N) or, with d ∉ S, one of three small-deficit losses: (S ∖ {d−1}, 1) with 1 ∉ S; (S ∖ {d−2}, 2) with 1, 2 ∉ S; (S ∖ {1, d−2}, 1) with 2, d−1 ∉ S.
- `CatchUp.even_dense_loss_forces_upper_or_odd_prefix_endpoint` (`PrefixBlockedDenseEndpoints.lean`; adds an even-total N): a loss gives the upper witness, or ({2..N} ∖ {d−1, d, h}, 1) = L for an odd hole h ∉ {1, d}, or d odd and ({3..N} ∖ {d−2, d−1, d}, 1) = L. These deficit-1 families have 4 and 5 holes in I_N, outside E21 and C81; no census yet.
- Top stratum (S ⊆ I_d, i.e. d = N): `CatchUp.TwoHoleTopBoundary.loss_forces_smaller_even_win` (d ≥ 5, ≤ 2 holes, even effective total): a loss forces S = {2..d−1} and V(I_{d−2}) = W with I_{d−2} even-total, so C1 at d − 2 excludes it (`nonloss_of_smaller_nonwin`); `CatchUp.ThreeHoleTopBoundary.loss_forces_smaller_even_win` (d ≥ 7, ≤ 3 holes, 1 ∈ S): S = I_{d−2} ∖ {2} and V(I_{d−3}) = W, I_{d−3} even-total.
- Tools: `CatchUp.IncompleteSubsumMass.missing_target_mass`: r distinct positive numbers missing a subset sum t ≤ their total have r(r+1) + 2r ≤ 2·total + 2 (dense sets hit every sum); `CatchUp.effective_total_add_twice_deficit_after_exact_block_opening`, `…_strictly_decreases_…`, `exact_block_opening_child_catchable_iff` (`EffectiveTotalDescent.lean`): taking an exact block (sum d), then opening w, lowers d + sum(S) by exactly 2d; the child is catchable iff 2d + 2w ≤ d + sum(S). A rank, not an invariant: holes grow along it.
**Tried.** Verified obstructions to proof steps (sets with 4 or more holes, not counterexamples to C99):
- Entering through the exact block: `CatchUp.DenseBlockEntryObstruction` ({4,5,6,7,8,10,11} at d = 9 meets the lower branch of `loss_frontier`): the continuing state ({4,5,7,8,10,11}, 3) draws, both numbers of the maximal block {4, 5} lose, only 8 is safe (`first_pick_values`, `unique_safe_first_pick`). Recheck `position_value 3 4 5 7 8 10 11` → D (8:D, rest L).
- Gap successors stay safe: `GapSuccessorObstruction.dense_even_maximal_gap_counterexample`: ({4,5,8,9,10,11,12}, 13) (blocks {4,9}, {5,8}, no subset sums to 3) wins, but its gap pick 10 leaves ({4,5,8,9,11,12}, 3) = L. Recheck → W, 10:L.
- Gap closing without density: `FullGapDensityObstruction.full_gap_counterexample_without_density`: ({3,4,7,8}, 10) loses, its only block {3,7}, opening 8 of {4,8} wins and the gap pick 8 loses; `FullGapDensityFamily.odd_family_obstruction`: the same for ({a, a+1, 2a+1, 2a+2}, 3a+1), every odd a ≥ 3 (there 2h + 1 > d). Rechecks a = 3, 5, 7 → L.
- Stopped by them (Aug 2026, historical): a hole-count hierarchy (continuing picks add holes, up to ⌊N/3⌋), pure exact-sum iteration, one scalar effective-total descent. Their induction on N: C100.
