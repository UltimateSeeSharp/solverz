# C116 The change number is the largest one below the deficit

C114 with the two-number turns narrowed: in C1 and in C110's band the player holding the draw keeps it in both roles with turns that are one number (any that ends the turn), or the largest number left below its deficit followed by any number that ends the turn.

**Use.** I27: the defender's strategy is one choice per turn (a number, or the second number after a fixed change number), not a choice of turn shape.
**Evidence.** [E42](../experiments/E42.md) (committed `ShortTurns::with_largest_change`): C110 k = 3..7 at every height ≤ 2(2k + 1), C1 at every even-total N ≤ 20, C92's families at N = 11..20, both roles: no draw lost.
Scratch (`scratch/a19/short/shape.rs`, shape 1, strict budget): {1..N} at every even-total N ≤ 16, both roles; C110 k = 3, 4, 5, every hole, every d ≤ k − 1 of the parity, heights a ≤ 2(2k + 1) (140, 324, 594 positions): no draw lost. C92's three families (({3..N}, 1), ({5..N}, 4), {3..N} minus each adjacent pair at 2) at N = 11, 12, 15, 16, both roles: no draw lost.
**Tried.** Special to these near-complete families: on every draw of a low dense set inside {1..14} (min S ≤ |S|/2, d ≤ |S| − 1) the shaped player loses 11,308 of 40,407 (`scratch/a19/uni/lowdense.rs`), e.g. ({1, 2, 4, 5, 6}, 0). The other end of the turn is not fixed: taking the smallest number that ends the turn as the second number loses C1 from N = 4 and most C110 positions (shapes 2 and 3 of `shape.rs`); two-number turns opening with the smallest number left lose C1 from N = 4 (C114 Tried).
**Proof.** Open.
