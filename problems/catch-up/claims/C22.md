# C22 Strategy transfer

O with |O| even, offsets ≥ 0, a > max O, g ≥ 0; σ a strategy for Z (either role) in R(O, g) such that every round start reached in a play consistent with σ has debt < a. In the real game on {a + o : o ∈ O} at gap g, Z plays σ with the picks numbered from the start, picks 2k − 1 and 2k forming round k. Then every real-game play against σ is a rounds-game play against σ with the same picks and the same outcome; so Z secures in V at least σ's worst outcome in R

**Proof.** C13's proof, read one round at a time; it uses only that the round's start debt d is below a and that max O < a. The mover's pick a + i ends its turn (a + i > d), so it is round k's first pick. The other trails by a + i − d < 2a; its pick a + j catches up iff j ≥ i − d (an exact tie, δ = 0, passes the turn back to the round's mover, as R's tie rule says), and that is round k's second pick. Otherwise it still trails by i − j − d ≤ max O < a; `valueAux` has no turn flag, so this node is a turn start, and its next pick is round k + 1's first, with the other as mover at debt −δ = i − j − d. The early-loss rule fires only at a round's answerer with one number left and j < i − d, which R scores as a loss too; with nothing left the trailing player loses in both. So, while the round starts reached have debt < a, the real game and R have the same options, the same next round start and the same terminal outcomes, and σ (applied to picks 2k − 1, 2k) is defined at every real-game node of these plays. Outcomes agree play by play; final margins agree except at early-loss endings, where the outcome is still the same loss. ∎
**Evidence.** Part (b) of C21's proof as first written; refuter proof mode (2026-10-26, with C21): checked by hand and per node (650,774 nodes, see C21).
