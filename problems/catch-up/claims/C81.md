# C81 Dense pair deletions never lose

**Statement.** For N with N(N + 1)/2 even and S = {2..N} minus j disjoint pairs {y − 1, y}, j even and 4j ≤ N: V(S, 1) ≠ loss.
**Use.** j = 2 is C74's interior hypothesis (R_b minus a second pair); the general j is the family that hypothesis falls into when answered pair by pair.
**Evidence.** Mine (2026-10-30, `scratch/a14/pairdel.rs`, one table over {1..24}): no loss for j ≤ 6 at every even-total N ≤ 24 (up to 12,376 sets per N), beyond the bound 4j ≤ N; the first losses come at j = 8 with 6 or 7 numbers left (C65's {6, 11, 14, 15, 18, 23} at N = 23; {6, 13, 14, 17, 20, 21, 24} at N = 24, `position_value` → L). N = 27, 28 (`pairdel2.rs`, outcome table over {1..28} packed 2 bits per entry, V({1..N}, 0) as E1 for every N ≤ 28): no loss for j ≤ 8 (up to 75,582 sets per N); the first losses at j = 10, 6 at N = 27 (e.g. {8, 13, 18, 19, 22, 27}) and 22 at N = 28 (e.g. {12, 13, 18, 19, 20, 23, 28}), `position_value` → L for both. Every loss so far leaves 6 or 7 numbers. At j = 2 the smallest number is a non-losing pick from N = 16 (C74).
**Tried.** Smallest-first by induction on j: after the pick 2 the opponent faces {3..N} minus pairs at deficit 1, which must be no mover win; that companion fails (`scratch/a14/pairdel3.rs`, N ≤ 28): no win for j ≤ 2 from N = 16 and j ≤ 4 at N = 27, 28, but from j = 4 (N ≤ 24) or 6 (N = 27, 28) the mover wins when the deleted pairs sit at the bottom and leave a high block, e.g. {11..23} at N = 23 (odd high blocks are mover wins, C12). So a proof of C81 must change its answer once the rest is high, as I8's phase split does.
