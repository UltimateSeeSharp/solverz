# C94 Pair sets at small deficits

**Statement.** A pair is {x, x+1}; pairs are separated when each start is ≥ 2 above the previous one; starts a < b < c < e < f; even-start means every start is even (catch-up-research's "canonical"; not our aligned pairs, which start ≡ k mod 2). "No win" = V ≠ win.
(a) Separated, any parity: two pairs, a ≥ 3, at d = 2: no win. Two pairs, a ≥ 4, at d = 4: no win unless the starts are (4, 7) or (4, 8). Three pairs, a ≥ 4, at d = 3: a win iff the starts are (4, 7, 14). Four pairs, a ≥ 4, at d = 2: no win; so ({a..a+7}, 2) is no win. For N ≥ 3, V({4..N}, 2) ≠ win ⇒ V({3..N}, 1) ≠ loss (the pick 3); ({4..11}, 2) is no win.
(b) Even-start, a ≥ 6: two pairs at d = 6 win iff the starts are (6, 10) or (6, 12); three pairs at d = 5 win iff (6, 10, 12) or (6, 10, 20).
(c) Even-start, a ≥ 6: four pairs at d = 4 win iff the starts are (6, 10, 20, 40).
(d) Five separated pairs, a ≥ 4, at d = 3: an upper pick u + 1 never wins (the reply u leaves four pairs at d = 2, (a)), so S wins iff some lower pick x ∈ {a, b, c, e, f} leaves (S ∖ {x}, x − 3) a loss. Even-start: no win if a ≥ 6; for a ≥ 4 the pick a never wins (b, c, e, f even, any a), so a win needs a = 4 and a winning lower pick x ∈ {b, c, e, f}.
(e) With the anchor {4, 5}: {4, 5} and three even-start pairs, starts 6 ≤ b < c < e, none equal to 8, at d = 4: no win. Endgames beside 5 (even starts ≥ 6, separated): ({5, b, b+1}, 10) with b ≠ 8, ({5, b, b+1}, 8), ({5, b, b+1, c, c+1}, 9) with b, c ≠ 8, ({5, b, b+1, c, c+1}, 7), ({5, b, b+1, c, c+1, e, e+1}, 8) with none 8, and ({5, 7, b, b+1, c, c+1}, 2) for any b ≥ 10, c ≥ b + 2: no win.
(f) Even-start five pairs, a ≥ 4, at d = 3: no win when 8 is no start; a win needs a = 4, a start at 8 and a winning lower pick x ∈ {b, c, e, f}, x ≠ 8.
(g) [4, 15] minus one even-start pair, at d = 1 or 3: no win. [4, 15] minus two: draw at d = 0, no win at d = 2, no win at d = 4 except {4, 5, 8, 9, 10, 11, 14, 15} (minus {6, 7}, {12, 13}). ([4, 15], 2) is no win, so ([3, 15], 1) ≠ loss.
