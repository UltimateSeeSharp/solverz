# C75 Every opening draws iff every pair is neutral

**Statement.** For N ≥ 3: every opening of I_N draws (V(I_N ∖ {a}, a) = draw for every a) iff every ordered pair a ≠ b of I_N is neutral: after opening a, player 2's pick b is worth a draw to it.
**Use.** Reformulates C2 as a statement about two-pick continuations. At the largest opening a winning reply has a companion (C90). Same module: if winning replies lower some rank and every opening has a neutral partner, V(S) = draw (`value_eq_draw_of_ranked_reply_graph`); for I_N, every pair state (I_N ∖ {a, b}, b − a), a < b, no loss plus one neutral pair at opening 1 give V(I_N) = draw (`value_Icc_eq_draw_of_all_pair_deletion_nonloss_and_neutral_at_one`). A pair state is no loss once the tied I_N ∖ {a, b − a, b} is no win (b ≠ 2a; for b = 2a the pick a + 1 leaves a deficit-1 residual); with ({3..N}, 1) = draw these give V(I_N) = draw (`value_Icc_eq_draw_of_additive_residuals`, `CatchUp/Earlier/AdditiveTripleReduction.lean`).
