# C80 Score shift

**Statement.** For s ≤ t and any c: `valueAux R (s + c) (t + c) false = valueAux R s t false`; a non-opening value depends only on the deficit t − s.
**Use.** Moves our Lean results stated at fixed scores to any scores; we quantify over the score instead (C28, C30).
