# C88 Only the diagonal flips across heights (BANDSTEP)

For blocks {h..h+2p−1} at real heights h (C32's deformation), across every breakpoint h* ∈ [1, 2p − 1] the band entries with d < p (d ≡ p mod 2) keep their value; only d = p may change.

**Use.** I17's mechanism: a descent in the height from C24's a ≥ 2p − 1 in which the off-diagonal band is invariant and only the diagonal entry needs its own argument.
**Mechanism (from C32).** Across a breakpoint h* the tree changes only at near-tie nodes (a player ε behind keeps picking, or ε ahead hands over: the same (R, ε) with the roles swapped), so a root value can change only through near-tie positions that are not draws. C88 is then: no non-draw near-tie position decides an off-diagonal band root. The band's lowest entry d = p mod 2 is C32 itself: a draw for every real h ≥ 1/2 (p ≤ 8, refuter's `param.rs`), so for it no breakpoint above 1/2 changes anything.
**Evidence.** Refuted (2026-11-04).
