**Statement.** If `valueAux (Icc 2 N) 0 1 false = .draw` for every N ≥ 2 with 1 + … + N even, then C1.
**Proof.** N = 0: no numbers, a draw. N = 1: odd total, nothing to prove. N ≥ 2: value({1..N}) = `valueAux (Icc 1 N) 0 0 false` (`valueAux_true_eq_false`), and C26 with R = {1..N}, t = 1, s = 0 needs exactly `valueAux (Icc 2 N) 0 1 false = .draw`, since {1..N} − {1} = {2..N}.
