# C34 Far blocks are a margin tolerance

**Statement.** S a finite set of positive integers, E_k = k 4-blocks {x_i..x_i+3}, x_1 > 2·sum(S) + 10, each later block above twice the total below it plus 10. Then m(S ∪ E_k, g) = sign(m)·max(|m| − 2k, |m| mod 2), m = m(S, g), i.e. ψ applied k times, ψ(X) = X − 2·sign(X) for |X| ≥ 2 and X for |X| ≤ 1. With C33: if sum(S) + g is even, V(S ∪ E_k, g) = draw iff |m(S, g)| ≤ 2k (MT); if odd, V(S ∪ E_k, g) = sign(m(S, g)).
**Position form (k = 1).** m(S ∪ Q, d) = ψ(m(S, d)) for every S below a far quadruple Q and every d ≤ max S; for a far pair it fails exactly where the low game ends level (who moves next matters), the quadruple's own row being 0 at a tie. ψ is monotone and odd on each parity class, so playing Q last commutes with optimal play: the content is that opening Q early never helps. Route to a proof: induction on |S|; the S-picks give ψ(m(S, d)) exactly; an early opening of Q leaves a far pair after the reply, which needs the pair's turn-dependent form.
**Use.** FB (k = 1): a drawn set stays drawn with a far 4-block on top. I6's Lemma B (the low game with the top quadruple as final payoff) is C34 for {1..N−4}, so it follows from C1(N − 4).
