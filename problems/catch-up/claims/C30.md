# C30 Two-token lemma

**Statement.** R finite, s any score, t ≠ y in R. If `valueAux (R.erase t) s (s + t) false ≠ .win` (after the level mover's t the opponent cannot win), then `valueAux (R.erase y) s (s + y) false ≠ .loss` (after its y the opponent does not lose). Corollary: if two distinct picks t, t' each leave the opponent unable to win, the level position is a draw.
**Proof.** C28's copying argument with the weaker hypothesis. Let H = `valueAux (R.erase t) s (s + t) false` (opponent to move, trailing by t) and A_y the opponent's node after y.
- If H is an early loss (s + sum(R − t) < s + t), then y ≤ sum(R − t) < t. A_y is not an early loss (it holds t > y), so it reaches its options; its option t catches up and ends the opponent's turn, after which the level mover trails by t − y with everything left summing to sum(R − t) − y < t − y: a loss for it (early loss, or the terminal rule if nothing is left). So A_y = win, in particular ≠ loss.
- Otherwise H holds y, so it is nonempty and the best of its options, none of which is a win (H ≠ win, C6). y < t: as in C28, the opponent's t at A_y reaches the level mover at the very call P_y that is H's option "pick y" (same set, same scores), P_y ≠ win, so A_y ≠ loss. y > t: the opponent's t keeps it behind and reaches Q_y, whose negation is H's option "pick y", so Q_y ≠ loss; A_y is not an early loss (else Q_y would be a loss), so A_y ≠ loss.
- Corollary: each option of the level mover is neg(A_y). With t and t' both "opponent cannot win", every option y ≠ t is ≠ win (by t) and the option t is ≠ win (by t', since t ≠ t'); the option t is ≠ loss (hypothesis), so it is a draw; the value is a draw (C6). In outcome terms (win 1, draw 0, loss −1), applying the lemma to (t, y) and to (y, t) gives m_y + m_t ≤ 0 for the level mover's options y ≠ t: at most one pick wins, and then every other pick loses.
