# C83 Lower-ray boundary

For every N ≥ 11 with N(N + 1)/2 even, 3 ≤ b ≤ N, R_b = {2..N} ∖ {b − 1, b} and y ∈ R_b ∩ {2, b − 2, b + 1, N}: V(R_b ∖ {y}, y) ≠ loss (opening y of the tied R_b does not win).

**Use.** C74's boundary hypothesis; with C82 and C81 at j = 2 (its interior hypothesis) it gives C1 for N ≥ 11 (N ≤ 8 by E1).
**Evidence.** [E25](../experiments/E25.md): no loss for every even-total N from 11 to 28; at N = 27, 28 every first turn of the defender is safe in every case. C74's evidence (`scratch/a14/ray.rs`): holds for every even-total N from 11 to 24 (32 to 84 cases per N); fails only at N = 4, 7, 8. The tied R_b is itself a draw in every case checked (C81's two-sided census: {2..N} minus one pair at d = 0, N ≤ 28), which gives every y at once. Independent: CU-L014's census (C81's Evidence) contains C83's cases for N = 20..28 (m = 1, h = 3; y = N via M = N + 1, h = 4, N ≤ 27).
**Tried.** C77 by hand (2026-11-04). (b′) needs y ≥ max(R_b ∖ {y}), so only y = N, b = N − 1 qualifies. Elsewhere (b) leaves conditions "opening w of a tied set does not win" for every w above the block, the same kind of statement as C83, and they branch: y = N, b ≤ N − 2 needs a block without N − 1 (1 is absent), e.g. {2, N − 2}, leaving w = N − 1, then {3, N − 4} leaving N − 3, then {4, N − 7} leaving N − 6 and N − 5; y = b + 1 < N leaves every w in {b + 2..N}. E25 lists which turns are safe, to see whether a pattern prunes the branching. Why the recursion cannot close by itself: on a set with minimum L, a block summing to w has largest element at most w − L (two elements) or less (more), so the conditions cover every w′ in the top L − 1 positions; each step raises the minimum by one and adds a hole near the top, so the family of "opening w does not win" statements it needs grows in L, in its holes and in its window without bound. A proof needs a family closed under play (as C81's draw region would be), not exact-sum steps alone.
**Proof.** Open. Partial, verified in our build: y = N, b = N − 1 (S = {2..N − 3}, d = N) for every N ≥ 7 is `interval_tail_value_ne_loss_of_deficit_eq_top_add_three` (`CatchUp/BoCowgill/LowerRayEndpoints.lean`) at m = N − 3: V({2..m}, m + 3) ≠ loss for m ≥ 4, via the block {3, m} ∋ max S (C77 (b′)); it is the last step of C73 (b)'s proof.
