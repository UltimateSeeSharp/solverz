# C83 Lower-ray boundary

For every N ≥ 11 with N(N + 1)/2 even, 3 ≤ b ≤ N, R_b = {2..N} ∖ {b − 1, b} and y ∈ R_b ∩ {2, b − 2, b + 1, N}: V(R_b ∖ {y}, y) ≠ loss (opening y of the tied R_b does not win).

**Use.** C74's boundary hypothesis; with C82 and C81 at j = 2 (its interior hypothesis) it gives C1 for N ≥ 11 (N ≤ 8 by E1).
**Evidence.** C74's evidence (`scratch/a14/ray.rs`): holds for every even-total N from 11 to 24 (32 to 84 cases per N); fails only at N = 4, 7, 8. The tied R_b is itself a draw in every case checked (C81's two-sided census: {2..N} minus one pair at d = 0, N ≤ 28), which gives every y at once.
**Tried.** C77 by hand (2026-11-04). (b′) needs y ≥ max(R_b ∖ {y}), so only y = N, b = N − 1 qualifies. Elsewhere (b) leaves conditions "opening w of a tied set does not win" for every w above the block, the same kind of statement as C83, and they branch: y = N, b ≤ N − 2 needs a block without N − 1 (1 is absent), e.g. {2, N − 2}, leaving w = N − 1, then {3, N − 4} leaving N − 3, then {4, N − 7} leaving N − 6 and N − 5; y = b + 1 < N leaves every w in {b + 2..N}. E25 lists which turns are safe, to see whether a pattern prunes the branching.
**Proof.** Open. Partial: y = N, b = N − 1 (S = {2..N − 3}, d = N): A = {3, N − 3} contains max S and sums to N, so (b′) gives V ≠ loss for every N ≥ 7 (needs C77 (b) in our build).
