# C36 Twins with a tie-break (TD's first cell)

**Statement.** For p ≥ 1 and B = {1, 3, …, 2p − 1} (fam a) or {2, 4, …, 2p} (fam b): the multiset of pairs {x, x + ε}, x ∈ B, with 0 < ε < 1/(p + 1) and the mover trailing by ε·(p mod 2) (not the opening), is a draw. Every such ε gives the same game, the lexicographic one (integer parts first, then the count of upper elements). At ε = 0 it is exact twins, a draw by peeling the top twins (journal 2026-10-22).
**Use.** The base of I11: C1 for N = 2p (fam a, p even) and N = 2p + 1 (fam b, p odd, via C29) follows from C36 and TD's crossings of the breakpoints r/s, s ≤ p + 1, up to t = 1.
**Evidence.** Mine (2026-10-28, `scratch/a11/twineps.rs`): draw for fam a p ≤ 11, fam b p ≤ 10. Refuter (2026-10-28, `scratch/refuter/td/tdlex.rs`, exact limit game): draws at TD's own deficit; the limit game is not unit-token Catch-Up at other deficits; completing the opponent's broken pair loses from p = 3 (P1) and p = 4 (P2), and P1 must open low. Not all bases: 12 of about 6,500 sets B ⊆ {1..14} with |B| ≤ 6 fail, all with a sparse high core ({7, 8, 10, 11, 12}).
**Generalized** by C62 (every height c; C36 is c = 1/2, 1).
**Failing bases (mine, 2026-10-30, `scratch/a13/lexfail.rs`).** Every B ⊆ {1..16}, |B| ≤ 6 (14,876 bases): none fails with |B| ≤ 4; the 60 failures are 13 five-element cores, sparse and high (min/span 0.78–1.5, e.g. {7, 8, 10, 11, 12}, {9, 10, 12, 14, 16}; the mover loses 2 upper elements), and 47 extensions of a core by one small number (the mover wins 2 at a tie). C36 holds for nearly every base, so TD's bases need only avoid such cores; whether play from them can reach one is open. The draw does not track Catch-Up on the base: B = {1, 3} draws here though m({1, 3}, 0) = +2 (`lexbase.rs`).
**Tried.** Twins do not cancel below the top, not even at a tie: m({1, 1, 2}, 0) = 0, m({2}, 0) = 2 (`set_margin`; ideator's candidate, `scratch/a13/twincancel.rs`: 255 of 3,480 cases over {1..6}, d = 0). A local top-pair rule: m(S ⊎ {KM, KM + 1}, d) is not a function of m(S, d + j), |j| ≤ 3, on bases {1..3}, {1..4} (`scratch/a13/lexpair.rs`, 2026-10-30).
