# C104 The low column of blocks (EB)

For every n ≥ 6, height 1 ≤ a ≤ n/2 and deficit 0 ≤ d ≤ n − 1 with d + sum(B) even, B = {a..a+n−1} (n odd or even): V(B, d) = draw.

**Use.** Root claim of I23. C1 is the entry (n, a, d) = (N, 1, 0) for N ≡ 0 mod 4 and (N − 1, 2, 1) for N ≡ 3 mod 4 (C27, Lean `conjecture_of_two_families`); C82 is (N − 2, 3, 1). C86 (BAND) is the slice d ≤ n/2 of the even-n rows at every height; this claim is the whole column d ≤ n − 1 at low heights only, both parities of n. False above the low heights: at a > d + sum of offsets the block is the rounds game, where the mover at d > n/2 loses by d − n/2 (C20), and between (n/2 < a < n − 1) the entries are irregular (n = 12, d = 8: a draw for a ≤ 7, +2 at a = 8, 9, a draw at 10, 11, −2 from 12). Excluded small exceptions: (4, 2, 2) (C47) and (5, 1, 3) ({1..5} trailing by 3 wins by 2 with the turn {1, 4}).
**Evidence.** [E36](../experiments/E36.md) (committed, two engines): n = 6..20 at every a ≤ n/2, no non-draw, |m| ≤ 1 at every d ≤ n − 1; the column runs on to d = a + n − 1 except four small ends, none from n = 12. Ideator fresh04c (own solver `margin.py`, checked against A278587 for N ≤ 14): even n ≤ 12 at a ≤ n + 1, n = 14 at a ≤ 8; odd n ≤ 11 at a ≤ n + 1, n = 13 at a ≤ 6; no violation for n ≥ 6. With it: |m(B, d)| ≤ 1 at every d ≤ n − 1 in the same region (the off-parity entries are ±1), and at a = 1, 2 the draws usually go on to d = n + 1.
