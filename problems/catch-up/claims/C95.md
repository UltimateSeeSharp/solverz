# C95 Three-number endgames

**Statement.** (a) For 0 < a < b < c < 2a and d < 2a: V({a, b, c}, d) = win iff d < a + b − c, or c − a ≤ d < a + c − b, or b < d < b + c − a; V ≠ loss iff d ≤ a + b − c, or c − a ≤ d ≤ a + c − b, or b < d ≤ b + c − a. So a draw at the right ends that no win range covers, a loss elsewhere.
(b) For a ≥ 2, b ≥ a + 2 (an orphan a below the pair {b, b+1}): V({a, b, b+1}, a + 1) = draw; V({a, b, b+1}, a − 1) = draw iff b ≥ 2a − 1, and a mover win for b ≤ 2a − 2.
(c) For x < a < b, 0 < d ≤ a, r = b − a: V({x, a, b}, d) ≠ win if x + r ≤ d, or if d ≤ x ≤ d + r, r ≤ x + d and x + d < b.
(d) For a ≥ 5, d ≤ a + 3 (the 3-subsets of C93's {a..a+3}, instances of (a)): {a+1, a+2, a+3} draws at d = a + 2 and wins elsewhere; {a, a+2, a+3} draws at a + 1, loses at a + 2, wins elsewhere; {a, a+1, a+3} always wins; {a, a+1, a+2} draws at a + 1 and a + 3, wins elsewhere.
