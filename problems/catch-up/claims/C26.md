# C26 Token lemma

**Statement.** R a finite set of naturals, t = min R, s any score. If the mover trailing by t on R − {t} draws, `valueAux (R.erase t) s (s + t) false = .draw`, then the level mover on R draws: `valueAux R s s b = .draw` for b = true (opening) and b = false.
**Proof.** At scores (s, s) any single pick ends the turn, so with either flag the mover's options are, for each x ∈ R, neg(A_x) with A_x = `valueAux (R.erase x) s (s + x) false` (the opponent's node).
- x = t: A_t is the hypothesis node, a draw, so this option is a draw.
- x > t: the opponent may take t first. Since t < x it stays strictly behind, so that option of A_x is Q_x = `valueAux ((R.erase x).erase t) (s + t) (s + x) false`. In the hypothesis game the mover (score s, opponent s + t) may pick x > t (x ∈ R − {t}), which ends its turn; that option is neg(Q_x) on the same set ((R − x) − t = (R − t) − x) with the same scores. The hypothesis node is not empty (it holds x) and not an early loss (that would be a loss, not a draw), so its value is the best of its options. The hypothesis game is a draw, so by C6 none of its options is a win: neg(Q_x) ≠ win, so Q_x ≠ loss. If the early-loss rule fired at A_x (s + sum(R − x) < s + x), then (s + t) + sum(R − x − t) < s + x too, so Q_x = loss (or, if R − x − t is empty, the scores s + t < s + x give loss); hence the rule does not fire and A_x = best of its options ⊇ {Q_x}, so A_x ≠ loss by C6, and neg(A_x) ≠ win.
- So some option is a draw and none is a win: the value is a draw (C6). No "depends only on the deficit" lemma is needed, since Q_x has the same scores in both games.
**Evidence.** Ideator (2026-10-26, unchecked, `scratch/ideator/fresh/` and `scratch/ideator/descent/token.rs`): every S ⊆ {2..18} with V(S, 1) = draw (58,811 sets) gives value({1} ∪ S) = draw, and the tie-position form holds in all 107,840 cases within {1..18}. On {1..N} opening 1 draws for every even-total N ≤ 35 (data), so the converse holds there.
