# C18 Catch-up potential step

T finite, |T| even, t1 > t2 > … the numbers left, c = c_td(T), c'' = c_td(T − {t1, t2}) (0 if |T| = 2). Z plays AM+T: first picker the largest left; second picker the largest left unless that gives an exact tie (margin 0 after the round, so Y keeps the move), then the second largest left (at |T| = 2 the only one). Γ = min(s + c, 0) if Z moves, max(s − c, 0) if Y moves, Γ = s at T = ∅. After one round Γ' ≥ Γ for every Y pick, unless Y moves with s < (t1 − t2) − c''; then exactly Y's pick t1 lowers it, to Γ − ((t1 − t2) − c'' − s)

**Proof.** Write c' = c_td(T') for the set T' left after the round; c_td(∅) = 0, so Γ = s at ∅ agrees with both formulas. (a) Z moves (s ≤ 0) and takes t1; Y takes t_j. Removing t1 and t_j flips the signs of t2..t_{j−1} in the alternating sum, so c − c' = t1 + 2A ± t_j with A = −t2 + t3 − … ± t_{j−1}, and t1 − t_j ≥ c − c' reduces to (t2 − t3) + (t4 − t5) + … ≥ 0 (up to t_{j−1} for j even, up to t_j for j odd; equality at j = 2). So s' + c' ≥ s + c. This shares C14's sign bookkeeping but is the other direction: C14 says s − c never decreases. If Z moves next (s' ≤ 0, including a tie, which keeps Z's move), Γ' = min(s' + c', 0) ≥ Γ; if Y moves next, Γ' ≥ 0 ≥ Γ. (b) Y moves (s ≥ 0). If Y takes t_i with i ≥ 2, Z's largest is t1 > t_i, so s' = s + t1 − t_i > 0: no exception, Y moves next, and C14's per-round inequality (Z took the largest) gives s' − c' ≥ s − c, so Γ' ≥ Γ. If Y takes t1 and Z answers t2: s' = s − (t1 − t2) and c' = c'' = c − (t1 − t2). If s' > 0, Γ' = max(s' − c'', 0) = Γ; s' = 0 happens only at \|T\| = 2 (for \|T\| ≥ 4 the exception applies), where the game ends at 0 = Γ. If s' < 0, Γ = 0 (s < t1 − t2 ≤ c) and Γ' = min(s − (t1 − t2) + c'', 0), which is ≥ 0 iff s ≥ (t1 − t2) − c''. If s = t1 − t2 and \|T\| ≥ 4, AM+T answers t3 instead: s' = t3 − t2 < 0 and c' = c_td({t2, t4, t5, …}) ≥ t2 − t4 > t2 − t3, so Γ' = 0 = Γ. Converse: for \|T\| ≥ 4, c'' > 0, so s < (t1 − t2) − c'' excludes s = t1 − t2; AM+T answers t2 and Γ drops by (t1 − t2) − c'' − s. At \|T\| = 2 the game ends: Y takes t1, Z takes t2, final s − (t1 − t2). ∎
