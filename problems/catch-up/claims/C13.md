# C13 High sets are the rounds game

For O a finite set of non-negative integers with |O| even, g ≥ 0 and a > g + sum(O): V({a + o : o ∈ O}, g) = R(O, g), where V(S, g) = `valueAux S s (s+g) false` (any s; the mover trails by g, not the opening) and R is the rounds game (section)

**Rounds game.** For O with \|O\| even: R(O, d), the mover trailing by d ≥ 0. A round: the mover picks i ∈ O, then the other picks j ∈ O − {i}; the mover's signed debt becomes δ = d + j − i; if δ ≥ 0 the mover moves first in the next round at debt δ (a tie keeps the mover), else the other does, at debt −δ. O empty: draw at debt 0, else loss. Equivalently: one pick each per round, the player behind picks first (at a tie, the previous first picker), higher total wins.
**V.** V(S, g) = `valueAux S s (s+g) false` for any s: the mover's value trailing by g at a turn start. It depends only on the deficit, and a mid-turn node equals a turn start with the same scores (`valueAux` has no turn flag, only the opening flag). value(S) = V(S, 0), since at 0–0 every pick catches up, so the opening flag changes nothing.
**Proof.** Claim, by induction on \|O'\| (\|O'\| even): V({a + o : o ∈ O'}, d) = R(O', d) whenever d + sum(O') < a. For O' = ∅ both are draw at d = 0 and loss otherwise. Otherwise the mover trails by d < a, so any pick a + i ends its turn; the other then trails by a + i − d. Its pick a + j catches up iff j ≥ i − d; then the first mover trails by δ = d + j − i ≥ 0 at a turn start. If j < i − d, the other still trails by i − j − d = −δ, with 0 < −δ < a: if numbers remain, its next pick ends its turn, and that pick is the first of the next round with the other as mover at debt −δ; if none remain (O' − {i, j} = ∅), the empty-set rule, or the early-loss rule one step earlier, scores a loss for the other, as R does at positive debt. In both cases O'' = O' − {i, j} satisfies the hypothesis: d + j − i + sum(O'') = d + sum(O') − 2i < a for δ ≥ 0, and i − j − d + sum(O'') = sum(O') − d − 2j < a for δ < 0. Same player to move, same options, same terminal outcomes; best is the maximum by C6, so the values agree. The early-loss rule fires nowhere else: a mover at debt < a with a number left catches up with one pick, and the other, trailing by a + i − d < 2a, catches up with two whenever two remain; c = 1 nodes always have an odd count left because \|O'\| is even.
