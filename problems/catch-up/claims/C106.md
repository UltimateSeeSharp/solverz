# C106 Tied blocks minus one number never lose (B2)

For every n ≥ 4, height a ≥ 1, B = {a..a+n−1} and h ∈ B with sum(B) − h even: V(B ∖ {h}, 0) ≠ loss; at a = 1, V({1..n} ∖ {h}, 0) = draw.

**Use.** I24, with C105. Its a = 1 half alone contains C1: {1..N} = {1..N+1} ∖ {N+1}, for N ≡ 0 and 3 mod 4. On odd n it is the no-loss half of C105. The tied mover does win on even n at a ≥ 2, by up to large margins (ideator run 4: 34 wins inside {1..13}, e.g. {4, 6, 7, 8, 9}).
**Evidence.** [E35](../experiments/E35.md) (committed, two engines): n ≤ 19 at every a ≤ 2n and a = n², no loss; at a = 1 no win. Ideator fresh04c (`margin.py`, run 4, run 14): every block inside {1..13}, holes of the draw parity: 0 losses; at a = 1 no win for n ≤ 15. Off the draw parity the tied mover can lose by 1 (e.g. {2..8}), which the parity forces anyway.
