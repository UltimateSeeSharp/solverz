# C90 Maximum companion

**Statement.** S finite, c ∈ S with c ≥ every number of S, and for every x ∈ S with x < c the position P(x) = (S ∖ {x, c}, c − x) is nonempty and catchable (its sum ≥ c − x). If after the opening c the reply a wins for its player (an edge c → a of the reply graph: a ∈ S, a ≠ c, V(P(a)) = win, since a < c keeps the turn), then some b ∈ S with b ≠ a, b < c is a winning reply to c too, and the cross picks win: b in P(a), a in P(b). So a winning reply to the maximum opening is never the only one.
**Use.** C75's reply graph: every opening of I_N draws iff it has no edge (a pair that is not neutral is an edge one way, `reply_edge_iff_reverse_loss`); C90 says the maximum vertex has out-degree 0 or ≥ 2. The hypotheses hold for S = I_N, N ≥ 3 (sum P(x) = N(N+1)/2 − x − N ≥ N − x). Catchability follows from the edge (sum S ≥ 2c), so C90 holds for every finite S with maximum c, as CU-L011 claimed (refuter, 2026-11-05). The maximum is needed: S = {1,3,5,6,10,13}, opening 3, has the single winning reply 1 (`position_value 3 1 5 6 10 13`). The shifted (deficit-1) graph has no such companion, ({3..7}, 1): the maximum 7 has the single winning reply 3 (`ShiftedReplyCycle.interval_seven_no_max_companion`, C67's module), as the deficits there differ by one and the cross-pick identity fails.
**Proof.** Verified in our build, ported from catch-up-research@b0853b4 (2026-11-04; `lake build --wfail`, standard axioms): `CatchUp.reply_edge_from_max_has_companion`, `CatchUp.reply_edge_from_max_not_unique` (`CatchUp/BoCowgill/ReplyMaximumCompanion.lean`; the edge is `ReplyEdge`, `CatchUp/BoCowgill/Earlier/ReplyDigraphReduction.lean`). P(a) wins and is catchable, so some pick b wins there; b in P(a) and a in P(b) have the same outcome (`pair_deletion_move_outcome_cross`, both picks below c), so P(b) wins: c → b.
