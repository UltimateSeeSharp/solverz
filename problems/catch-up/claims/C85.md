# C85 Partially collapsed blocks draw (PBT)

For all c ≥ 1, p ≥ 1 and t ∈ {0, 1}^p: V(⊎_{i<p} {c + 2i, c + 2i + t_i}, |t| mod 2) = draw.

**Use.** t = 1…1 is C12 (TI): C1 at c = 1 with p even, C29's family at c = 2 with p odd; t = 0 is twins at height c. At c = 1 it is the part of C84 that lowers only even elements. Root claim of I16.
**Evidence.** E22: every t, every c ≤ 2p, p ≤ 10 (committed engine, checked against `Solver`). Ideator (2026-10-30, `scratch/ideator/fresh30b/pbt.rs`, unchecked): every t for p ≤ 9 at c = 1, 2; p ≤ 8 at c = 3; p ≤ 7 at c ∈ {4, 5, 6, 8, 10, 13}. The rounds game (C13's high limit) draws at the parity debt for every t, p ≤ 8 (`roundsnear.rs`).
**Tried.** No known strategy proves the high base: always-max, AM+T, twin answer + AM+T, Hyb2 (e.g. offsets {0, 1, 2, 2, 4, 4}, Z trailing by 1: −2) and a token-first opening each lose by ≥ 2 from p = 3 (`amnear.rs`, `amtwin.rs`, `hyb2near.rs`, `hyb2tok.rs`). Composition of pairs played bottom-up (C9) fails on 197 of 1,024 entries.
- Why Hyb2 fails (by hand, 2026-11-04, rounds game on {0, 1, 2, 2, 4, 4}, Z first at debt 1): Z's max pick 4 is a twin; Y answers 1, breaking {0, 1}, and leads the round start ({0, 2, 2, 4}, Y trailing by 2) with c = 4 > 2 (pre-switch). Y takes 4: Z's answer 2 leaves Y first on {0, 2} at debt 0 (Y takes 2, wins by 2); answer 0 leaves Z first on {2, 2} trailing by 2. Z's token opening 1 draws (Y's answers 0, 2, 4 all lead to 0). So the first pick, not the answer, is what breaks; E24 tests bumped-top first picks.
- Paper fact: Hyb2's post-switch guarantee carries over to multisets. With the bottom-up matching of a sorted multiset, removing a matched pair {i, π(i)} gives c(R − {i, π(i)}) = c(R) − |π(i) − i| (twins have gap 0), so at a Y start with e ≥ c(R) the partner answer keeps e' − c' ≥ e − c ≥ 0 and Y keeps the move: Z ≥ draw from every post start. Only pre-switch play and Z's first picks are open.
- Twins are not neutral in the rounds game (by hand, 2026-11-04): R({0, 3}, 1) = +2 for the mover (3, then 0), but R({0, 1, 1, 3}, 1) = 0 (the answer 1 to 3 hands the move back at debt 1 on {0, 1}). So no proof can delete twin pairs and reduce to the full block; a simulation "play the twin when the opponent takes one" also breaks at ties, where the round's first picker keeps the move and the simulated and real first pickers differ.
**Proof.** Open.
