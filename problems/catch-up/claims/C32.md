# C32 TI at real heights

**Statement.** B(h, p) = {h + o : 0 ≤ o < 2p}, h real, the mover trailing by g0 = p mod 2 (same units). Draw for every h > 0 (p even), every h ≥ 1/2 (p ≥ 3 odd), every h ≥ 1 (p = 1). Scaling by 1/δ is an isomorphism, so equivalently an arithmetic progression of 2p terms, first term a, difference δ, the mover trailing by g0·δ, is a draw for a/δ in the same ranges. At h = 1 and p even this is C1 for N = 2p; at h = 2, p odd, it is C27's second family.
**Why the parameter helps.** Every comparison in the game is (difference of pick counts)·h + integer, with the count difference at most 2p, so the game's combinatorial type is constant between consecutive fractions r/s with s ≤ 2p, and constant for h > p(2p − 1) + 1 (C13). At a generic h a draw is a balanced split: both players take p numbers, with offset sums equal (p even) or differing by the debt. Crossing a breakpoint h* changes the tree only at near-tie nodes: a player ε behind continues, or ε ahead hands the move over; both are the same position (R, ε) with the roles swapped, so the root can change only through near-tie positions that are not draws (at generic h, every position with |R| odd is one).
**Evidence.**
- Refuter, claim mode (2026-10-26, `scratch/refuter/tir/`): an exact parametric solver (`param.rs`, h symbolic; checked against {1..N} at h = 1 for N ≤ 14 and against an integer solver on 31k random comparisons) gives the value as a function of h on all of (0, ∞): draw everywhere for p = 2, 4, 6, 8; for p = 1 a mover win on (0, 1), draw from 1; for p = 3, 5, 7 a mover win on (0, 1/2), draw from 1/2. Integer engines agree at every breakpoint and cell midpoint up to h = p(2p−1) + 3 for p ≤ 7. p = 9: draw at all breakpoints in [1/2, 3] and the grid j/19 on [9/19, 20]; p = 10: draws on (0, 1] exhaustively and the grid j/23 on (0, 3].
- The odd threshold falls below 1/2 for larger p (refuter): 2/5 at p = 9 (mover win exactly on (0, 2/5) among 613 points on (0, 3]), 1/3 at p = 11 (one engine). So for p odd the statement claims only h ≥ 1/2; the true threshold θ_p ≤ 1/2 is not part of it.
- Ideator (`scratch/ideator/fresh/genbreak.rs`, `genscan.rs`): every breakpoint and a grid hitting every cell on (0, 2p + 1] for p ≤ 7; p = 8 breakpoints (mine, `scratch/b45/`): all 1,360 draws.
- Openings (refuter, exact): the second smallest opening draws on (0, ∞) for p = 2, (0, 8) for p = 4, (0, 11) for p = 6; the smallest on (0, 2), (0, 6), (0, 9). With C30 (two drawing picks at a tie), "the opponent cannot win after the two smallest openings" would give C32 for p even below those heights.
- Literature: nothing on Catch-Up over arithmetic progressions or real numbers (refuter, four searches; mine, two).
