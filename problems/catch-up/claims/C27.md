# C27 Two block families suffice

**Statement.** If V({1..2p}, 0) = draw for every even p ≥ 2 and V({2..2p+1}, 1) = draw for every odd p ≥ 1, read at score s = 0 (`valueAux … 0 0 false`, `valueAux … 0 1 false`), then C1.
**Proof.** 1 + … + N is even iff N ≡ 0 or 3 mod 4. N ≡ 0 mod 4, N = 2p with p even: value({1..N}) = V({1..N}, 0) (the opening flag changes nothing at a level start, `valueAux_true_eq_false`), the first family. N ≡ 3 mod 4, N = 2p + 1 with p odd: {2..N} is the block a = 2 with 2p numbers, its g0 = p mod 2 = 1, a draw by the second family; C26 with R = {1..N}, t = 1, s = 0 gives value({1..N}) = draw. (N = 0 is trivial.)
