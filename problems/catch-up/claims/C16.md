# C16 High pair sets draw

For E a pair set with p pairs and a > 1 + sum(E): V({a + o : o ∈ E}, p mod 2) = draw. Gives C12 for blocks with a > 1 + p(2p−1), and C8 (E) for pair sets placed high

**Proof.** From C13 and C15. The rounds game takes all 2p numbers (no early loss), so the final margin is the initial lead plus a difference of the two players' totals from E, and sum(E) ≡ p gives margin ≡ g0 + p ≡ 0 (mod 2) for both players. So a margin ≥ −1 is ≥ 0, and always-max secures it for the mover (start at debt g0 ≤ 1) and for the other player (leading by g0 ≥ 0). Both secure at least a draw, so R(E, g0) = draw; C13 transfers it to V for a > g0 + sum(E), which a > 1 + sum(E) ensures.
**Evidence.** Refuter (claim mode, 2026-10-26, C3): every pair set with p = 2..9 and spacing up to max offset 200 (p ≤ 4), 80 (p = 5), …, 30 (p = 9), and every pair set within {0..25}, matches t_p at debts 0 and 1. Our `rounds_game 24`: all pair sets within {0..23}. Refuter proof mode (2026-10-26): SURVIVES; always-max from every start of C15 on the 4,181 pair sets containing 0 within {0..19} (least margin −1); a literal `valueAux` port gives draws on all 232 pair sets within {0..11} at a = sum(E) + 2 and a = sum(E) + 1 + g0.
**Lean, blocks** (2026-10-26, `CatchUp/Blocks.lean`). `block_draw_high`: for p ≥ 1 and a > p mod 2 + p(2p−1), `valueAux ((range (2p)).map (a + ·)) s (s + p % 2) false = draw` for every s, i.e. V({a..a+2p−1}, p mod 2) = draw. Deviations from C16: blocks only, not every pair set; the margin bound comes from C23 (`depth_class_roundsMargin`, AM+T) instead of C15 (always-max); the height is C13's a > g + sum, the same as C16's for p odd and one lower for p even. Parity via `even_roundsMargin_add`, the value via `roundsValue_eq_ofMargin`, the real game via `valueAux_map_add`. C16 itself stays `paper proof` (general pair sets). `lake build --wfail` clean; axioms propext, Classical.choice, Quot.sound.
