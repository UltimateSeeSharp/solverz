# C62 Twins with a tie-break at every height

**Statement.** For k ≥ 1 and real c > 0: the multiset of pairs {x, x + ε}, x ∈ {c, c + 1, …, c + k − 1}, played lexicographically as in C36 (integer parts first, then the count of upper elements), the mover trailing by ε·(k mod 2), is a draw.
**Use.** Scaling preserves the game, so C36 is c = 1/2 (fam a) and c = 1 (fam b); C62 is to C36 what C32 is to C1. Comparisons are (difference of counts)·c + integer, so the game changes only at c = q/r, r ≤ 2k, q ≤ k(k − 1): each k is a finite check. For c > 3(k − 1) + 3/(2k + 2) it follows from C21 (offsets E = {Ki, Ki + 1}, K = 2k + 2, a = Kc > 3·max E).
**Evidence.** Mine (2026-10-30). `scratch/a13/lexcells.rs`, every c = a/g with gcd 1, g ≤ 4k, c ≤ k(k − 1) + 1 (every breakpoint and a mediant inside every cell): a draw at every c for k ≤ 6 (5,580 values at k = 6). `lexap.rs`, progressions {a + ig} with gcd(a, g) = 1: all draw for g ≤ 7, a ≤ 30, k ≤ 7, and for g ≤ 5, a ≤ 20, k = 8. Unlike C32 (odd p: the mover wins on (0, 1/2)) there is no threshold. The drawing openings move with c (`lexopen.rs`): for k = 4, 5 the bottom upper element draws on (0, 5) and the bottom lower on (0, 1); from c = 5 only top upper elements draw. Bases other than progressions fail (C36's sparse high cores).
