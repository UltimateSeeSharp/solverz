# C62 Twins with a tie-break at every height

**Statement.** For k ≥ 1 and real c > 0: the multiset of pairs {x, x + ε}, x ∈ {c, c + 1, …, c + k − 1}, played lexicographically as in C36 (integer parts first, then the count of upper elements), the mover trailing by ε·(k mod 2), is a draw.
**Use.** Scaling preserves the game, so C36 is c = 1/2 (fam a) and c = 1 (fam b); C62 is to C36 what C32 is to C1. Comparisons are (difference of counts)·c + integer, so the game changes only at c = q/r, r ≤ 2k, q ≤ k(k − 1): each k is a finite check. For c > 3(k − 1) + 3/(2k + 2) it follows from C21 (offsets E = {Ki, Ki + 1}, K = 2k + 2, a = Kc > 3·max E).
**Evidence.** Mine (2026-10-30). `scratch/a13/lexcells.rs`, every c = a/g with gcd 1, g ≤ 4k, c ≤ k(k − 1) + 1 (every breakpoint and a mediant inside every cell): a draw at every c for k ≤ 7 (10,406 values at k = 7). `lexap.rs`, progressions {a + ig} with gcd(a, g) = 1: all draw for g ≤ 7, a ≤ 30, k ≤ 7, and for g ≤ 5, a ≤ 20, k = 8. Unlike C32 (odd p: the mover wins on (0, 1/2)) there is no threshold. The drawing openings move with c (`lexopen.rs`): for k = 4, 5 the bottom upper element draws on (0, 5) and the bottom lower on (0, 1); from c = 5 only top upper elements draw. In the bottom cell c ∈ (0, 1/(2k)) the first round is forced (`lexroot2.rs` at c = 1/(2k + 1), k = 3..6): every opening of a non-zero element loses on the count level, the zero element with the upper one for k odd and the lower one for k even draws, and the only reply that does not lose is the other zero element; this leaves k − 1 pairs at height c + 1, just above 1, the canonical position. So C62 at (k, 0+) follows from C62 at (k − 1, 1+) once those deviations are shown to lose. Just above height 1 (c = 1 + 1/(2k + 1), k = 4..6) the first round is not forced but stays in the bottom two pairs: opening or answering with an offset ≥ 2 loses on the count level. Bases other than progressions fail (C36's sparse high cores).
**Tried.** One strategy for all heights (`scratch/a13/lexpieces.rs`, adapted from the ideator's `tdcells.rs`; Z sees only play, every breakpoint and cell): none, the pieces split at integers as for blocks (C55). k = 3 on [1/100, 8]: P2 one piece, P1 two (switch at c = 3); k = 4 on [1/100, 5]: P1 switches at 3, P2 at 1 and 3. C36's c = 1 sits at the lower end of its piece. Below 1 there is no switch: (0, 1) is one piece per role for k ≤ 6 (k = 6 on [1/100, 1]: one piece each), so one strategy draws C36's c = 1/2 and the bottom cell (0, 1/(2k)) alike. A window lemma, "with the bottom pair intact a pick above 2·min R loses", fails at reachable turn starts (`scratch/a13/lexwin.rs`, `lexwin2.rs`; generic c, deficit below one unit): 272 of 6,872 for k = 4, 4,602 of 69,869 for k = 5, mostly short endgames such as {1, 1', 10, 28} at c = 1/9; it describes opening play only. C63's one-round peel does not continue above height 1: at c = 3/2 (k = 3, 5, 7, `lexroot2.rs`) no opening leaves P2 only losing stray answers; after the bottom upper element the answers of offset 1 draw, since the mirror's lead 2c no longer exceeds c + 1. Short certificates (`scratch/a13/lexcert3.rs`: a strategy for one player whose every line ends within T turns, checked at every pick, at a smaller canonical C62 position, at a twin-mirror win, i.e. only intact pairs left and the other player behind by more than the token slack and less than min R, or at the end): below height 1 P1 has one in 3 turns for every k ≤ 9 (C63's proof), P2 for even k; at c = 15/11 none in 6 turns from k = 5 (k ≤ 8), at c = 25/11 none from k = 5 (k ≤ 7), so above height 1 the leaves need more than canonical positions and mirror wins. Even with every smaller all-pairs position as a leaf at its true value (mode 1), P1 has no certificate within 4 turns at c = 15/11 (k ≤ 8) or 25/11 (k ≤ 7): P2 can answer into another pair and keep broken pairs on the board; P2 has one for every k there.
