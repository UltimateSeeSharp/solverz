# C18 Relative difference set minus its subgroup

Let R be a (q + 1, n, q, (q − 1)/n) relative difference set in an abelian group G of order n(q + 1)
relative to a subgroup H of order n, translated to miss H. Then R·H = G − H and
(R − H)(R − H)^(−1) = q + ((q − 1)/n)(G − H) − 2(G − H) + nH, so R − H (R marked +, H marked −) is an
SDS iff (q − 1)/n = n + 2 (for n ≥ 2; n = 1 always gives the trivial (v, v, v − 4) set), i.e. q = (n + 1)²: parameters (n((n + 1)² + 1), (n + 1)² + n, n). Bose's
affine RDS {x ∈ GF(q²)* : Tr(x) = 1}, projected, gives one in the cyclic group of order n(q + 1) for
every prime power n + 1.
