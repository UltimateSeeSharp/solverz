# C14 Box bound on the coset sums

Under C13's setting, |a_h| ≤ c puts every y_h = (a_h − t₀)/q in [lo, hi] with lo = −⌊(c + t₀)/q⌋,
hi = ⌊(c − t₀)/q⌋, so Σ (y − lo)(hi − y) ≥ 0 gives S₂ ≤ (lo + hi)·S₁ − N·lo·hi. No SDS when every
s' = ±s and t₀ fails C13's test or this bound.

**Evidence.** It replaces C6's search over vectors (sc2.py's R2dp): on the open rows it kills exactly
the 1,387 Instances C6 kills beyond C13 (`solver/selfconj.py certs`; C5 + C13 + C14 = 7,458 = C6's
count), so C6 needs no search.
**Tried.** A DP over vector values (sc2.py's `min_count`), not needed.
**Proof.** Termwise (y − lo)(hi − y) ≥ 0, summed with Σy = S₁ and Σy² = S₂ (C13). Lean:
`not_hasSDS_of_box`, `boxOk_of_congr` in `lean/SignedDifferenceSets/Box.lean`; per row `BoxCheck.lean`.
