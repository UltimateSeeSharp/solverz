# C9 Multiplier theorem with a fixed translate

Gordon arXiv:2212.10630 Thm 5.1 (McFarland; Tan arXiv:1610.01914 Result 3.2): for an SDS
(v, k, λ) on G with gcd(v, n) = 1, every t in the group M it names is a multiplier; since
gcd(s, v) = 1 (s² = n + λv), the translate of D with Σ D(x)·x = 0 is fixed by every t in M at
once, and its sign sum may be taken +s (C2).

**Evidence.** Refuter SURVIVES (`scratch/refuter/a5-a3/report.md`): hypotheses hold for every Instance A5 uses; the
character/ideal proof re-derived and the elementary proof for squarefree n checked step by
step; the theorem holds on all 574 known sets it applies to and on every SDS in the 17 groups
of order ≤ 15.
**Tried.** Not new: Gordon's table already used it for composite n (43 "Orbit Exhaust" entries; the
ideator's claim that it did so only for prime-power n was wrong).
**Proof.** As in Gordon Thm 5.1; the translate step only needs gcd(s, v) = 1. Lean: every n ≠ 0 prime to v, `IsSDS.exists_translate_fixed'` (`MultiplierWitt.lean`, Witt vectors,
helper W); refuter SURVIVES (`scratch/refuter/i13/report-2026-11-06-2316.md`).
