# C2 Translation and negation

If D is an SDS with parameters (v, k, λ), so are x ↦ D(x + t) for every t and
x ↦ −D(x). A search may fix one marked element at 0 and the sign sum at +s (C1).

**Used by.** The triage search; every exhaustive run.
**Evidence.** The defining sum Σₓ D(x)D(x + g) is unchanged by both maps.
**Proof.** Reindex the sum by x ↦ x + t; signs enter in pairs. Lean:
`IsSDS.translate`, `IsSDS.neg` in `lean/SignedDifferenceSets/Symmetry.lean`.
