# C19 Gaussian characters on a quotient of exponent 4

Let D be an SDS (v, k, λ) on G, n = k − λ = m², s² = k + λ(v − 1) (C1), and H a quotient of G with
4h = 0 for all h, |H| = N. Every character ψ of H takes values in {±1, ±i}, so ψ(D) = A_ψ + B_ψ i with
integers A_ψ, B_ψ, and A_ψ² + B_ψ² = n for ψ ≠ 1 (|ψ(D)|² = n). Real characters (ψ⁻¹ = ψ, R of them, the
trivial one included) other than ψ = 1 have ψ(D) = ±m; the others pair off with ψ⁻¹, which has the same A. Summing all ψ(D):
N·a₀ = s' + Σ_{R − 1} ±m + 2 Σ_{(N − R)/2} x with s' = ±s and each x in X(n) = {x : n − x² a square}.
No SDS when for both s' = ±s and every R in [1, N] with N − R even no such choice is ≡ 0 mod N (R need
not be known: the pairing forces N − R even; at N = 1 only R = 1, which never kills).
