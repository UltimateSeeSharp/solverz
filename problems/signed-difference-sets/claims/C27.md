# C27 Field descent without ramification

Let D be an SDS (v, k, λ) on G, n = k − λ ≠ 0, ZMod m a quotient of G with fibres of size c and gcd(m, n) = 1, and
F d = m such that every t = 1 + F u (u < d) is prime to m and congruent mod m to a power of each prime p | n. Then
φ(m) n ≤ m F c².

**Uses.** C10 (`IsSDS.exists_translate_fixed_contract'`, verified).
**Evidence.** Proof: by C10 a translate Y of the coset sums on ZMod m is fixed by every such t, and has
autocorrelation n [g = 0] + λc. For a unit a and χ_a(Y) = Σ Y(h) ζ^(a h): substituting h → t h gives
χ_a(Y) = Σ Y(h) ζ^(a h) w^u with w = ζ^(a F h), and summing over u < d, Σ_u w^u = d if F h = 0 and 0 otherwise
(w ≠ 1 is a d-th root of unity). So χ_a(Y) = χ_a(Y_S), S = {h : F h = 0}, |S| ≤ F. Each |χ_a(Y)|² = n, so
φ(m) n = Σ_(a unit) |χ_a(Y_S)|² ≤ Σ_a |χ_a(Y_S)|² = m Σ_S Y² ≤ m F c² (Parseval).
This is at least as strong as Schmidt's field-descent bound (Tan arXiv:1610.01914 Def 2.10, Results 2.11–2.12) for n prime
to m: the descent is replaced by the multiplier theorem and F is read off the multiplier group; C10's single fixed translate
(McFarland–Rice) removes Schmidt's root-of-unity factor, so on N9792, SDS(200, 139, 18) in C₂ × C₁₀₀, C27 gets F = 10 where
Tan's F(100, 121) = 20 kills nothing.
