# C21 Ma's lemma on a mixed quotient C_{p^j} × K

Let D be an SDS (v, k, λ) on G, n = k − λ, p a prime with e = v_p(n) ≥ 2, H = C_{p^j} × K a quotient of G
(j ≥ 1, p ∤ |K|, and K = 1 or p^i ≡ −1 mod exp K for some i), P the subgroup of order p of C_{p^j},
c = v/|H|, b = ⌊e/2⌋. If p^b > 2c, no SDS exists.

**Uses.** C3, C5 (its F_p Frobenius step on K).
**Evidence.** Ideator round 2 (B5a, `scratch/ideator/2026-11-06-1837.md`): 1,241 open rows
(`scratch/ideator/r2/ma_hits.txt`), no `exists` row hit; the lemma Y ∈ p^b ℤ[H] + Pℤ[H] held on 760 brute-force Y
(`r2/ma_lemma_test.py`); p^b > 2c never holds on the 32,730 quotients where E8 found an integer vector (`r2/e8ma.py`).
**Proof sketch.** Coset sums Y (C3), YȲ = n + λcH. In A = ℤ[H]/(P) (free over ℤ[ζ_{p^j}] with basis K) H ↦ 0, so
YȲ = n; π = 1 − x, π^φ = p·unit, A/πA = F_p[K], Ȳ ≡ Y^(p^i) mod π (Frobenius), F_p[K] reduced ⇒ π | Y; induct to
Y ∈ p^b A, i.e. Y = p^b X₁ + P X₂. Then (1 − g_P)Y ∈ p^b ℤ[H] with coefficients ≤ 2c < p^b, so Y = P·Z ↦ 0 in A,
against YȲ = n ≠ 0. Weakest steps: A/πA = F_p[K] with the involution matching Frobenius; π^φ = p·unit in A.
