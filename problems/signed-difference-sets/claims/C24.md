# C24 Mod-q vanishing: one character of each inverse pair kills D mod q

Let D be an SDS (v, k, λ) on a finite abelian G, n = k − λ, q a prime dividing n, K a field of characteristic q and
ψ: G → K^× a homomorphism with Σ_{x ∈ G} ψ(x) = 0. Then ψ(D) · ψ(D^(−1)) = 0 in K, where ψ(D) = Σ_x D(x) ψ(x) and
D^(−1)(x) = D(−x); so ψ(D) = 0 or ψ(D^(−1)) = 0.
