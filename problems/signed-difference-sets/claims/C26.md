# C26 Ma's lemma at the edge: parity of the halved coset sums

D an SDS (v, k, λ) on G, 4 ∣ n = k − λ, s² = k + λ(v − 1) (C1), s′ = ΣD = ±s. Let H = C_{2^j} × K be a quotient of G
(j ≥ 1, |K| odd, 2 self-conjugate mod exp K), c = v/|H|, u the element of order 2 of C_{2^j}. Then the coset sums satisfy
Y(h + u) ≡ Y(h) (mod 2), and 8 ∣ 2s′ − (k + λ(2c − 1)). For c = 1 (H = G) the support of D is a union of ⟨u⟩-cosets and
Z = (contraction to G/⟨u⟩)/2 is an SDS (v/2, (k + λ)/4, λ/2); the condition is its parity.

**Uses.** C1, C3, C21 (`MaLemma.lean` up to `exists_pow_mul`).
**Evidence.** Proof: C21's argument with b = 1 gives ψ(Y) ∈ 2A in A = ℤ[K][X]/(1 + X^r), i.e. 2 ∣ Y(h + u) − Y(h). With
F = Y + Y(· + u) = 2Z, each term of Σ (2F − F²) = 4s′ − 2(k + λ(c − 1)) − 2λc is −4Z(Z − 1) ≡ 0 (mod 8) and pairs up under
h ↦ h + u (u ≠ 0, 2u = 0), so 16 ∣ 4s′ − 2k − 2λ(2c − 1). Checks (2026-11-06/07, `scratch/c26/`): every SDS with 4 ∣ n on
C₄, C₈, C₁₂, C₁₆ (472, exhaustive) has ⟨u⟩-invariant support; the general condition holds on all 45 valid known sets (objects

0 `exists` rows and 177 open rows (smallest killing c: 125 with c = 1, the rest 3, 7, 23, 31; the Lean certificates use other
c from 1 to 31).
