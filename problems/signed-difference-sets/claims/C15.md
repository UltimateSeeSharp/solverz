# C15 Multiplier theorem with a fixed translate, squarefree n

C9 for squarefree n: for an SDS D (v, k, λ) on G with n = k − λ squarefree and gcd(v, n) = 1, there
is one translate D' = D(· + a) with D'(t·x) = D'(x) for every t coprime to v such that, for each
prime p | n, t·x = p^f·x on G for some f ≥ 0.

**Evidence.** Refuter SURVIVES ([R13](../reviews/R13.md)): every SDS on the 25
abelian groups of order ≤ 16 with squarefree n and gcd(v, n) = 1 (1,352 sets), 321 known sets, 0
failures; the control with all units in place of the multipliers fails as it must. Matches E10's
multiplier group (`solver/src/orbits.rs`) for rows with squarefree n.
**Tried.** —
**Proof.** The refuter's elementary route (a5-a3 report §2): Frobenius in F_p[G] for each p | n gives
W' = D^(t)D^(−1) − λG ≡ 0 mod p; CRT (n squarefree) gives n | W'; W'W'^(−1) = n² and ΣW' = n force
W' = n[g], so D^(t) = gD; the translate with centroid 0 has g = 0 for every t at once. Lean:
`IsSDS.exists_multiplier`, `IsSDS.exists_translate_fixed` in `lean/SignedDifferenceSets/Multiplier.lean`.
