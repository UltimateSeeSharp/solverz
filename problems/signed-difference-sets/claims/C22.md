# C22 Sylow trace rule

Let D be an SDS (v, k, λ) on a finite abelian G, n = k − λ > 0, s² = n + λv (C1), p a prime, H a quotient of G
that is a p-group, |H| = p^t, e = v_p(n). Then
- p odd: p^min(t, ⌈e/2⌉) ∣ s;
- p = 2 (t ≥ 1): n = m² and, with w = v₂(m), 2^min(t, w) ∣ s, and 2^(w+1) ∤ s when w < t.
(Divisibility, not valuations: s = 0 occurs on existing SDS, e.g. N1 (5, 4, −1), N2 (9, 8, −1).)
