# C5 Rule SC: self-conjugacy congruence on a quotient

Let D be an SDS (v, k, λ) on G, n = k − λ > 0, p a prime with p^(2j) | n (j ≥ 1), H ≠ 1 a
quotient of G with p ∤ |H| and p self-conjugate mod exp(H) (p^i ≡ −1 mod exp(H) for some i),
c = v/|H|, and a the coset sums of D on H (C3). Then all a_h are congruent mod p^j. So if
p^j > 2c, no SDS exists (all a_h equal, χ(a) = 0 for χ ≠ 1, against |χ(a)|² = n > 0).

gives a_h ≡ a_h' (mod p^j). Elementary for j = 1 (only p | n used): in F_p[H], x^(p^i) = x̄

for any μ in x x⁻¹ = n + μH (needs H ≠ 1). Lean: —.
