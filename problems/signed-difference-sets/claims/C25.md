# C25 Self-conjugate primes enlarge the coset-sum multiplier group (N1a)

D an SDS (v, k, λ) on G, n = k − λ, H a quotient with gcd(|H|, n) = 1, c = v/|H|, Y the coset sums (C3). Let
S₂ = {p ∣ n : p^i ≡ −1 mod exp H for some i}, S₁ the other primes of n, and
M′ = {t ∈ (ℤ/exp H)^× : t ∈ ⟨p mod exp H⟩ for every p ∈ S₁}. Then some translate of Y is fixed by every t ∈ M′.

**Uses.** C5, C10 (I13's form for every n).
**Evidence.** Ideator round 3 (N1a, main folder `scratch/ideator/2026-11-06-2034-none.md`): proof sketch below; brute
force on all integer Y in ℤ[C₇] with YY^(−1) = 338 − 2·C₇ (28 solutions, each with an M′-fixed translate, none fixed by
all units); no `exists` row killed. Credit: Miller, arXiv:2511.10231, Thm 7 (difference sets); this is the SDS form on
quotients prime to n.
**Proof sketch.** W = Y^(t)Y^(−1) − λcH. For p ∈ S₁, p^(e_p) ∣ W as in C9/C10. For p ∈ S₂, C5 gives Y = rH + p^j Z with
j = e_p/2; expanding, W = ((n − p^(2j)(ΣZ)²)/|H|)·H + p^(2j)·Z^(t)Z^(−1) and p ∤ |H|, so p^(e_p) ∣ W for every unit t.
CRT: n ∣ W; WW^(−1) = n², so U = W/n has UU^(−1) = 1, ΣU = 1, hence U = h and Y^(t) = hY; gcd(s′, |H|) = 1 gives one
translate fixed by all of M′ (C15's step).
