**Restatement.** D is an SDS on G and H = C_{p^j} x K is a quotient of G, where p does not divide |K| and p^i = -1
mod exp K. Write n = k - lambda, e = v_p(n) >= 2, b = floor(e/2) and c = |G|/|H|. Then the coset sums Y on H satisfy
Y in p^b Z[H] + P Z[H]. So when p^b > 2c, Y is constant on P-cosets and dies in Z[H]/(P), which contradicts
Y Ybar = n != 0 there. There is one natural reading and I tested that one.

### F1. The proof sketch: every step holds (no error found)
- A = Z[H]/(P) = Z[K] (x) Z[zeta_{p^j}]. This holds because P = Phi_{p^j}(g), since Phi_{p^j}(X) = sum_{t<p} X^(t p^(j-1)).
  The H-sum is (sum K)(sum C_{p^j}) = (sum K) P (sum_{t<p^(j-1)} g^t), so H maps to 0 and Y Ybar = n in A. Holds.
- pi^phi = p*u with u a unit **in A**: u lies in Z[zeta], which is a subring of A with the same 1. Checked exactly
  (`norm.py`): the coefficients of (1-x)^phi mod Phi are divisible by p, and N(u) = 1 for p^j in
  {2, 4, 8, 16, 32, 3, 9, 27, 5, 25, 7, 49, 11, 13}. Holds.
- pi is a non-zero-divisor: A is free over the domain Z[zeta] with basis K, and pi acts coordinatewise. Holds.
- A/piA = F_p[K]. Since pibar = -x^(-1) pi, the ideal piA is stable under the involution, and the involution
  induced on F_p[K] is k -> -k. Frobenius gives y^(p^i) = sum a_k (p^i k) = ybar. Holds.
- Induction: Y = pi^t Y_t with Y_t Ybar_t = (unit) pi^(e*phi - 2t) n'. Running it up to t = b*phi keeps the
  exponent >= 2 at every step, so Y is in pi^(b*phi) A = p^b A. This covers p = 2, j = 1 (phi = 1, pi = 2,
  A = Z[K]) and odd e. When e*phi is odd the extra half-step gives pi | n', a contradiction, which agrees with
  He-Wu Thm 3.2. That is harmless, and the Lean proof should stop the induction at b*phi.
- Final step: (1 - g_P)P = 0, so (1 - g_P)Y = p^b (1 - g_P) X1. Its coefficients satisfy |a_h - a_{h-g_P}| <= 2c
  < p^b, so they are 0. Then Y = P*Z maps to 0 in A, but n != 0 in A (A is a free Z-module and 1 is a basis
  element). Holds. On every row n > 0, since |lambda| <= k and n = 0 only for the full set with k = lambda = v.
- Literal reading: the statement says "for some i", and i = 0 adds nothing. "K = 1 or" is redundant. e >= 2 forces
  n != 0, including in Lean, where padicValNat 0 = 0. The strict p^b > 2c is needed: O3, CW(4,4) in C4, sits at
  p^b = 2c = 2.

### F2. The hypothesis "p^i = -1 mod exp K" is exactly what the Frobenius step needs, and it is necessary
- Checked by exhaustive search over F_p[K] (`frob.py`, `frob.out`) in 17 claim cases:
  - p = 2: K = C3, C5, C9, C3^2, C11, C13.
  - p = 3: K = C2, C4, C2^2, C5, C7, C2 x C4, C10.
  - p = 5: K = C3, C6, C2^2.
  - p = 7: K = C4, C2^2.
- In every one of them, ybar == y^(p^i) for all y, and y*ybar = 0 forces y = 0.
- Controls, where p is not self-conjugate mod exp K, do have nonzero y with y*ybar = 0:
  - p = 2: K = C7 (14), C15 (30), C3 x C5 (30).
  - p = 3: K = C8 (16).
  - p = 5: K = C4 (8).
  - p = 7: K = C3 (12).
- exp K is itself the order of some element of K. So "self-conjugate mod every element order" is the same
  condition, and nothing weaker works. (I first guessed otherwise; C3 x C5 with p = 2 shows the guess was wrong.)
- H only has to be a quotient of G. Every hit row's invariant factors allow this (F3).

## Literature

- **Ma's lemma.** Opened: Tan, *Group Invariant Weighing Matrices*, arXiv 1610.01914, Result 2.7. If G has a cyclic
  Sylow p-subgroup and p^a divides chi(Y) for every nontrivial chi, then Y = p^a X1 + P X2. Tan credits
  S.L. Ma, PhD thesis, Univ. Hong Kong 1985.
- **Turyn's self-conjugacy.** Tan's Result 2.6 cites Turyn 1965.
- **The combination for CW.** Australas. J. Combin. vol. 18, p. 111 (OCR; I could not read the authors) derives
  "P - N = p^b X1 + Q X2" with Q of order p, citing Ma's thesis. That is the same move made on circulant weighing
  matrices.
- **Not used for SDS in what I opened:**
  - Gordon, *Signed Difference Sets*, arXiv 2212.10630 v1: no nonexistence theorems beyond integrality and
    lambda >= -1.
  - He-Wu, *Nonexistence results and constructions for SDS*, arXiv 2608.22936 v2 (2026-09-20): four obstructions
    (v_p(n) even under self-conjugacy, the C2-quotient, two parity ones). Ma is cited only for a PDS survey.
  - Arasu-Gordon-Zhang, arXiv 1908.08447: Lander/Turyn self-conjugacy only.
  - Gordon, arXiv 2501.14924 v2: Lam's RDS bound only.
- **Not opened:**
  - Pott 1995 (LNM 1601) §1.5: no text available.
  - Arasu-Ma 2001, JACO 14 (EMIS returned 503).
  - Ma-Schmidt McFarland PDF (binary).
  - A search for SDS + Ma's lemma 2024-2026 found only He-Wu.
- **Credit.** C21 is Ma's lemma (Ma 1985; Pott 1995 §1.5) combined with Turyn's self-conjugacy (1965). The
  combination is known for circulant weighing matrices. I found it nowhere for SDS. The mixed-quotient SDS form
  and the elementary proof through A = Z[H]/(P) are the ideator's. The rule should cite Ma and Turyn, and should
  not be claimed as a new theorem.
