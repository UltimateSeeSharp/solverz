### Restatement

D: G -> {-1,0,1}, an SDS (v,k,lam), n = k - lam, s^2 = k + lam(v-1) (so sum D = +-s). H = G/K with 4H = 0, |H| = N.
For psi in Hom(H, C*), psi(D) := sum_x D(x) psi(phi x) lies in Z[i]; |psi(D)|^2 = n for psi != 1. The R characters with
psi^2 = 1 give psi(D) real, so +-m (needs n = m^2); the N - R others pair psi <-> conj psi with equal real part A,
A^2 + B^2 = n. Sum of real parts: N a0 = s' + sum_{R-1} (+-m) + sum_{(N-R)/2} 2x, x in X(n). Kill: for both s' = +-s and
every R in [1, N] with N - R even, 0 not reachable mod N. Unambiguous; the true R is 2^rank(H/2H), the claim quantifies over
a superset (conservative). The Lean form only needs n = m^2 when it is applied (hm is a hypothesis), fine.

### F6. The prose of C19.md is literally false at N = 1 (wording; fix before recording)

`claims/C19.md` line 8: "No SDS when for both s' = +-s and every even R in [2, N] no such choice is = 0 mod N". The
trivial quotient H = 0 (N = 1) satisfies 4h = 0, and [2, 1] has no even R, so the condition holds vacuously and the
prose says: no SDS whenever n is a square and s^2 = k + lam(v-1) is. Counterexamples: O3 (4,4,0) in C4, O7 (27,10,1) in
C3^3 (n = 9, s^2 = 10 + 26 = 36), any SDS with square n. Lean's `GaussKills` ranges over R in [1, N] with
N - R even, which at N = 1 is R = 1 and never kills (`not GaussKills 1 3 5` by decide), so the Lean statement is right
and the rows are unaffected. Fix: state R in [1, N] with N - R even (or N >= 2; then R is even). Also lines 5-6, "Real
characters ... have psi(D) = +-m", holds only for psi != 1 (the trivial one gives s'); the formula already excludes it.
Side: the true R = 2^rank(H/2H) kills nothing more than all R (0 extra open rows, N <= 64); no open row dies at N = 4
(kills by N: 8: 91, 16: 221, 32: 150, 64: 44 row-quotient pairs), matching "None die on C4 alone".
