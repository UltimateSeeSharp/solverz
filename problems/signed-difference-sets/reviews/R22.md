### Part 1 — C23
- **Lean statement vs C23 / C5 / C14.** `not_hasSDS_of_compositeModulus` is C14's `not_hasSDS_of_box`
  with `q = p^j` replaced by `modulusProd L`. Each prime in L carries C5's hypotheses
  (`SelfConjOn`: prime, i > 0, p^i • h = −h, p ∤ |H|, p^{2j} | k − λ). The primes are pairwise
  distinct (`hpw`), and the test is the same `BoxOk` (C13's `MomentsOk` ∧ box) for s' = ±s and every
  t₀ ∈ [0, q). `CmCert.Kills` has the same arithmetic as `ScCert.Valid` (with d | p^i + 1 per factor).
  `CmCert.not_hasSDS` concludes ¬ HasSDS (Grp r.ms) r.k r.lam for any Fintype instance. Sound and
  faithful.
- **Rows recomputed** (`c23_check.py`). I wrote my own parser, primality, self-conjugacy and Lean-literal
  BoxOk. All 132 rows' (ms, k, λ, v) equal their instances.csv key. All 132 are `open` with no object.
  Every certificate satisfies Kills. The 132 `none` ids in settle-round4.tsv equal the Lean ids, and the
  chunk names match.
- **Own search over all 70,543 rows.** It tried every subset of ≥ 2 primes with q ≤ 20,000 (the solver
  uses only the full set, with q ≤ 5,000). It kills 1,181 rows: 132 `open` (exactly the Lean set, none
  missed, none extra), 1,049 already `none`, 0 `exists`.
- **Tested on known SDSs.** The box test reaches 31 `exists` rows (4 with ≥ 2 primes) and kills none of
  them (`c23_exists.py`). The congruence mod q holds on every stored object (O1–O60) on all 46
  object/quotient pairs, 3 of them with two primes (`c23_objects.py`). No stored or scratch set has a
  C23 row's (v, k, λ).
- **Minor (wording).** claims/C23.md says "C5 (2c < q), C13 and C14 hold with q". The Lean proves only
  the C14 box test with q, which includes C13. "C5 with q" is not stated, but no row needs it: on all
  502 quotients with ≥ 2 primes and 2c < q, the box test already fails for every t₀ (`c23_c5q.py`).
  C23.md's Evidence still says 94 rows; there are 132.

  the key. The plus/minus masks are disjoint and fit inside v. Decoded in Mathlib's `finProdFinEquiv`

- **Status.** The 19 settle rows are `open`; N1134 and N9807 are `exists`. The tsv's object ids and
