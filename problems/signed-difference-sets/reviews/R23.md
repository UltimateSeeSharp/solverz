and a surjection G ->+ ZMod (r p) × K. Assume |G| = c |H|, p^i x = −x on K, p^e ∣ k − λ, k ≠ λ, 2b ≤ e,

the batch is an entry (Row, MaRowCert) of MaRows/PartNN.lean. `partNN_kills` decides `Kills` and (p, r) ∈ maPairs,

### Part 1. Does MaRule say C21? Yes. No hypothesis is weaker than C21 allows (SURVIVES)
- **r.** r is free, but `CycloFacts p r` fails unless r is a power of p.
  - Suppose a prime q ≠ p divides r. Take S = ℤ[ζ_{rp}] and x = ζ_{rp}. Then Ψ(x) = 0, but x − 1 is a unit because
    rp is not a prime power, so (x − 1)^N = p z is impossible.
  - At r = p^(j−1), Ψ = Φ_{p^j} and p = (1 − ζ)^φ · unit, so the facts hold in ℤ[X]/(Ψ) and hence in every ring.
  - So MaRule's quotients are exactly C21's C_{p^j} × K.
- **K.** `p^i • x = −x` (i > 0) is the same as p^i ≡ −1 mod exp K. It forces p ∤ |K|, and K = 1 is allowed.
- **p^e ∣ k − λ with 2b ≤ e.** Every such b is ≤ ⌊v_p(n)/2⌋, so this is not more general than C21's
  b = ⌊v_p(n)/2⌋.
- **k ≠ λ.** It is present, and it is needed because p^e ∣ 0 for every e.
- **c.** c = |G|/|H| exactly, and the inequality is strict. c ≥ 1 forces b ≥ 1.
- **HasSDS.** The conclusion uses the problem's own HasSDS. Nothing in the 20-file import closure redefines HasSDS,
  IsSDS, Grp, Row, MaRule or CycloFacts.
- **MaRule is true independently of the Lean proof.**
  - Turyn (Tan arXiv:1610.01914 v4, Result 2.6) gives p^b | χ(Y) for every non-trivial χ of H.
  - Ma (Result 2.7) then gives Y = p^b X1 + P X2.
  - The entries of (1 − g)Y are at most 2c < p^b in size, so they are all 0. Hence Y = P Z, and χ(Y) = 0 for χ
    non-trivial on P. This contradicts |χ(Y)|² = n ≠ 0.
- **Concrete tests.** These use my rule in its strongest form: best j, best K over all self-conjugate exponents,
  best b.
  - It fires on none of the 60 objects, which I re-verified as SDSs (`objs5.out`), and on none of the 200 `exists`
    rows.
  - `small5.py` covers every SDS in all abelian groups of order ≤ 12, plus C16 at n = 16. The rule fires on 14
    parameter sets, none of which has an SDS, and on no existing one.
  - (9, 8, −1) exists in C3 × C3 and the rule spares it. It fires in C9, where no SDS exists.
  - CW(4, 4) in C4 sits at 2c = p^b and is not hit.

### Part 2. Kills against MaRule: every hypothesis is derived in a kernel-checked theorem (SURVIVES)
`not_hasSDS_of_maRule` (MaCheck.lean 41-71) derives each MaRule hypothesis from Kills:
- **φ.** φ = `linMap`. It is onto by `linMap_surjective` from the preimages P.
- **c.** `|G| = (ms.prod / (r p ks.prod)) · |H|` by `Nat.div_mul_cancel`. Kills requires `r p ks.prod ∣ ms.prod`, so
  the floor division is exact.
- **K.** p^i x = −x comes from (p^i + 1) • x = 0 (`Grp.nsmul_eq_zero`, with each factor d ∣ p^i + 1).
- **The rest.** The strict `2c < p^b`, `k ≠ λ`, `2b ≤ e` and `p^e ∣ k − λ` are passed through unchanged.
- **ks.** `ks ≠ []` only picks the `Grp (k₀ :: ks)` shape, with `[1]` standing for K = 1. A 0 factor is impossible,
  since d ∣ p^i + 1.
- **Soundness.** A wrong Kills could only make that theorem unprovable, never unsound.
- **Independent check.** My own re-implementation of Kills (rows5.py) accepts all 1,457 certificates, all with r a
  power of p.
