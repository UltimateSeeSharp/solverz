### N49 (25,12,1) C5xC5
Lean and set OK. Open; not in Gordon 2022, He-Chen-Ge 2024, He-Wu 2026. O6 has a stabilizer of
order 3 in AGL(2,5) x {+-1} and is affinely equivalent (A = [[1,2],[0,3]], t = (1,3), sign -1)
to an eighth-power cyclotomic SDS of F_25: P = three order-8 cyclotomic classes (size 3), N =
one class (r4_struct.py, r4_o6cyc.py; 32 class/sign choices work). No paper I opened builds SDSs
from order-8 classes (Gordon Sec 3: e-th powers with N = {0}; HCG Sec 5: order 4). Worth
recording as the set's structure (family (8f+1, 4f, (f-1)/2) at f = 3), not as prior art.

### N61 (27,10,1) C3^3
Lean and set OK. Open (no paper states it). But it is the m = 1 case of He-Chen-Ge's product
construction (arXiv 2306.05631 Sec 4; DCC 92 (2024) 2323-2340): G = G0 x G1 x G1,
D = (x0,0,G1) + (0,G1,x1) + (0,D',D'), parameters (3^(2m+1), 3^(2m)+1, 1). Their Thm 4.1
states m even (D' from a Paley PDS). At m = 1 with D' = {1} - {2} (Gordon Prop 2.2, v = 3) and
x1 = 0 it gives a (27,10,1) SDS in C3^3, and O7 is affinely equivalent to it
(A = [[2,1,0],[2,2,0],[0,0,1]], t = 0, sign +) (r4_hcg_m1.py). Origin must credit HCG.

### N62 (27,10,1) C3xC9
Lean and set OK. Open. HCG's construction needs G = G0 x G1 x G1 elementary abelian. O8 has a
trivial stabilizer in Aut(C3xC9) x G x {+-1} (|Aut| = 108); no structure from a known family.

### N67 (27,14,5) C3^3
Lean and set OK. Marked Open in sds.json, but Gordon's own Prop 2.3 ("For v = 4n-1 a prime
power": P = nonzero squares, N = {0}, a (4n-1, 2n, n-2) SDS) at v = 27, n = 7 gives (27,14,5)
in (GF(27),+) = C3^3 (r4_paley27.py: signed counts all 5). The database applied Prop 2.3 only
to primes (all 32 "Paley and zero" keys have prime v). O9 is not affinely equivalent
(GL(3,3) + translation, +-) to the Paley set: a new set, but no new existence result.

### N68 (27,14,5) C3xC9
Lean and set OK. Open. Prop 2.3 needs (GF(27),+) = C3^3; D = P - {0} from a DS P would need a
skew Hadamard DS; O10's P is not a DS (intersection numbers 5, 6, 7). Stabilizer of O10 has
order 2. No known construction found.

### N73 (27,17,8) C3^3
Lean and set OK. Marked Open in sds.json, but Gordon's own Thm 4.1 (n = m^2, q = 2m-3 and
r = q+6 prime powers; G = (GF(q),+) + (GF(r),+); N = {(0,0)}, P = {chi(x)chi(y) = 1} u
{(0,y): y != 0}; a (4n-9, 2n-1, n-1) SDS) at m = 3 gives (27,17,8) in GF(3)+GF(9) = C3^3
(r4_gordon41.py: 16+, 1-, signed counts all 8). The database files this construction under
[3,9] (N74 "Yes, Prime Power Pair"), but (GF(9),+) = C3^2. (N74 itself is true: 108 sets in
C3xC9 by the census, so only the attribution is off.) O11 is not affinely equivalent to
Gordon's set.
