### 3. sc_rows.py: latent mismatch `j = max(j, 1)` (sc_rows.py, the line `j = max(j, 1)`)

cert() accepts a prime with v_p(n) = 1 and labels it j = 1, i.e. it tests "p | n" (its header
says so), but the Lean theorem demands p^(2j) | n, i.e. p^2 | n for j = 1. On the current table
this fires on 26,073 rows, all already `none`, e.g. N9 SDS(13,12,2,[13]) -> p=5, j=1, H=C13:
n = 10, 25 !| 10, so `hn` is false and that certificate cannot be discharged. It produces no
bad line in sc_rows.txt (no open row has such a prime; check_certs.py confirms p^(2j) | n on all
3,858), so nothing is wrong today, but the script's rule is not the theorem's rule: any re-run
on a changed table could emit unprovable certificates, and when a row has both kinds of prime
the min-(i,|H|) choice could pick the unprovable one. Fix: `if j == 0: continue`, or add a
j = 1 Lean variant with `hn : (p : ℤ) ∣ k - lam` (congr_of_autocorr already needs only p | n).
The mathematics of the e = 1 kills is fine (odd v_p(n) with p self-conjugate on a nontrivial
quotient kills outright); only the Lean link is missing.

### 7. Lean proof review: the global CharP instance and other details -- no defect

- `instance : CharP (AddMonoidAlgebra (ZMod p) H) p` (SelfConjugacy.lean:30) is global and
  exported. CharP is a Prop-valued class, so a second instance (Mathlib has none for
  AddMonoidAlgebra; grep of Mathlib finds only Subalgebra/FreeAlgebra/FractionRing ones) cannot
  create a non-defeq diamond. It only fires with [AddCommGroup H] [Fintype H] [Fact p.Prime] in
  scope; at worst it is a slightly over-constrained instance. Not a soundness or clash issue.
- `eq_zero_of_autocorr`: m = p^(2i) - (1 + p^i) in Nat; the `nlinarith` side needs
  1 + p^i <= p^(2i), true as p^i >= 2 (hp2). The final rewrite uses y = y^(p^i p^i) =
  y^(1+p^i) y^m = (y y^(p^i)) y^m = 0. Correct.
- `congr_of_autocorr` uses autocorrelation at g = 0 as well (ha for all g); the caller supplies
  it via p | n (n = p^(2j+2) q). `congr_pow_of_autocorr` takes mu' from a fixed g0 != 0 and
  needs `hH1`; j = 0 base is Int.modEq_one. Recursion is structural on j. All as in the paper
  proof; nothing wrongly gained (sec. 4).
- `not_hasSDS_of_selfConj` final step: with all a_h = a_0, e1: |H| a_0^2 = lam c and e2:
  |H| a_0^2 = k + lam (c - 1), so k = lam, against `hk`. |a_h| <= c from abs_contract_le. Correct.
- C5.md vs Lean: C5 says n > 0, Lean says k != lam (weaker hypothesis, still true: the proof
  never uses the sign); C5's "for some i" vs Lean's i > 0 loses nothing (i = 0 would need
  exp(H) | 2, where i = 1 works for odd p and p = 2 is excluded by p !| |H|).

## Literature

- Arasu, Gordon, Zhang, "New nonexistence results on circulant weighing matrices",
  arXiv:1908.08447 (HTML v3 opened): Thm 2.1 (Lander, group-ring form via Jungnickel 1992):
  G abelian of order n, p self-conjugate mod n (p-free part), A in Z[G], A A^(-1) = 0 mod p^(2a)
  => A = 0 mod p^a; they apply it to foldings (quotients), e.g. "3 is self-conjugate modulo 4
  ... row sums must be (9,0,0)". C5's lemma is this applied to a - tH on a quotient (lam != 0
  needs the constant t, hence p !| |H|). Consistent with the Lean form; nothing stronger claimed.

  arXiv:2608.22936 (HTML v2 opened): Thm 3.2: m | exp(G), m > 1, p^j = -1 mod m => v_p(n) even.
  No criterion with p^(2j) | n and a coset-size bound; matches C5.md ("covers only odd v_p(n)").
