## Findings

### 1. Restatement

D: G -> {-1,0,1} with D D^(-1) = n + lam G in Z[G], n = k - lam > 0, G abelian of order v.
phi: G -> H onto, H != 1, c = v/|H|, a = phi(D) in Z[H] (coset sums, |a_h| <= c,
a a^(-1) = n + lam c H). If p is prime, p does not divide |H|, p^i = -1 mod exp(H) for some i,
and p^(2j) | n, then a_h = a_h' mod p^j for all h, h'. If moreover p^j > 2c, all a_h are equal,
so chi(a) = 0 for chi != 1, contradicting |chi(a)|^2 = n > 0. No ambiguity found; the
"for some i" is the usual self-conjugacy (p not dividing m, so the p-free part of m is m).
Note: c = 1 (H = G) is allowed and is the plain Turyn test on D itself.

### 2. Proof check

Cases the proof must cover: p = 2 and p odd; j = 1 and j >= 2; v_p(n) even and odd; H = G
(c = 1) and H proper; exp(H) <= 2; the final step needs a nontrivial character.

ANT proof: correct. p does not divide m = exp(H), so p is unramified in Z[zeta_m]; p^i = -1
mod m puts complex conjugation in the decomposition group <Frob_p>, which (abelian Galois
group) is the same for every prime P over p, so conj(P) = P and v_P(alpha) = v_P(conj alpha).
2 v_P(alpha) = v_P(n) = v_p(n) >= 2j, so alpha in prod P^j = p^j Z[zeta_m]. Fourier inversion:
|H| a_h - s = sum_{chi != 1} chi(a) chi(h^-1) lies in p^j Z[zeta_m] intersected with Z = p^j Z
(a rational algebraic integer is an integer), and |H| is a unit mod p. For v_p(n) odd the same
line gives a contradiction outright; turyn.py uses floor(e/2), which is weaker, not wrong.

Elementary j = 1: correct. Frobenius is a ring endomorphism of the commutative F_p[H], a_h^p =
a_h, h^(p^i) = h^-1, so x^(p^i) = xbar; e = H/|H| is idempotent; x xbar = lam c H mod p and
H(1 - e) = 0, so y = x(1 - e) has y^(1+p^i) = 0; with N = ord of p mod exp(H),
y = y^(p^(N r)) = 0 for p^(N r) >= 1 + p^i (equivalently: F_p[H] is semisimple). So x = x e =
tH. Nothing used about |a_h| <= c or about the multiple of H, only p | n and H != 1 later.

Elementary j >= 2: correct as an induction on the lemma "x x^-1 = n + mu H, mu any integer,
p^(2j) | n => x = const mod p^j". Write x = tH + p b. Then
p^2 b b^-1 = n + mu' H, mu' = mu - t^2|H| - 2 p t eps(b). The coefficient at any h0 != 1 (needs
H != 1) gives p^2 | mu', so b b^-1 = n/p^2 + (mu'/p^2) H with p^(2(j-1)) | n/p^2; induction
gives b = t' H mod p^(j-1), so x = (t + p t')H mod p^j. The step needs the lemma for general
mu, which the j = 1 proof provides (the H-term is killed by 1 - e whatever its coefficient).

H = G: allowed (phi = id, c = 1, a = D); every step above holds. Final step: a = tH gives
chi(a) = t sum_h chi(h) = 0 for chi != 1 (exists since H != 1), but chi(a) chi(a)bar =
chi(n + lam c H) = n > 0. Correct. Threshold p^j > 2c is right: |a_h - a_h'| <= 2c; p^j = 2c
is (correctly) not used.

No gap found in either proof.

### 10. The claim is sound but not sharp: a free strengthening (R1)

The Fourier step gives more than "all a_h agree mod p^j": |H| a_h = s mod p^j, where
s = sum D = |P| - |N|, s^2 = n + lam v. So every a_h lies in the class t = s |H|^-1 mod p^j
(up to the sign of s, which is symmetric). Kill whenever [-c, c] holds at most one integer of
that class (rule SC is the case where it never holds two). This is how Arasu-Seberry get n/m
>= p^t (not 2n/m) for weighing matrices: lam = 0 gives p^t | s, t = 0, so some |a_h| >= p^t.
refuter/rule-sc/refined.py on the worktree's instances.csv: R1 kills 4,787 open Instances
(rule SC's 3,858 plus 929), 0 existing; on the 683 verified known sets the step
h a_h = s mod p^j holds in all 216 tests and R1 kills none of their parameters
(known_refined.py). R1-only examples: N1199 SDS(80,55,6,[2,40]), p = 7, H = C2 x C10
(7^1 = -1 mod 10), c = 4, s = 23, t = 23 * 20^-1 = 5 mod 7: only -2 in [-4, 4], so a = -2H,
contradiction. N194 SDS(37,36,8,[37]), p = 2, H = G (c = 1, 2^18 = -1 mod 37), s = 18 even:
every D_g even, so D = 0. (Smallest R1-only: N194, N523, N524, N544, N559, N1199, ...)
Not part of the claim under review; a proposal with the same proof plus one line.

### 12. A further cheap strengthening (R2), checked against E8

R2 adds the two linear facts of every contraction: sum a_h = s and sum a_h^2 = n + lam c. With
all a_h in V = {x in [-c, c], x = t mod p^j}, kill when no counts N_x >= 0 on V (sum N = |H|,
>= 2 values used) meet both (exact 3x3 solve after enumerating the rest; feasible_counts
agrees with brute force on 3,000 random inputs). refined6.py (|V| <= 6 only, for speed;
refined6_r2.out): 7,381 open Instances killed (rule SC alone 3,858; + R1 + R2), 0 existing.
Checks: on the 683 verified known sets R1/R2 kill nothing; e8_cross_r2.py: on all 47,938
(Instance, quotient, p) triples where E8 found a contraction vector and p qualifies, R1/R2
never declare that quotient infeasible. Proposal only; it would need the same Lean lemma.

### Verdict: SURVIVES

Tried: both proofs step by step (all cases incl. p = 2, j >= 2 induction, H = G, odd e,
threshold); turyn.py line by line; an independent reimplementation (identical 5,466 kills,
3,858 open); brute force of the lemma on 12 small groups (0 violations in ~19k tests, controls
fail as they should); 683 verified known SDSs (0 violations, 0 kills); E8 found-flags (0
conflicts); E4 (4 kills, all exhausted-empty). Literature: classical (Turyn 1965 Lemma 3 and
Theorem 6; Arasu-Seberry for weighing matrices, with the sharper n/m >= p^t), not applied to
Gordon's table by Gordon or He-Wu (He-Wu Theorem 3.2 is the odd-exponent case only).
Not a proof: Lean decides. Side results: R1/R2 strengthen it (7,458 open kills, section 13); 21 Gordon keys
store sets that are not SDSs.

## Literature

- Turyn, Character sums and difference sets, Pacific J. Math. 15 (1965) (msp.org PDF, read):
  Lemma 3 is the ANT step (p semiprimitive = self-conjugate mod m, |eta|^2 = n => p^(2b) || n
  and p^b | eta). Theorem 6 (v1 = 1 case) is the coset-sum step for subsets: m | chi(D) on the
  characters of a quotient of order v2, (m, v2) = 1 => v >= m v2. Corollary 1 gives
  v1 m <= 2^(r-1) v for difference sets (the (120,35,10) example).
- Arasu, Seberry, On circulant weighing matrices, Australas. J. Combin. 17 (1998) 21-37
  (scanned PDF, page 22 read as an image): Theorem 3, quoted from Arasu-Seberry 1996 (J. Combin.
  Des.): WC(n,k), p^(2t) | k, m | n, m = m' p^u, p^f = -1 mod m'; then 2n/m >= p^t if p | m and
  n/m >= p^t if p does not divide m. Rule SC is the SDS analogue of the p | m-free case, with the
  weaker bound p^t <= 2c (see 10 for why lam = 0 gives c).
- Arasu, Gordon, Zhang, arXiv:1908.08447v3 (HTML read): Theorem 2.1 (Lander, via Jungnickel
  1992): A A^(-1) = 0 mod p^(2a), p self-conjugate mod |G| => A = 0 mod p^a.
- Tan, Group invariant weighing matrices, arXiv:1610.01914 (ar5iv read): Result 2.6 (Turyn),
  Result 2.7 (Ma's lemma: chi(Y) = 0 mod p^a for chi != 1, cyclic Sylow p => Y = p^a X1 + P X2).
- Gordon, arXiv:2212.10630 (PDF text read): Section 5 uses multipliers and intersection numbers
  (contraction); no self-conjugacy test. The table's Open entries were not filtered by it.
- He, Wu, arXiv:2608.22936v2 (HTML read via fetch summary): Section 3 cites Turyn; Theorem 3.2
  concludes only that v_p(n) is even (the odd-exponent kill), Corollary 3.3 the cyclic case;
  no p^j bound, no coset congruence. The project's import.py applies exactly that (e odd only).
- Not found: any paper stating the bound for SDS or applying the even-exponent quotient bound
  to Gordon's table (searches: "circulant weighing matrix self-conjugate p^{2j} quotient",
  "group invariant weighing matrix self-conjugate p^j Ma's lemma", "difference set
  self-conjugate quotient p^j |U| Turyn"). Not opened: Arasu-Seberry 1996, Arasu-Ma JACO 14
  (2001) (server 503), Lander's book.
So: the method is classical (Turyn 1965; Arasu-Seberry 1996 for weighing matrices); for SDS
it is a direct transfer that, as far as I found, nobody applied to Gordon's table.
