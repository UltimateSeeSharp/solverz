## Findings

Restatement. C9: D an SDS (v, k, lam) on finite abelian G, n = k - lam squarefree, gcd(v, n) = 1.
Every natural t with gcd(t, v) = 1 that acts on G as p^f (some f >= 0, depending on p) for each
prime p | n is a multiplier (D^(t) = g D), and one translate of D is fixed by all such t at once.
C10: the same for the coset-sum vector of D on a quotient H with gcd(|H|, n) = 1 (integer vector,
autocorrelation n[g=0] + lam c). Gordon arXiv:2212.10630 Thm 5.1 (opened, HTML v1): G of exponent e,
D in Z[G], D D^(-1) = n mod G, gcd(v, n) = 1, t with gcd(v, t) = 1, t = p_i^f_i mod e; then t is
a multiplier and some translate of D is fixed by t (per t; C9's "all t at once" is stronger, via the
centroid). Natural reading tested: Lean `t • x` = t·x, hypothesis "acts as p^f on G" = "t = p^f mod e".

#### F2 (statement fidelity) — the Lean says what C9/C10 say, restricted to squarefree n; no vacuity found
Read literally (`Multiplier.lean:278-283, 391-396, 474-478, 485-489, 496-502`):
- `p ^ f • x` parses as `(p ^ f) • x` (`^` 75 > `•` 73); `t • x` is nsmul = coordinatewise t·x on
  prod ZMod m_i, the same map as `orbits.rs:92 scale`. `∀ x, t • x = p^f • x` <=> t = p^f mod e.
- f : ℕ (f = 0 allowed, i.e. t = 1 mod e): Gordon's integer f_i reduce to f >= 0 (p is a unit mod e).
- Quantifiers: `∃ a, ∀ t, ... ∀ x` — one translate for all admissible t at once (stronger than
  Gordon's per-t "some translate", correct via the centroid since gcd(s, v) = 1).
- `Nat.Coprime t |G|` is Gordon's gcd(v, t) = 1; it is redundant unless n = ±1 (for p | n,
  t = p^f mod e already forces gcd(t, e) = 1), and needed there (t = 0). Not a strengthening.
- Sign of n: `Squarefree (k - lam : ℤ)` excludes n = 0; for an SDS n >= 0 anyway (|lam| <= k), and
  for an integer vector on G with |G| >= 2, n = |chi(a)|^2 >= 0; n = ±1 is covered (no primes, all
  units). Multiplier sign: + (s = 0 would need v | n, i.e. v = 1).
- C10: hypotheses on t and coprimality are w.r.t. H (|H|, t·h on H), weaker than w.r.t. G; mu =
  lam·c is the right coset-sum autocorrelation (k + lam(c-1) = n + lam c at 0); the translate b in H
  lifts to a translate of D because φ is surjective. Tan arXiv:1610.01914 Result 3.2 (opened) has
  D in Z[G], so the integer-vector core is the literature statement too.
- Not in the Lean (needed by E10 rows): "sign sum +s" (negation keeps SDS and M-fixedness, C2) and
  the per-row facts gcd(t, v) = 1, t = p^f mod m_i for the residues E10 lists; all decidable per row.

#### F4 (E10 vs. the Lean hypotheses on t) — they match; the per-row obligations are small
`orbits.rs:64-89`: M = ⋂_{p|n} <p mod e> as residues t in [0, e). For such t:
- `Nat.Coprime t |G|`: t is a power of p mod e with gcd(p, e) = 1 (asserted at `orbits.rs:38`), so
  gcd(t, e) = 1, and e, v have the same prime divisors, so gcd(t, v) = 1. Holds; decidable per row.
- `∀ p prime, (p:ℤ) ∣ n → ∃ f, ∀ x, t • x = p^f • x`: t is in every <p mod e>, so t = p^f mod e, and
  e·x = 0 on G gives t•x = p^f•x. A row proof must (i) enumerate the primes of n (any prime p with
  p ∣ n is in `Nat.primeFactors n`), (ii) give f per p, (iii) turn `t • x = p^f • x` on
  prod ZMod m_i into t = p^f mod each m_i (nsmul is coordinatewise, `nsmul_eq_mul` on ZMod).
- `scale` (`orbits.rs:92-100`) is x_i·(t mod m_i) mod m_i, which is `t • x` on prod ZMod m_i.
- The generator shortcut (`orbits.rs:87`: p1^(N/|M|) generates the unique subgroup of order |M| of
  the cyclic <p1>) is correct, so M-orbits are exactly the orbits of {t•x : t in M}.
Remaining, not in the Lean: (a) n squarefree (F1); (b) the sign-sum +s normalisation (negation);
(c) the gcd(v, n) = 1 test is `IsCoprime (v:ℤ) n` in Lean — same thing.

## Literature

- Gordon, arXiv:2212.10630 (HTML v1, opened): Thm 5.1 as restated above; per-t translate; no
  squarefree or n > lam condition; gcd(v, n) = 1 required; no remark on n = 1.
- Tan, arXiv:1610.01914 (HTML, opened): Result 3.2 (McFarland, thesis Thm 9.1), same hypotheses, D in
  Z[G], conclusion "t is a multiplier ... D has a translate D' = Dg with D'^(t) = D'" (per t). Def 3.1
  allows a sign ±; for D in Z[G] with v > 1 the sign is + (s ≠ 0), as the Lean proves.
- Arasu, Gordon, Zhang, arXiv:1908.08447 (ar5iv, opened): Thm 4.1 (McFarland) for integer CW matrices
  (lam = 0, cyclic, integer entries): gcd(m, k) = 1, t = p_i^f_i mod m => multiplier. Consistent.
- Search "multiplier theorem ... squarefree n elementary proof group ring gcd(v,n)=1 McFarland":
  no source stating the elementary squarefree proof (none opened beyond the above).
