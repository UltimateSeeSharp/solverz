### 1. Restatement

- A5: if gcd(v, n) = 1 and M = {t mod e : t = p^f_p mod e for every prime p | n} (e = exp G), then some
  translate of D satisfies D(tx) = D(x) for all t in M; so D (up to translation and global sign) is
  a {-1,0,1} vector constant on M-orbits with sum s. An exhaustive search of such vectors that finds
  none kills the Instance. Natural reading; no ambiguity except "translate (or +-translate)": the
  search fixes sum = +s, which is WLOG because -D is an SDS with the same invariance.
- A3: v odd, lam even, d = v - k, d(d-1) < v-1 => no SDS (any abelian G).
- A7: for a quotient H with gcd(|H|, n) = 1, the coset-sum vector a (F3) has a translate in H constant
  on M_H-orbits (M_H as M with e = exp H); search such a with F3's constraints plus |a| <= c,
  sum|a| <= k <= sum maxm, parity; none on some H kills.

### 2. A5: the multiplier theorem (statement, hypotheses, the translate step)

Gordon arXiv:2212.10630 (HTML v1, opened 2026-11-06), Thm 5.1, attributed to McFarland's thesis via Tan's
Result 3.2: G abelian of order v, exponent e; D in Z[G] with D D^(-1) = n mod G (i.e. n + lam G);
gcd(v, n) = 1; n = p_1^e_1 ... p_s^e_s; t with gcd(v, t) = 1 and t = p_1^f_1 = ... = p_s^f_s (mod e).
Then t is a multiplier and some translate of D is fixed by t. Composite n is allowed by the statement
itself; nothing in it restricts to prime powers. Every A5 kill has gcd(v, n) = 1 (checked: oe rows come
from mult.py, which skips gcd > 1; my recheck recomputes M only for those), and D in {-1,0,1}^G is in Z[G],
so the hypotheses hold for every killed Instance.

Own proof check of the theorem (to not rely on Gordon's sketch): for chi != 1, chi(D) chi(D)bar = n, so
(chi(D)) is a product of primes over the p | n; t = p^f mod e puts sigma_t in the decomposition group
<Frob_p> of every such prime (p unramified, p not dividing e), so (sigma_t chi(D)) = (chi(D)) and
chi(D^(t)) = u chi(D) with |u| = 1 in every embedding (all conjugates of chi(D) have |.|^2 = n), u a root
of unity (Kronecker). S = D^(t) D^(-1) - lam G has chi(S) = n * root of unity for chi != 1 and
s^2 - lam v = n for chi = 1; Fourier inversion: |G| S(g)/n is a rational algebraic integer, and
gcd(n, v) = 1 gives n | S(g); T = S/n has T T^(-1) = 1 (all characters of modulus 1), so T = +-g, and
sum T = 1 gives T = g; multiplying D^(t) D^(-1) = n g + lam G by D gives D^(t) = g D. No positivity is
used (n_1 = n), which is why the SDS version holds without Hall's "p > lam".

Translate step (the referee's worry "t - 1 not invertible"): not needed. s^2 = n + lam v gives
gcd(s, v) = gcd(n, v) = 1, so x -> s x is a bijection of G; translate D so that its centroid
xi(D) = sum D(x) x is 0 (translation by g adds s g). Then D^(t) = g D gives 0 = t xi(D) = xi(g D) = s g,
so g = 0: the same translate is fixed by every t in M at once (the centroid choice does not depend on t).
Sign: -D is an SDS with the same invariance, so sum = +s (as orbit_exhaust.py and my recheck use) is WLOG.
Orbit-level autocorrelation: for M-invariant D, A(tg) = A(g), so one shift per orbit suffices.

Squarefree "elementary proof reusing A1" (report l.133-137): checked every step. Frobenius in F_p[G]:
D^(t) = D^(p^f) = D^{p^f} (power) mod p, valid because t = p^f mod e and D(x)^p = D(x) in F_p.
W = D^(t) D^(-1) = D^{p^f - 1}(n + lam G) = lam s^{p^f - 1} G mod p, and lam s^{p^f-1} = lam mod p
(Fermat if p does not divide s; if p | s then p | lam v so p | lam); f >= 1 can always be chosen.
W' = W - lam G: sum W' = s^2 - lam v = n; W' W'^(-1) = (n + lam G)^2 - 2 lam s^2 G + lam^2 v G = n^2
(uses G^(t) = G, W G = W^(-1) G = s^2 G). Squarefree n: W' = 0 mod n by CRT, sum of squares n^2 forces
W' = +-n g, sum W' = n gives +n g, then D^(t) = g D as above. Correct. The same proof works verbatim for
an integer vector a on H with a a^(-1) = n + lam c H, gcd(|H|, n) = 1 (A7): lam c sigma^{p^f-1} = lam c
mod p because p | sigma implies p | lam c |H|, p not dividing |H|.
No gap found.

### 3. A3: proof, script, small cases

Proof, every step. S = supp D, |S| = k, Z = G \ S, d = v - k. For g != 0, the nonzero terms of
sum_x D(x)D(x+g) are the x with x, x+g in S, each +-1 = 1 mod 2, so N_S(g) := #{x in S : x+g in S} = lam
mod 2 (also for lam < 0). Inclusion-exclusion over x in G: N_Z(g) = v - #{x in S} - #{x : x+g in S}
+ N_S(g) = v - 2k + N_S(g) = v + lam mod 2. v odd, lam even: N_Z(g) odd >= 1 for all v - 1 nonzero g, so
the d(d-1) ordered pairs of distinct elements of Z cover G \ {0}: d(d-1) >= v - 1. Cases: d = 0 (k = v,
then N_Z = 0, rule correctly fires), d = 1 (k = v-1: N_S(g) = v - 2 odd, so lam odd: consistent),
lam negative (parity unaffected), any abelian G (no structure used). v even, lam odd: an element u of
order 2 pairs the terms x and x + u of the shift-u sum, so lam is even (correct; no row has it,
checked over all 70,543 rows). Boundary: equality d(d-1) = v - 1 is allowed by the rule (strict <), and
it is attained by real sets: (7,4,0), (7,4,2), (13,9,0), (13,9,6) below. No gap.

Script: the ideator's producer of sp_hits.txt is not in the folder (only union.py reads it). Recomputed
from instances.csv (a3_check.py): 553 open hits, identical id set to sp_hits.txt; 0 'exists' rows hit;
1,349 'none' rows hit (consistent). d ranges 1..22 as claimed.
Small cases (a3_brute.py, every D in {-1,0,1}^G for C3, C5, C7, C9, C3xC3, C11, C13): every SDS found
obeys the rule (0 violations); boundary cases attained. Known sets (known_test.py, 683 verified):
the lemma N_Z(g) = v + lam mod 2 holds on every set and every shift, and the rule fires on none.

- He-Chen-Ge arXiv:2306.05631 (HTML): no "multiplier" or "orbit" anywhere. He-Wu arXiv:2608.22936 (HTML):
  "multiplier" only in the introduction (citing Gordon); no multiplier theorem. Nobody beyond Gordon
  applies McFarland to SDS as far as these show.
- A3: classical for lam = 0. Wallis-Whiteman, Bull. Austral. Math. Soc. 12 (1975) 433-447, sect. 2
  (text extracted from the Cambridge PDF): for odd n a weighing matrix W(n,k) needs
  (n-k)^2 - (n-k) + 1 >= n (OCR garbled, attributed to their ref. [2]); equality makes the zero pattern
  a projective plane. Arasu-Seberry, Australas. J. Combin. 17 (1998), Thm 1 (iii)-(iv) (OCR): the same
  condition for circulant W(n,k), equality => projective plane. A3 is this parity argument with an even
  lam instead of 0, and the ideator's "refinement" (equality => planar difference set) is their (iv).
  He-Wu Cor 4.5 (no (p^m, p^m - 1, lam)-SDS for lam even) is A3's d = 1 case, which is immediate: d = 1
  forces lam = v - 2 mod 2. No source found stating A3 for lam != 0.
- Searched, nothing found: the inequality for SDS with lam != 0; any SDS paper using multipliers for
  composite n other than Gordon's table.
