## Findings

### Statement (restated)
G abelian of order n(q+1), H ≤ G of order n, R ⊂ G with |R| = q such that every g ∉ H is a
difference r − r' (r, r' ∈ R) exactly λ_R = (q−1)/n times and no g ∈ H \ {0} is (an RDS
(q+1, n, q, (q−1)/n)). Then R meets q of the q+1 cosets of H once each; translate R so the missed
coset is H. Put D = 1_R − 1_H (values +1 on R, −1 on H, 0 elsewhere). Claim: D is a signed
difference set iff (q−1)/n = n+2, i.e. q = (n+1)^2, with (v,k,λ) = (n((n+1)^2+1), (n+1)^2+n, n).
Existence: for every prime power s = n+1, Bose's affine RDS {x ∈ GF(s^4)* : x + x^(s^2) = 1}
(q = s^2) in Z_{q^2−1}, reduced mod v = n(q+1), is such an R in Z_v; so a cyclic SDS
((s−1)(s^2+1), s^2+s−1, s−1) exists for every prime power s.
Ambiguity: "iff" silently needs n ≥ 2 (see F1). Tested reading: n ≥ 2, G abelian, the SDS
definition of README (D D^(−1) = (k−λ) + λG).

### Findings

#### F1 The group-ring derivation is correct for n ≥ 2; "iff" is false for n = 1 (degenerate, harmless)
Steps checked by hand: (a) two elements of R in one coset would give a difference in H \ {0},
which has coefficient 0 in RR^(−1); so R meets each coset at most once, and |R| = q of q+1 cosets
means exactly one is missed; translating keeps RR^(−1), so after translation R meets every coset
except H exactly once and RH = G − H. (b) H^(−1) = H, so RH^(−1) = G − H and HR^(−1) = (RH)^(−1) =
(G − H)^(−1) = G − H; HH^(−1) = nH. (c) Sum: q + λ_R(G − H) − 2(G − H) + nH. (d) Coefficients:
identity q + n = |R| + |H| = k (R ∩ H = ∅, so D is a genuine {0,±1} map with support k); h ∈ H\{0}:
n; g ∉ H: λ_R − 2. Constant off-peak ⟺ n = λ_R − 2 ⟺ q = (n+1)^2, then λ = n and
k − λ = q (README's D D^(−1) = (k−λ) + λG). Counting check (Σ D)^2 = (q−n)^2 = k + λ(v−1) holds as
the identity (n^2+n+1)^2 = n^4+2n^3+3n^2+2n+1.
Gap in wording: for n = 1, H \ {0} is empty, the H-condition is vacuous, and R − H is an SDS
(q+1, q+1, q−3) for every q (e.g. q = 2: D = (−1, 1, 1) in Z_3, λ = −1, q ≠ 4). The claim's "iff"
needs n ≥ 2; the q = (n+1)^2 direction and all table members (n ≥ 2) are unaffected.
Numerical test (`identity.py`, output `identity.out`): for every prime power q ≤ 64 and every
n | q − 1 (141 pairs), the Bose RDS projected to Z_{n(q+1)} was checked as an RDS (q+1, n, q,
(q−1)/n), translated to miss H, and the autocorrelation of R − H (and of R + H) compared
coefficient by coefficient with q + (λ_R ∓ 2)(G − H) + nH: 282 cases, 0 mismatches. Constant
off-peak correlation occurs exactly for n = 1 (all q) and q = (n+1)^2 for R − H: (20,11,2),
(51,19,3), (104,29,4), (300,55,6), (455,71,7). Sanity twin: R + H is constant exactly for
q = (n−1)^2, giving the Singer difference sets (15,7,3), (40,13,4), (85,21,5), (156,31,6),
(400,57,8), (585,73,9) (PG(3,s) parameters), as the classical "affine RDS + H = Singer" says.

#### F2 Bose's RDS and its projection: correct; own code rebuilds all six table-relevant members (survives)
Theory: in GF(q^2)* = <α> ≅ Z_{q^2−1}, R = {x : x + x^q = 1} is Bose's (q+1, q−1, q, 1) RDS relative to
GF(q)* = multiples of q+1. With q = s^2, s = n+1 a prime power, q − 1 = n(n+2), so GF(q)* has the
subgroup U of order n+2, = multiples of v = n(q+1) (v | q^2 − 1 = (q+1)n(n+2)); i ↦ i mod v is the
quotient by U, cyclic. Images are distinct (x = cy, c ∈ GF(q)*, Tr x = Tr y = 1 forces c = 1), and the
projection lemma gives a (q+1, n, q, (n+2)·1) RDS relative to GF(q)*/U = multiples of q+1 in Z_v (order n).
Own code (`bose.py`, `run_family.py`, output `run_family.out`; own primitive-polynomial search and GF(p^e)
arithmetic, nothing imported from e10-objects): for s = 2, 3, 4, 5, 7, 8, 9 (n = 1, 2, 3, 4, 6, 7, 8,
fields GF(16) … GF(6561)): |R| = q, R is a (q+1, q−1, q, 1) RDS in Z_{q^2−1} (all differences counted),
the projection has q distinct elements and is a (q+1, n, q, n+2) RDS in Z_v, misses exactly one coset;
translated, R − H is an SDS (5,5,1), (20,11,2), (51,19,3), (104,29,4), (300,55,6), (455,71,7), (656,89,8),
checked at every shift g ≠ 0 by Σ_x D(x)D(x+g) and by DFT (|D^(χ)|^2 = k − λ for all χ ≠ 1, worst error
6.7e-11). Checker validated: it rejects 20/20 broken variants of each set (sign flip, moved element,
wrong λ) (`identity.py`). Sets saved in `family_sets.json`.
Objects (`objects_check.py`): O38 (455,71,7) and O39 (300,55,6) pass the same checks; in each the minus set
is the subgroup of order n = multiples of q+1, the plus set misses it and is a (q+1, n, q, n+2) RDS;

coefficient q + n = k, off-peak n on H and (q−1)/n − 2 off H) and was matched coefficient by

are correct; my own code rebuilds the SDSs for n = 2, 3, 4, 6, 7, 8 (and n = 1), valid at every

N24175 (Z5 × Z60) is untouched (needs a (50,6,49,8) RDS there; undecided). Table 1 sporadic claim
confirmed. Origin: no publication found; credit the project's E10-objects refuter (2026-11-06),
