### N14471 (243,82,1,[3,3,3,3,3]): the cited Example 4.2 is not a signed set; Thm 4.1 with x1 = 0 is
- HCG Thm 4.1: m = 2 (even), G = G0 x G1 x G1 = Z3 x Z3^2 x Z3^2 = (F_{3^5},+) = Z3^5 = the key;
  D = (x0,0,G1) + (0,G1,x1) + (0,D',D'), x0 != 0, "x1 in G1"; parameters (3^5, 3^4+1, 1) = the key.
- Example 4.2 as printed (x0 = 1, x1 = (1,0), P' = {(1,1),(2,1),(1,2),(2,2)}): D' is a (9,8,-1) SDS
  (checked), but supp D' = G1 - 0 contains x1, so (0,G1,x1) and (0,D',D') overlap on {0} x (G1-0) x {x1}.
  build.py hcg41: the group-ring sum has coefficient 2 at (0,0,1,1,0), (0,0,2,1,0), (0,1,0,1,0),
  (0,2,0,1,0) and 0 at four more points (70 nonzero, not 82). It is not a signed set; the paper's count
  |D| = 2|G1| + |D'|^2 assumes disjointness, true only for x1 = 0 (the character computation, which never
  uses disjointness, still holds, so the defect is in "D is a signed set", not in DD^(-1)).
- With x1 = (0,0) (allowed by "x1 in G1"): 82 coefficients +-1 (50+, 32-), direct and FFT pass in Z3^5.
  So Thm 4.1 at m = 2, x1 = 0 settles N14471; Example 4.2's x1 = (1,0) is a misprint/error.
- Open in sds.json and instances.csv. Verdict: FLAWED as cited (Example 4.2 fails); the claim that a
  published construction settles N14471 stands, via Thm 4.1 with x1 = 0; credit must cite that.
