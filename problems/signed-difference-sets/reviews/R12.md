## Findings

Statement under attack (restated): for every entry (row, cert) of the 13 generated lists,
`ScCert.Kills` holds by kernel evaluation, and `ScCert.not_hasSDS` turns that into
`¬ HasSDS (ZMod m1 × ... × ZMod mr) k λ` for exactly the instances.csv row N<id>. The rows must
be the 6,071 `open` rows, each once, with factors, k and λ copied exactly. C6's arithmetic part
(`MomentsOk`, `not_hasSDS_of_moments`) must be a valid necessary condition.

### 1. Row data in the 13 chunks vs instances.csv -- pass

`rows_match.py` (this folder) parses the Lean text of Part01..Part13 itself (not sc_certs.txt):
6,071 entries, every raw list line matched by the entry regex, ids strictly increasing, no
duplicate id. For every entry: instances.csv row N<id> exists, status `open`, factor list equal
element by element and in the same order as the key, k and λ equal as strings (sign included;
no kill has λ < 0), and prod(factors) = v of the key. All 13 files are byte-identical outside
the entry lines up to the part number (md5 of the template part: 1 class of 13), so each ends in
the same `partNN_kills := by decide +kernel` and `partNN_not_hasSDS := ScCert.not_hasSDS ...`.
Of 22,450 open rows, 6,071 are in the chunks (3,858 tagged C5 in sc_certs.txt, the same count as
the earlier C5 refuter's set, and 2,213 C6).

### 2. Kill sets: Lean mirror, every admissible certificate, sc2.py -- pass

`leanmirror.py` re-implements `ScCert.Valid`, `ScCert.Kills`, `MomentsOk` from the Lean text
(Euclidean `/`, `%`; `IsPrimeTD`; `Dvds` factor by factor). `test_mirror.py`:
- the mirror accepts all 6,071 chunk entries (3,858 by 2c < p^j, 2,213 by the moments test),
  so `decide +kernel` has nothing false to prove;
- over EVERY certificate the theorem admits (each prime p with p^2 | n, each 1 <= j <= v_p(n)/2,
  each coordinatewise ds, least i, both signs), the kill set on open rows is exactly the 6,071
  chunk ids (difference 0 both ways), and on the 156 `exists` rows it kills nothing.
`cmp_sc2.py` / `cmp_sc2.out`: sc2.py's own `triple` logic minus the R2dp search, over all
quotient types and qualifying p (max j, s >= 0): every one of the 2,213 C6 rows is killed there
by R1/R2div/R2basic (0 suspect rows: none where Lean's moments test fires and sc2 stays open).
The other direction leaves 398 open rows that sc2 kills by R1 alone (only one value of the
residue class lies in [-c, c], e.g. N194 SDS(37,36,8,[37]): c = 1, q = 2, s = 18, t = 0, so
a = 0) but that neither 2c < p^j nor the moments test reaches; these are not a soundness issue,
they are C14's job (N194 is box_certs.txt's first line). R2div never fires (as C6.md says).

### 3. C14 (Box): row data, kill set, sc2.py -- pass; claim "exactly sc2's R2dp surplus" holds

`test_box.py` / `test_box.out` (this folder; mirror `box_ok`, `box_kills` in leanmirror.py from
Box.lean / BoxCheck.lean). BoxRows Part01..03: 1,387 entries, no id shared with the 6,071
SelfConjugacyRows ids, every entry equal to instances.csv row N<id> (factors in order, k, λ,
status `open`, prod = v), equal to box_certs.txt field for field, the 3 files byte-identical
outside the entries up to the part number. The mirror of `BoxKills` accepts all 1,387.
Over every admissible certificate (as in sec. 2) on open rows: box kills 7,458 rows, of which
1,387 are not C5/C13 rows, and those are exactly the BoxRows ids (difference 0 both ways); on the
156 `exists` rows it kills nothing. Against sc2.py's full verdicts (sc2_all.out, keys checked
equal to today's instances.csv): sc2 kills 7,458 open rows, C5 + C13 + C14 chunks = 7,458, symmetric
difference 0. sc2's first reason on the 1,387 box rows: R2dp 1,069, R1 318 (the R1-by-residue rows
of sec. 2 land here). So C14.md's count claim is right, and no box kill is a row sc2 leaves open.

### 4. Brute force and real sets against MomentsOk / BoxOk -- pass

- `lemma_vec.py`: every congruent, not-all-equal integer vector passes the mirrors of
  `MomentsOk` and `BoxOk` (any c >= max|a|): exhaustive y in [-3,3]^N (N <= 4) / [-2,2]^5,
  q in {1,2,3,4,5,7,8,9}, every t, plus 200,000 random vectors (N <= 40, q <= 27): 888,951 passes,
  0 failures; all 3,861 constant vectors fail `MomentsOk` (B = 0), as they must.
- `brute_small.py 15` / `brute15.out`: every SDS on every group of order <= 15 (19 groups,
  3,144 sets, 104 parameter triples). For each, every admissible certificate (29): neither
  `Kills` nor `BoxKills` holds for ±s; for each of the 1,458 (set, certificate) pairs the actual
  coset sums are congruent mod p^j and pass `MomentsOk` and `BoxOk` at (Σa, a_0 mod q).
- `objects_test.py` / `objects_test.out`: O1-O32 re-verified as SDS on every shift; 14
  admissible (object, p, j, quotient) pairs, the true coset sums pass congruence, `MomentsOk`,
  `BoxOk`, and the mirrors reject the certificate. Controls: in 13 of 17 non-self-conjugate
  (p, quotient) pairs the coset sums are NOT congruent mod p^j, so the self-conjugacy
  hypothesis is doing work. (Few admissible pairs: most objects are 2-groups with n a power of 2.)
