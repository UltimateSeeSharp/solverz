### 3. Parameter-level check: no published family has any of these parameters

Since any set a family produces has that family's (v,k,λ), checking parameters is decisive:

  33 is not; v = 361 needs k ∈ {90j, 90j+1}, 316 is not.

- Ordinary DS families (Singer, Paley, twin prime powers, Menon–Hadamard): k(k−1) ≠ λ(v−1) for all seven
  triples, and every set has minus signs, so none is an ordinary DS.
- Products: if D₁ ⊗ D₂ is an SDS then χ trivial on one factor forces s_i² = n_i, i.e. λ_i = 0, and then
  λ = 0. All 14 have λ ≠ 0, so no direct product of SDSs gives them; HCG's 3-group product is (3^{2m+1},…).

### 4. N170 SDS(36,11,2,[6,6]): a PDS-minus-identity set; credit the method

Both found sets (r4.out and e9-200.out) are, after translating the single minus element to 0, D = P − 0 with
P a regular (36,10,4,2) PDS (`structure.py`): P = (H₁ ∪ H₂) \ {0} for two order-6 subgroups with trivial
intersection, the Latin-square-type PDS L₂(6) (rook graph 6×6). E.g. r4: H₁ = {(i,−i)}, H₂ = {0}×Z₆ after
translating by −(5,1); e9: H₁ = {0}×Z₆, H₂ = {(i,3i)} after translating by −(0,3).
Proof in one line: (H₁+H₂−3)² = 6H₁+6H₂+2G−6H₁−6H₂+9 = 9 + 2G. In general any regular PDS with λ_P − μ_P = 2
gives P − 0 as an SDS (v, k_P+1, μ_P); He–Wu use exactly this identity in the proof of their Thm 5.3, but
state it only for C₂^{2m} (Desarguesian spreads). For L_r(m), λ − μ = m − 2r, so m = 2r+2: r = 2, m = 6 here.
C₆×C₆ is the only abelian group of order 36 with two trivially-meeting C₆ subgroups whose product is G;
for C₃×C₁₂ the found N169 set is not of this form (no translate makes its support minus 0 a PDS; with one
minus and ten plus elements, P ± 0 is the only PDS shape possible), so N169 needs its own origin.
Origin for N170: not new as an idea; credit "P − 0 for the L₂(6) Latin-square PDS (identity as in He–Wu,
proof of Thm 5.3)". The entry is still open in the table, so it remains a valid table fix.

## Literature

Construction (my derivation, `rds32.py`): H ≤ G of index 2, t ∉ H, X a (4,4,4,1)-RDS in H relative to K
(|K| = 4, XX⁻¹ = 4 + H − K, so XK = H). With A = H − 2X (all 16 elements of H marked, 4 minus):
- D = A + tK is an SDS(32,20,4): AA⁻¹ = 4XX⁻¹ = 16 + 4H − 4K, KK⁻¹ = 4K, and
  tKA⁻¹ + t⁻¹AK = t(2H) + t⁻¹(2H) = 4·tH (works for t of order 2 or 4, t² ∈ H);
- D' = A + t(H − K) is an SDS(32,28,12) (same computation: 6H + 6H on tH, 16 + 12H on H).
Exhaustive check over all abelian groups of order 16 and all K of order 4: a (4,4,4,1)-RDS exists only in
C₄×C₄ relative to 2(C₄×C₄). So it gives both parameter sets exactly in [2,4,4] and [4,8] (built and verified
on G, incl. t = (0,1) of order 8 in C₄×C₈ with H = {(a,2b)}). The found N137 and N139 sets have this shape
(profile on some index-2 H: 16 marked with 4 minus, other coset = complement of a K-coset, all plus;
`probe32.py`). This matches r4's pattern for (32,28,12): yes in [2,4,4], [4,8]; no in the other five (a weak
consistency check of r4's "no" rows, not a proof).

10/10 marked per coset), so for N127, N128, N129, N131 the search is the only origin I can find; for N130,
N132 the RDS set above is an alternative, simpler witness. Lifting test (`lift28.py`): no found (32,20,4) set
