#### F3. Structure of O12 confirmed independently -- holds
`R3/n35840_cyc.py` (own GF(361) = GF(19)[x]/(x²−2), generator 1+9x, own
classes C_c = {g^e : e ≡ c mod 8}, |C_c| = 45). D = −({0} ∪ all classes but C_i, C_j) + C_j
is a (361,316,141) SDS exactly for the 16 pairs (i, j) with j ≡ i−1 or i+5 (mod 8) (my
generator; E6's "C6 zero, C7 plus" is the same shape under another generator). The 16 are
one orbit under multiplication and Frobenius (x^19 sends class c to 3c). Each of the 16 is
mapped onto −O12 by exactly 45 GF(19)-linear maps (the stabilizer: multiplication by C0),
720 in all. So O12 = −(that cyclotomic set) up to a linear isomorphism GF(361)+ → Z19²:
P = {0} ∪ six classes (271), N = one class (45), zero = one class (45), N and the zero
class adjacent. In group-ring terms (sign flipped) D = G − C_i − 2C_j, and D is an SDS iff
|η_i + 2η_j|² = 175 for all rotations of the order-8 Gauss periods η (since χ(G) = 0).
