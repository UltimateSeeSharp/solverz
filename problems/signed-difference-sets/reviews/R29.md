### Restatement

C27: an SDS (v,k,λ) on G, n = k−λ > 0, a surjection G → Z_m (fibres c = v/m), gcd(m,n) = 1, F d = m with every
t = 1+Fu (u<d) a unit mod m and ≡ p^e (mod m) for every prime p | n. Then φ(m)·n ≤ m·F·c². Rows: kill when m F c² < φ(m) n.
C28: 4 | n, a surjection G → Z_(2r) × K (fibres c), 2^i ≡ −1 on K, (2,r) with C21's cyclotomic facts; coset sums W on
Z_r × K are even and Z = W/2 meets |Z| ≤ c, ΣZ² = (k+λ(2c−1))/4, autocorrelation λc/2, ΣZ = ±s/2, Σ|Z| ≤ k/2,
Σ|Z| ≡ s/2 (mod 2); no such Z ⇒ no SDS. Both readings are unambiguous; tested as stated.

### C27 findings

1. Mathematics — SURVIVES. Re-derived by hand: for a unit a and t = 1+Fu, substituting h → t h in χ_a(Y_b) (Y_b fixed by
   t, C10) gives χ_a(Y_b) = Σ Y_b(h) ζ^{ah} w^u with w = ζ^{aFh} a d-th root of unity; averaging over u < d leaves exactly
   the h with aFh = 0 ⇔ Fh = 0 (a a unit); |{h : Fh = 0}| = F; Parseval over all a ∈ Z_m bounds the φ(m) unit terms (each
   = n) by m·Σ_S Y² ≤ m F c². The set {1+Fu} need not be a group; the argument only uses each t separately. C10's sign:
   X^(t) = −X g would force s = 0, and s² = n + λv would then give m | n, impossible with gcd(m,n)=1, m>1; so the
   translate-fixed form of C10 is the right one. Lean (`IsSDS.totient_mul_le`, UnramifiedDescent.lean:200–231) feeds C10
   exactly this t-condition (t ≡ p^e on Z_m, exp Z_m = m) and gcd(m,n)=1. Numerical check on the 104 objects:
   444 (quotient, form) pairs with gcd(m,n)=1 — a translate fixed by the whole multiplier group exists in all 444, and
   χ_a(Y_b) = χ_a(Y_b restricted to S), |χ_a|² = n for every unit a and admissible F (`objects_check.py`).
2. Comparison with Schmidt/Tan — SURVIVES, with a wording correction. Coprimality of every 1+Fu with m forces rad(m) | F
   (if p | m, p ∤ F, some u < p ≤ d has 1+Fu ≡ 0 mod p), so m/φ(m) = F/φ(F) and the bound reads n ≤ c² F²/φ(F), Tan's
   Result 2.12 with the multiplier F in place of F(m,n). But C27 is not merely the unramified case of Schmidt's bound: on
   N9792 SDS(200,139,18,[2,100]) (m=100, n=121, ⟨11⟩ mod 100 = 1+10Z, F=10, c=2: 4000 < 40·121 = 4840) Tan's Def 2.10 gives
   F(100,121) = gcd(100, 2³·5) = 20 and the F-bound allows n ≤ 4·400/8 = 200, no kill. The gain is real and comes from
   C10's single translate (McFarland–Rice), which removes the root-of-unity cocycle that costs Schmidt's 2-adic exponent.
   Independent hand check: descend to Z_10, 4 units × 121 = 484 > 10 · (10 · 2²) = 400. 258 of the 259 rows are also
   killed by Schmidt's F-bound (`scratch/c26/fbound_kills.txt`); N9792 is the one that isn't. The claim's line "This is
   Schmidt's field-descent bound ... for n prime to m" should say "at least as strong as".

   n ≠ 0; n < 0 is impossible for an SDS anyway), gcd(m, n.toNat), F | m (F = 0 excluded by 1 < m), u ranges over
