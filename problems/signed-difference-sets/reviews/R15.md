### Restatement

D an SDS (v, k, λ) on abelian G, n = k − λ, s² = k + λ(v − 1), R = 2-rank of G (number of
even invariant factors), 1 ≤ r ≤ R, φ : G → C₂^r onto. Every character χ of C₂^r is ±1-valued;
pulled back to G, χ(D) ∈ ℤ and χ(D)² = n for χ ≠ 1 (so n = m², m ≥ 0). Summing χ(D) over all
2^r characters: s' + m·T = 2^r·a₀ with s' = ΣD ∈ {±s}, T = Σ_{χ≠1} ε_χ, a sum of 2^r − 1 signs
(odd, |T| ≤ 2^r − 1). Kill: no (s', T) with 2^r | s' + mT; closed form
min(v₂(s), r) ≠ min(v₂(m), r) (v₂(0) = ∞). Unambiguous; tested as read.

### F1 Proof, step by step: correct

- Real characters: χ ∈ Ĝ is ±1-valued iff χ² = 1 iff χ kills 2G, i.e. factors through
  G/2G ≅ C₂^R, R = number of even invariant factors (true for any cyclic decomposition, so
  counting even entries of the key is right). Any onto φ : G → C₂^r, r ≤ R, exists.
- χ(D)² = Σ_{x,y} D(x)D(y)χ(x)χ(y) = Σ_{x,y} D(x)D(y)χ(y − x) (χ(x) = χ(x)⁻¹)
  = Σ_g χ(g)·c(g), c(0) = k = n + λ, c(g) = λ (g ≠ 0), so = n + λ·Σ_g χ(g) = n for χ ≠ 1.
  Equivalently χ applied to D D⁻¹ = n + λG with χ(D⁻¹) = conj χ(D) = χ(D).
- χ(D) ∈ ℤ, so n = m² (n not a square, n < 0: no SDS when R ≥ 1, He–Wu Thm 4.2).
- Σ_{χ∈Ĥ} χ(D) = Σ_x D(x) Σ_χ χ(φx) = 2^r·a₀ (orthogonality on C₂^r); χ = 1 gives ΣD = s'
  with s'² = s² (C1).
- T = sum of 2^r − 1 signs: odd, |T| ≤ 2^r − 1, every odd value in range reached; the odd values in
  [−(2^r−1), 2^r−1] cover every odd residue mod 2^r, so the range bound never matters.
- Closed form: v₂(mT) = v₂(m) for odd T, and {mT mod 2^r : T odd} = residues of exact valuation
  v₂(m) if v₂(m) < r, {0} otherwise. So a solution exists iff min(v₂(s), r) = min(v₂(m), r).
  s = 0: needs 2^r | m, matches (v₂(0) = ∞). m = 0 (n = 0, only D = ±G): needs 2^r | s = v,
  always true since 2^R | v; matches. Checked mechanically too: closed form = T-search for every
  r ≤ R on all 70,543 rows of instances.csv (`rows.py`, assertion).
- Monotone in r: if min(a, r) ≠ min(b, r) then they differ at every r' ≥ r. So the rule reduces to
  the single test at r = R; smaller r adds nothing. r = 1 never fires when v is even
  (s² − m² = λv even gives s ≡ m mod 2).
- Not used anywhere: λ ≠ 0, k < v, n > 0. Lean hint: with s, m as `Nat.sqrt` junk values the rule
  stays sound, since non-square S or n leaves no SDS anyway (C1, He–Wu 4.2); R = 0 must give no
  kill (no r ≥ 1).

### Limits of the truth tests

The rule can fire only with R ≥ 3, s, m, k, λ even (F4); of the exhaustively searched groups only
C₂³, C₂²×C₄, C₂⁴ have R ≥ 3, so the brute force mainly tests the identities the rule rests on
(χ(D)² = n, Σχ(D) = 2^R·a₀), which hold on every set. The firing regime itself is tested by the
proof and by the high-rank objects (O14, O28, O32, O33) sitting exactly on the boundary
min(v₂ s, R) = min(v₂ m, R).
