### Restatement

D: G -> {-1,0,1} an SDS (v,k,lam), n = k - lam, s^2 = k + lam(v-1) (so sum D = s' in {s,-s}). phi: G ->> H with 3H = 0,
N = |H| = 3^a. For psi in Hom(H, C*), psi(D) = sum_x D(x) psi(phi x) lies in Z[w] = {A + Bw}; for psi != 1 its norm
A^2 - AB + B^2 = |psi(D)|^2 = n. N odd, so psi != 1 implies conj psi = -psi != psi; conj pairs share the trace
t = psi(D) + conj psi(D) = 2A - B. Inversion: sum_psi psi(D) = N a0 (a0 = sum of D over ker phi); taking traces and halving,
N a0 = s' + sum over the (N-1)/2 pairs of t, each t in T(n) = {2A - B : A^2 - AB + B^2 = n}. Kill: for both s' = +-s, no
choice (with repetition) of (N-1)/2 elements of T(n) makes s' + sum = 0 mod N. Unambiguous; the relaxation (traces chosen
independently from T(n)) only weakens the rule. Lean's `EisKills N s n` is exactly this, with T(n) given as the list
`eisTraces n` = {+-t : t <= M, t^2 + 3b^2 = 4n for some b <= M}, M = eisBound n (>= sqrt(4n)).

### F1. The math, step by step (survives)

- Values: psi(h)^3 = psi(3h) = 1, so psi(h) in {1, w, w^2 = -1 - w}; psi(D) = A + Bw with A, B in Z.
- Norm: psi(D) conj psi(D) = sum_g psi(phi g) sum_x D(x) D(x+g) = n + lam sum_g psi(phi g) = n, the last sum 0 because
  psi o phi != 1 (phi onto). With conj w = -1 - w: (A + Bw)(A - B - Bw) = A^2 - AB + B^2. Holds for every psi != 1.
- No real psi != 1: psi = conj psi = psi^{-1} gives psi^2 = 1, with psi^3 = 1 so psi = 1 (N odd).
- Trace: (A + Bw) + (A - B - Bw) = 2A - B; t^2 + 3B^2 = 4n, so |t| <= 2 sqrt(n), t = B mod 2 (forced mod 4).
- Inversion: sum_psi psi(D) = sum_x D(x) sum_psi psi(phi x) = N a0 (real). Traces: 2N a0 = 2s' + sum_{psi != 1} t_psi
  = 2s' + 2 sum_pairs t, hence N a0 = s' + sum_pairs t with exactly (N - 1)/2 pairs. The pair traces need not be
  distinct and are chosen with repetition in the kill, so it only relaxes; no case dropped.
- N = 3 never kills unless T(n) is empty: 3 | v gives s^2 = k + lam(v-1) = n mod 3 and t^2 = 4n = n mod 3, so t = +-s
  mod 3 and -s' is reachable. Consistent with all 144 rows using N = 9 (141) or 27 (3), none N = 3.
- Numerically (F3): norm, conj pairing (psi -> -psi maps A + Bw to (A - B) - Bw), no real nontrivial psi, trace in T(n),
  sum of traces = 2 N a0 and s' + pair sum = N a0 for every C3^a sub-quotient: 0 violations on all objects with a
  factor divisible by 3 and on the constructed sets of F4; a one-sign perturbation of O7 is caught (53 violations).

### F4. What the 144 kills really use: the ramified prime above 3 (observation, not a flaw)

`classify.py`: in every one of the 144 rows all traces are divisible by 9 (n = 27: T = {0, +-9}; n = 81: {+-9, +-18};
n = 243 at N = 9: {0, +-27}) and 9 does not divide s (141 rows at N = 9: 16 with 3^3 || n, 122 with 3^4 || n, 3 with
3^5 || n), or 27 does not divide s (3 rows at N = 27, 3^5 || n, T = {0, +-27}). The pair count never matters.
Explanation: (1 - w) is the only prime above 3 in Z[w], ramified and fixed by conjugation, so 3^e || n forces
v_(1-w)(psi(D)) = e for every psi != 1, and N a0 - s' = sum_{psi != 1} psi(D) lies in (1 - w)^e cap Z = 3^ceil(e/2) Z:
3^min(a, ceil(e/2)) | s. `ramified.py`: over all 70,543 csv rows (a <= min(3-rank, 6)) C20 kills exactly the rows that
"n is not a norm of Z[w], or 3^min(a, ceil(e/2)) does not divide s" kills (10,624 both, 0 only one). So on this table C20
is the self-conjugacy (Turyn-type) congruence for p = 3 dividing v; the project's C5 misses it because its certificate
needs p^i = -1 mod exp(H), impossible for p = 3 on a 3-group (`ScCert`). Consequence for recording: correct, but the
journal/README should not present the 144 as a new method; cite it as the classical congruence (see Literature).

## Literature

- He, Wu, arXiv:2608.22936v2 (HTML opened): Thm 3.2 needs p^j = -1 mod m with m | exp(G), conclusion v_p(n) even;
  its Lemma 2.2 assumes p does not divide m. No Z[w], no congruence on s modulo a power of p dividing v. The p | m case
  that C20 uses is not there (consistent with the 144 rows being open after their filters).
- Yayla, arXiv:1408.6883v2 (HTML opened), Sec. 2: Turyn's definition, q self-conjugate mod u = q^r w (gcd(q, w) = 1)
  when q^j = -1 mod w, and Lemma 1 (Turyn, Pacific J. Math. 15 (1965) 319-346): then every prime ideal above q in
  Z[zeta_u] is fixed by conjugation. For u = 3^a, w = 1: 3 is self-conjugate mod 3^a, the input of F4's argument.
- Arasu, Gordon, Zhang, arXiv:1908.08447 (ar5iv opened), Sec. 2: same definition with v(n) the p-free part; Thm 2.1
  (Lander; group-ring form by Jungnickel 1992): A A^(-1) = 0 mod p^(2a) and p self-conjugate mod n give A = 0 mod p^a.
  Per character on H = C3^a this gives psi(D) = 0 mod 9 when 81 | n, hence 9 | s: that covers the 125 rows with
  3^4 or 3^5 || n at N = 9. The other 19 (3^3 || n at N = 9; 3^5 || n at N = 27) need the half-step from the ramified
