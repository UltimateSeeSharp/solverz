### 1. Restatement

Setting: D an SDS (v, k, lam) in abelian G, n = k - lam > 0, s >= 0 with s^2 = n + lam v; H = G/K
a quotient (|H| = h > 1, exp m, c = v/h), a_h the coset sums: a a^(-1) = n + lam c H, sum a = +-s,
|a_h| <= c, m_h = #marked in coset h with |a_h| <= m_h <= c, m_h = a_h mod 2, sum m_h = k.
Lemma (SC, refuter SURVIVES): p prime, p not dividing h, p^i = -1 mod m, p^(2j) | n
=> all a_h agree mod p^j.
- SC++ (sc2.py): with q = p^j, j = floor(e/2), e = v_p(n): all a_h lie in
  V = {x in [-c, c] : h x = s mod q} (WLOG sum a = +s); R1 kills if |V| <= 1; R2 kills if no
  multiset of h values from V has sum s and sum of squares n + lam c.
- A1 (tiers.py): (tier 1) H = G, p | n, p not dividing v, p self-conj mod exp G; (tier 2) proper
  H, p | n, p > 2c; (tier 3) e >= 4, p^floor(e/2) > 2c. Claimed lemma: p^(2b-1) | n =>
  h a_h = sigma mod p^b; v_p(n) odd impossible.
- A2 (ruleM4.py): on Instances A1 leaves, j = floor(e/2), V as in SC++ (|V| <= 7 only); kill if
  no counts N_x >= 0 on V with sum N = h, sum N x = s, sum N x^2 = n + lam c,
  sum N|x| <= k <= sum N maxm(x), k = sum N|x| mod 2, maxm(x) = c or c-1 with parity of x.
No ambiguity in the claims; "WLOG sum = +s" holds since -D is an SDS with the same parameters
and V, the moments and the m_h bookkeeping are symmetric under a -> -a.

### 2. Proof check of every step beyond SC

Cases: p = 2 / odd; b = 1 / b >= 2; v_p(n) even / odd; H = G (c = 1) / proper; |V| = 0, 1, >= 2.
- R1's residue class: if all a_h = t mod q then sigma = sum a_h = h t, so t = sigma h^-1 mod q
  (h a unit mod q). A one-line consequence of SC's conclusion, not a new claim. |V| = 0: no value;
  |V| = 1: a constant, chi(a) = 0 for chi != 1 (h > 1) against |chi(a)|^2 = n > 0. Correct.
- R2's identities: sum a = sigma (trivial character), sum a^2 = coefficient of 1 in a a^(-1)
  = n + lam c (F3 at shift 0). A constant vector never meets both for h > 1 (h Q = s^2 forces
  h n = n), so "not all equal" is automatic. Correct.
- A1's exponent claim p^(2b-1) | n => h a = sigma mod p^b: the induction step i -> i+1 needs
  T_i T_i^(-1) = n h (h - H)/p^(2i) = 0 mod p, i.e. p^(2i+1) | n (p does not divide h); from
  i = 0 to b the largest requirement is p^(2b-1). Correct. Consistent with SC: if v_p(n) >= 2b it
  is SC with j = b; if v_p(n) = 2b-1 the next line (T_b T_b^(-1) has the non-integral coefficient
  -n h/p^(2b)) is a contradiction, i.e. He-Wu Thm 3.2 / Turyn's odd-exponent fact for a character
  of order dividing exp H. So the extra case is vacuous, not stronger. The Frobenius step
  T^(p^i) = T^(-1) in F_p[H] (coefficients in F_p, x^(p^i) = x^-1) and T = T^(p^(2i)) with
  p^(2i) >= 1 + p^i are correct.
- A1 tier 1 (H = G, b = 1): all D(x) equal mod p. p >= 3: D in {0, G, -G}, each gives n = 0;
  p = 2: D = 0 or every D(x) odd, i.e. k = v. So tier 1 needs k < v when p = 2; ruleMa.py
  checks it (`q == 2 and k < v`), tiers.py line `if v % p and selfconj(p, exponent(f)): return 1`
  does not. Harmless only if no open Instance with p = 2 in tier 1 has k = v (checked in 4).
- A1 tier 2: b = 1 (p | n), p > 2c: all a_h congruent mod p with |a_h - a_h'| <= 2c < p, so
  constant. Correct. Tier 3 is SC itself (j = floor(e/2), e >= 4).
- A2's bookkeeping: a_h = P_h - N_h, m_h = P_h + N_h, so m_h = a_h mod 2 and |a_h| <= m_h <= c
  (coset of size c); hence m_h <= maxm(a_h) (largest integer <= c of a_h's parity), and
  sum|a_h| <= k = sum m_h <= sum maxm(a_h), k - sum|a_h| = sum(m_h - |a_h|) even. Every bound is
  necessary; correct. For c = 1: maxm(0) = 0, maxm(+-1) = 1: right.
Numerical test of A1's exact claim (lemma_a1.py, lemma_a1.out): every integer a in [-B,B]^H with
a a^(-1) = n + mu H, n > 0, on C3 (B 12), C4 (8), C5 (6), C6 (4), C7 (3), C2xC2 (9), C8, C9, C10,
C3xC3 (2); for each self-conjugate p not dividing |H|: 4,149 tests, odd v_p(n) never occurs,
h a_h = sigma mod p^ceil(e/2) always; controls (p not self-conjugate) fail in 11,010 of 11,448.
No gap found in any step.

### 3. Do the scripts implement exactly their claims?

sc2.py (SC++), read line by line:
- verdict(): j = e // 2 (p^(2j) | n), h = 1, p | h and non-self-conjugate p skipped, c = v // h,
  quotient types from indep.quotient_types (re-derived in 4). Right j, c and residue
  (t = s h^-1 mod q). "s-not-integer" counts as a kill but never fires (every row of
  instances.csv has n > 0, s^2 = n + lam v a square, k < v; checked over all 70,543).
- triple(): a = t0 + q y; S1 = (s - h t0)/q (asserted integral), S2 from sum a^2 (R2div if not
  integral), z = y - floor(S1/h): sum z = A in [0, h-1], sum z^2 = B. R2basic (B <= 0, B < A,
  B - A odd) are necessary conditions (sum z^2 >= sum|z| >= A, z^2 = z mod 2). min_count is an
  exact unbounded 2-D knapsack over (sum, sum of squares) minimising the number of nonzero z;
  kill iff > h. Zero padding is valid only if 0 is in [-m, R - m]; if not, the test can only
  under-kill (a real vector's nonzero part still has <= h entries). No error.
tiers.py (A1):
- tier 1, `if v % p and selfconj(p, exponent(f)): return 1`: no `k < v` guard for p = 2, unlike
  ruleMa.py (`q == 2 and k < v`). As code, tier() therefore kills real SDSs (v, v, v - 4), e.g.
  (5,5,1) in C5 and (9,9,5) in C9 (n = 4, p = 2 self-conjugate; see 6). No row of instances.csv
  has k = v, so tiers.txt is not affected. Minor; fix before reuse.
- tier 2 uses b = 1 with only p | n (any e >= 1), tier 3 is SC (e >= 4, p^(e//2) > 2c). The
  claimed p^(2b-1) bookkeeping is used only at b = 1, e = 1; on open rows no triple
  (p, H) with p self-conjugate mod exp H, p not dividing |H| and v_p(n) odd exists at all
  (a1_odd.py: 0), because import.py already removed such rows with He-Wu Thm 3.2 (its m runs
  over all divisors of exp G, which covers every exp H). So on the data A1 = SC plus the
  H = G, p = 2, v_2(n) in {2, 3} case (all D(x) odd, impossible for k < v).
ruleM4.py (A2):
- b = e // 2 (SC's bookkeeping, not A1's), quotients with h > 1, p not dividing h, self-conjugate
  p, r = s h^-1 mod q, |V| <= 7 only, and only on rows with A1 tier 0. feasible(): DFS over
  count vectors, values by |x| descending; prune `Q - N xx > (cnt - N) xx` is equivalent to
  Q > cnt xx (valid, never cuts a solution); last value forced; A_abs <= k <= M and parity at

### Verdict

- SC++ (R1/R2, sc2.py, 7,458 open kills): SURVIVES. Every step past SC is a one-line consequence
  of SC plus Gordon's Lemma 5.2 identities. sc2.py implements the claim exactly. An
  independent MILP run gives the identical 16,167-row kill set. Every one of the 7,458 open
  witnesses was rechecked exactly. Against 694 verified sets: 0 kills and 0 violations. No
  'exists' row is killed. E8: 0 conflicts on 47,938 triples, and the lemma held on 24,731
  enumerable E8-found triples.
- A1 (tiers.py, 4,638 open kills): SURVIVES as a claim and as a count. The p^(2b-1)
  bookkeeping is correct but vacuous: when v_p(n) is odd the case is already impossible (He-Wu),
  and on open rows it never fires. A1 is a subset of SC++, so it adds 0 kills. Code defect
  (latent, no effect on any row): tier 1 lacks the `k < v` guard for p = 2, and tier() kills
  the real (v, v, v-4) sets.
- A2 (ruleM4.py, 3,045 kills): SURVIVES. The m_h bookkeeping (sum|a| <= k <= sum maxm, parity)
  is correct. The ids are reproduced (2 MILP-unsure, settled by R2), and all 3,045 witnesses
  were rechecked exactly. It kills 0 known sets and 0 'exists' rows. The 163 E8-found quotients
  it rejects are all explained by the k <= sum maxm bound, which E8 does not check.
- Union: 3,712 open kills beyond E8, SC, A3, A5 and A7. Both the scripts' outputs and my own
  run give this count, for 12,302 of 22,450 open rows in total. SC++ alone gives 3,488, A2
  adds 224 and A1 adds 0.
Not a proof: Lean decides (the lemma plus a finite check per Instance).

## Literature

- Gordon, arXiv:2212.10630 (HTML opened 2026-11-06): Lemma 5.2 ("intersection numbers") gives
  exactly R2's two identities, sum b_h = s and sum b_h^2 = k + lam(d - 1) (= n + lam c), citing
  Beth-Jungnickel-Lenz VI.5.4. No parity or m_h bounds (A2's k <= sum maxm is not there), no
  self-conjugacy or exponent bound.
- Search "signed difference sets nonexistence self-conjugacy coset sums contraction" (2026-11-06):
  He-Wu arXiv:2608.22936 (snippet: self-conjugate, C2-quotient and near-full-support obstructions
  leave 22,466 open cases), Turyn 1965 (PJM), Arasu-Seberry/Ma-type sources; nothing stating the
  residue class + moments test or the m_h bound for SDS.
- Turyn 1965 Lemma 3, Arasu-Seberry 1998 Thm 3 and Ma's lemma were opened and summarised by the
  rule-sc refuter (rule-sc/report.md 9); A1's ceil(e/2) bookkeeping is Turyn's Lemma 3 read with
  the odd case excluded (p^(2b) || n exactly), so it adds nothing beyond SC.
