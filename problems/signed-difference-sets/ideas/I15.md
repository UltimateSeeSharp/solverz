# I15 Signed combinations of a relative difference set (exists)

N-coefficient β²n − γ²λ + 2βγ(ν − μ) vanishes and its values lie in {−1, 0, 1}; C18 is one case. New
families F1 (R − N, (n³, n² + n − 2, n − 2)), F1′, F3, F4. Rows: 19 open with sets verified by numpy

(whose sds.json sets fail). Lean: `SetCheck` per set.
