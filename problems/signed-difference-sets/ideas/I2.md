# I2 Cyclotomic classes of order 8

Sign vectors on (GF(q), +), q = p^m ≡ 1 mod 8, constant on the eight
cyclotomic classes Cⱼ = {α^(8t + j)} (each of size f = (q − 1)/8) and on {0}:
3⁹ − 1 sign choices per field. Why: O6 (N49) is affinely such a vector
(refuter, [R2](../reviews/R2.md)); they include the Paley sets (order
2) and every order-4 cyclotomic choice. The autocorrelation is constant on
each class, so eight sums decide a choice.

**Kill test.** E6, every choice for every q ≤ 10⁵: a hit on an open Instance
is a set for it; hits at every q of one form point to a family; no hit on an
open Instance kills I2 for the table.
