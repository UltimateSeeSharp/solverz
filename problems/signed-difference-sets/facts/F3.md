# F3 Contraction to a quotient

For an SDS D on G with parameters (v, k, λ) and a homomorphism φ : G → H, the
coset sums a(h) = Σ_{φ(x) = h} D(x) satisfy, for every g′ ≠ 0 in H,
Σ_h a(h)·a(h + g′) = λ·|φ⁻¹(g′)|, and |a(h)| ≤ |φ⁻¹(h)|. A case dies when no
integer vector on H meets these.

**Used by.** N32 (C₂ × C₁₀ → C₅: no vector in [−4, 4]⁵ with autocorrelation 32).
**Evidence.** The standard contraction of the group-ring identity (Gordon,
arXiv:2212.10630; He–Wu's quotient method); `scratch/contract.py` finds the C₅
obstruction for N32 and none for N3 (contraction to C₃ has solutions).
**Proof.** Both sides count the pairs (x, x + g) with φ(g) = g′, each g ≠ 0.
Lean: `IsSDS.contract_autocorr`, `abs_contract_le` in
`lean/SignedDifferenceSets/Contraction.lean`.
