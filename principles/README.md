# Principles

How we attack problems, distilled mainly from Terence Tao (blog, talks, papers, videos) plus a few others. Agents and humans read these before working on a problem; workflow rules in `CLAUDE.md` and agent prompts cite them.

| File | Covers |
|---|---|
| [problem-solving.md](problem-solving.md) | Heuristics for making progress: simplify, toy models, partial progress, obstructions |
| [scepticism.md](scepticism.md) | Red flags in a "proof", and the checklist before believing a claimed result |
| [ai-and-computation.md](ai-and-computation.md) | Using AI and computers: what they're good and bad at, search loops, scorers |
| [lean.md](lean.md) | Formalizing: statement fidelity, step-by-step recipe, trust |
| [values.md](values.md) | What counts as done, what to record, how to behave toward the community |
| [sources.md](sources.md) | Every source, with link and what it contributed |

Tags like `[ICM]` point to entries in `sources.md`. Paraphrases, not quotes, unless in quotation marks. Raw transcripts stay out of git.

Living document: when a source or our own experience teaches something new, add it here with its tag.
