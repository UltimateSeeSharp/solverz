# Principles

How a top mathematician works; rough guides, never rules.

**Solving**
- Turn off all difficulties but one; toy and finite versions; play with
  examples and the smallest case that resists.
- Try what will probably fail; how it fails is a clue.
- Drop a hypothesis, strengthen the conclusion, ask how a lemma will be used.
- Look for a conserved quantity, a symmetry, a better formulation.

**Doubting**: signs to look closer, never to reject
- Too easy, proves too much, a missed case, drift away from the problem.
- Fluent is not evidence; a source counts once opened; Lean certifies the
  statement, not the prose.
- Read exactly which version of a problem was solved.

**Computing**
- Run the obvious computation before stating a conjecture.
- Search with programs that generate candidates; expect the scorer to be
  gamed; keep it fixed during a run; re-verify winners.
- Formalize step by step: statements with `sorry` first, then fill them;
  note where Lean deviates from the paper proof.

**Toward others**
- Record failures and dead ends; they save the next person the most time.
- Don't strip-mine: check who works on a problem; prefer work that adds
  understanding.
- Disclose AI and tool use when sharing.
